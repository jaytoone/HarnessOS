## 1. CLG 진입 원칙

### VALUE GAP 이론이 예측하는 CLG 성공 조건

CLG가 작동하는 유일한 조건: **커뮤니티 안에서 갭이 공개되는 순간이 발생해야 한다**. iter 2에서 CLG를 선택한 이유는 Career Mirror의 핵심 판매 메커니즘("갭 공개 = 판매")이 커뮤니티 환경에서 자연스럽게 증폭되기 때문이다.

**핵심 등식**: 커뮤니티에서 갭 진단 콘텐츠를 공유하는 행위 = 무료 판매 행위. 사용자가 자신의 갭을 커뮤니티에서 발견하면, 동시에 그 갭을 목격한 동료들도 "나도 이 갭이 있나?" 질문을 시작한다. 이것이 Social_Amplifier의 물리적 구현이다.

### 주의: 커뮤니티에서 피칭 = 스팸, 갭 진단 = 가치 기여

커뮤니티에 "우리 제품 좋아요"를 올리면 스팸으로 분류된다. 반면 "당신이 몰랐던 커리어 발산점 3가지"를 올리면 가치 기여가 된다. 차이는 판매 의도의 노출 여부가 아니라, **콘텐츠 자체가 갭을 표면화하는가 여부**다.

### 3개 원칙

**원칙 1: Give before Take — 진단 먼저, 전환은 나중에**

커뮤니티에 최소 3회 가치 기여 콘텐츠를 올린 후에만 제품 CTA를 노출한다. 첫 3개 포스트는 순수 갭 진단 콘텐츠다. 제품 링크 없음. 반응이 오면 DM에서 "이걸 자동으로 해주는 도구가 있다"로 전환.

**원칙 2: 갭 진단 콘텐츠 — 커뮤니티 구성원이 자기 갭을 발견하게 만드는 콘텐츠**

iter 10 인터뷰 프로토콜의 Q3("같은 일 하는 사람들 중에 왜 저 사람은 더 잘 되지?"), Q5("지금 방식 그대로 2년 뒤에도 하고 있으면?"), Q10("비슷한 배경인데 훨씬 빠르게 간 사람이 뭘 알았다고 생각해요?")을 콘텐츠 형태로 변환. 질문을 던지고, 커뮤니티 구성원이 자기 답을 달게 만든다. 그 답 자체가 갭의 자가 진단이다.

**원칙 3: Social Amplifier 활성화 — 갭 공개가 사회적 이벤트가 되게 하라**

iter 15에서 도출한 Social_Amplifier 계수(L3: 1.2, L4: 1.5, L5: 1.8)를 커뮤니티 환경에서 극대화하는 설계. 핵심: 한 명이 갭을 공개하면 동료 3-5명이 "나도 확인해볼까"로 이동하는 연쇄 반응. 이를 위해 갭 진단 콘텐츠는 반드시 **비교 가능한 형태**(체크리스트, 스코어, 벤치마크)로 설계한다.

## 2. 타겟 커뮤니티 분류

### Tier 1 (즉시 진입 — L4-L5 ICP 밀도 높음)

iter 12에서 식별된 채널을 CLG 관점에서 재분류한다. Tier 1은 L4-L5 ICP가 밀집된 커뮤니티로, Career Mirror의 갭 진단이 즉각 반응을 얻을 수 있는 곳이다.

**1. Disquiet (disquiet.io)**
- 플랫폼: 웹 커뮤니티 (한국 프로덕트 빌더/인디 메이커)
- 구성원 특성: 사이드 프로젝트 빌더, 초기 창업가, PM, 개발자. 대부분 "내 이름으로 뭔가 만들고 있다" — 정체성 이동성 높음
- ICP 매칭도: 90%. 아웃컴 카테고리 1(시리즈A 창업가), 2(프리랜서), 5(크리에이터)에 집중
- 진입 전술: 프로덕트 빌더 채널에 "궤적 발산점 분석 결과" 시리즈 게시. Disquiet은 데이터 기반 인사이트를 좋아하는 문화 → 분석 포스트가 자연스러움. 관리자 제한 낮음

**2. 글또 (geultto.github.io) — 글 쓰는 개발자 모임**
- 플랫폼: Slack 워크스페이스 + GitHub
- 구성원 특성: 개발자 중 외부 아웃풋(블로그, 기술 글)을 적극 생산하는 그룹. 정체성 이동성이 검증된 ICP
- ICP 매칭도: 85%. 아웃컴 카테고리 3(테크리드/CTO 전환), 6(사내 전문가 → 외부 인정)에 집중
- 진입 전술: 글또 Slack #자유 채널에 "기술 블로거의 커리어 궤적 vs 비블로거 궤적 — 데이터 분석" 포스트. 글또 참여자는 이미 "쓰는 것이 커리어에 어떤 영향을 미치나"에 관심 → 갭 진단이 직접적 관심사

**3. AWSKRUG / GDG Korea — 클라우드 기술 커뮤니티**
- 플랫폼: Discord / 오프라인 밋업
- 구성원 특성: 중급-시니어 개발자, DevOps, 아키텍트. 기술 깊이가 있으나 외부 가시성은 편차 큼
- ICP 매칭도: 80%. 아웃컴 카테고리 3, 6에 매칭. 특히 "시니어인데 왜 나는 CTO가 아닌가"를 은연중 고민하는 L4 ICP 다수
- 진입 전술: 밋업 후 네트워킹 시간에 "커리어 궤적 비교 연구" 소개. 오프라인에서 1차 접촉 후 온라인 전환. 커뮤니티 디스코드에 분석 요약 공유

**4. 프리랜서 코리아 카카오 오픈채팅**
- 플랫폼: 카카오톡 오픈채팅 (다수의 직군별 방 존재)
- 구성원 특성: 프리랜서 개발자, 디자이너, 마케터. 독립 수익을 추구하며 정체성 이동성이 내재된 그룹
- ICP 매칭도: 85%. 아웃컴 카테고리 2(월 500만+ 프리랜서), 4(독립 컨설턴트)에 집중
- 진입 전술: 방 관리자 사전 허가 후, "프리랜서 수익 궤적 상위 20% vs 나머지 — 어디서 갈렸나" 주제로 진입. 프리랜서 커뮤니티는 수익 비교에 민감 → 갭 자극 강도 높음

**5. 인프런 / 커리어리 — 기술 학습 + 커리어 커뮤니티**
- 플랫폼: 웹 커뮤니티
- 구성원 특성: 주니어-시니어 개발자, PM, 디자이너. 학습 의지가 높고, "다음 단계"에 대한 질문이 활발
- ICP 매칭도: 75%. L3 ICP 비율이 높으나, L4 전환 가능성 있는 구성원도 다수. 아웃컴 카테고리 3, 6 매칭
- 진입 전술: 인프런 커뮤니티/커리어리에 "같은 연차인데 왜 저 사람은 다른 궤적인가" 시리즈 글 게시. 플랫폼 특성상 학습 콘텐츠 형태로 포장하면 자연스러움

### Tier 2 (2개월 후 — L3 ICP, 규모 큰 커뮤니티)

Tier 1에서 검증된 갭 진단 콘텐츠를 더 넓은 커뮤니티에 배포하는 단계. L3 비율이 높지만 규모로 보상.

**1. 블라인드 (Blind)**
- 플랫폼: 앱 (익명 직장인 커뮤니티)
- 구성원 특성: 대기업/스타트업 직장인. 연봉, 이직, 커리어 비교가 일상적 토픽. Social_Position_Gap이 상시 활성화된 환경
- ICP 매칭도: 65%. L1-L3 비율이 높으나, "같은 연차인데 왜 연봉이 다른가"가 발산점 진단과 직결
- 진입 전술: 익명 환경이므로 데이터 기반 포스트가 유리. "N년차 개발자 커리어 궤적 분석 — 연봉 상위 vs 하위 발산점" 형태

**2. LinkedIn Korea**
- 플랫폼: LinkedIn
- 구성원 특성: 중견-시니어 전문직. 프로필 기반으로 ICP 사전 스크리닝 가능. 콘텐츠 도달 범위가 커뮤니티 대비 넓음
- ICP 매칭도: 70%. L3-L4 분포. 이직 2회+ 기재자 = 정체성 이동성 존재
- 진입 전술: 개인 피드에 "커리어 궤적 연구 시리즈" 발행. LinkedIn 알고리즘은 인사이트+데이터 조합에 노출 보상. 댓글 참여자 DM 전환

**3. 원티드 커뮤니티 (wanted.co.kr)**
- 플랫폼: 웹 커뮤니티 (채용 플랫폼 부속)
- 구성원 특성: 이직 준비자, 커리어 전환 고민자. "다음 단계"에 대한 긴급성이 높은 그룹
- ICP 매칭도: 70%. L3 밀도 높음. "이직하면 뭐가 달라지나"가 갭 프레이밍과 직결
- 진입 전술: 원티드 커리어 콘텐츠 섹션에 기고 형태로 갭 진단 콘텐츠 배치

### Tier 3 (PLG 단계 — 플랫폼형, 바이럴 적합)

CLG에서 PLG로 전환된 후, 바이럴 계수를 극대화하는 플랫폼.

**1. Twitter/X (한국 테크 커뮤니티)**
- 플랫폼: Twitter/X
- 구성원 특성: 기술 블로거, 오픈소스 기여자, 인디 메이커. 짧은 인사이트 공유 문화. 리트윗 기반 바이럴
- 바이럴 적합도: 높음. Career Mirror의 익명화 공유 기능(Free tier)이 트윗 형태로 자연스럽게 유통. "내 커리어 발산점 3개를 봤다" → 동료 클릭
- PLG 연결: 공유 링크 클릭 → 5필드 입력 → 갭 공개 → 본인도 공유 → 연쇄

**2. 브런치 (brunch.co.kr)**
- 플랫폼: 카카오 블로그 플랫폼
- 구성원 특성: 커리어/자기계발 글 작성자와 독자. 장문 인사이트에 반응하는 문화
- 바이럴 적합도: 중간-높음. "커리어 궤적 분석 결과" 형태의 장문 콘텐츠가 브런치 독자 취향에 부합. 카카오 공유 생태계로 확산
- PLG 연결: 브런치 글 → Career Mirror 링크 삽입 → 독자가 자기 궤적 확인 → 본인도 글 작성

## 6. CLG → PLG 전환 트리거

### 전환 조건 정의

CLG는 창업자가 직접 커뮤니티에서 관계를 만들어 사용자를 확보하는 모델이다. PLG는 제품 자체가 사용자를 확보하는 모델이다. 전환 시점 = **제품이 창업자 없이도 새 사용자를 데려오는 순간**.

### 정량적 전환 트리거

**트리거 1: 공유 기반 신규 가입 비율 > 40%**

- 측정: `신규 가입 중 공유 링크 경유 비율`
- 의미: 전체 신규 가입자의 40% 이상이 기존 사용자의 공유 링크를 통해 유입되면, 제품이 자체 배포 능력을 갖춘 것
- iter 5의 "공유 잠금 해제" 메커니즘(Free tier: 익명화 결과 공유 → 발산점 상세 1개 잠금 해제)이 이 트리거의 엔진
- 현재 상태(CLG): 공유 링크 경유 비율 0% (아직 제품 없음) → 목표: W4 이후 10% → 3개월 후 40%

**트리거 2: 바이럴 계수(k) > 0.5**

- 측정: `k = (기존 사용자당 평균 초대 수) × (초대 → 가입 전환율)`
- k > 1.0이면 순수 바이럴 성장 가능하지만, 현실적으로 k > 0.5이면 CLG + PLG 혼합 모드가 효율적
- iter 15의 Social_Amplifier 계수: L5 사용자의 갭 공개가 동료 3-5명에게 전파 → 이론적 k = 3 × 0.3 = 0.9 (L5), 2 × 0.2 = 0.4 (L3)
- PLG 전환 기준: L4 사용자 기준 k > 0.5

**트리거 3: Core tier 유지율 > 70% (3개월)**

- 측정: Core tier 가입 후 3개월 시점 유지율
- 의미: 유지율 70%+이면 제품이 지속적 가치를 전달하고 있으며, PLG 스케일 시 churn으로 성장이 상쇄되지 않음
- iter 15 연결: Core tier(₩24,900/월) → 3개월 유지 = ₩74,700 LTV 확보 → CAC 여유분 발생 → paid acquisition 테스트 가능

### PLG 전환 시 행동 변화

| 항목 | CLG 모드 | PLG 모드 |
|---|---|---|
| 사용자 확보 | 창업자 DM + 커뮤니티 포스트 | 공유 링크 + SEO + 제품 내 초대 |
| 커뮤니티 역할 | 사용자 확보 채널 | 브랜드 + retention 채널 |
| 콘텐츠 | 갭 진단 (수동 제작) | 사용자 생성 갭 데이터 (자동) |
| 핵심 지표 | 모집 수 / DM 전환율 | k-factor / 공유율 / activation rate |
| 가격 전략 | Core tier 집중 | Pro/Expert tier 업셀 강화 |

### iter 12 → iter 15 연결

- iter 12: 시드 코호트 90명 목표. 이 90명이 CLG의 씨앗
- iter 15: Core tier ₩24,900/월. 90명 중 Free → Core 전환율 8-12% = 7-11명 유료 사용자
- PLG 전환 시점: 90명의 시드 사용자가 공유 링크로 추가 36명+ 유입 (40% 공유 기반)시 → 총 사용자 126명+ → PLG 모드 진입

**진단**: 갭 프레이밍이 커뮤니티 구성원의 현실과 괴리. 가능한 원인:
- 발산점 데이터가 충분히 구체적이지 않아 호로스코프처럼 느껴짐 (iter 8 경고 재현)
- 커뮤니티 구성원이 L1-L2 비율이 높아 갭 자체에 관심 없음
- 포스트 톤이 "분석 결과 공유"가 아닌 "제품 홍보"로 읽힘

**피벗 옵션**:
- A) 발산점 데이터를 시드 코호트 인터뷰(iter 10)에서 직접 추출한 구체적 수치로 교체
- B) 타겟 커뮤니티를 Tier 2로 이동하고, Tier 1에서 더 좁은 니치 커뮤니티(예: 특정 직군 오프라인 모임)로 교체
- C) 콘텐츠 포맷을 데이터 분석에서 "질문 던지기"로 변경 (데이터 없이 Q3, Q5를 커뮤니티에 직접 질문)

**이론 수정 연결 (iter 11 falsification)**: 3개 커뮤니티에서 연속 무반응이면, "갭 공개 = 판매"가 커뮤니티 환경에서는 작동하지 않을 가능성. 이 경우 iter 11의 falsification 기준 F2("갭 공개 후 전환 의향 0% → 이론의 판매 메커니즘 부정")를 부분 충족. 커뮤니티 간접 갭 공개 vs 개인 직접 갭 공개의 차이를 이론에 추가해야 한다.

### 실패 신호 2: DM 전환 실패 (W2-W3)

**신호**: 갭 콘텐츠 반응은 있으나(댓글 10+), DM에서 제품 링크 전송 후 클릭율 < 10%

**진단**: 커뮤니티에서 갭에 관심은 있으나, "도구로 해결"에 대한 니즈가 약함. 가능한 원인:
- 갭 인식은 있으나 "도구가 필요하다"는 인식이 없음 (자체 해결 가능하다고 판단)
- DM 톤이 판매로 전환되는 순간 방어벽 활성화
- 무료라고 해도 "또 다른 서비스 가입"에 대한 피로도

**피벗 옵션**:
- A) DM 대신 커뮤니티 내에서 "라이브 갭 진단 세션" 진행 (Zoom/Google Meet, 30분, 5명 그룹)
- B) 링크 전송 대신 "분석 결과를 제가 직접 해드릴게요" → 수동 갭 분석 → 결과를 보여준 후 "이걸 자동화한 도구가 있어요"로 전환
- C) 제품 링크 없이, 체크리스트(자산 1)만 배포하고 체크리스트 완료자에게 "상세 분석 받아보시겠어요?"로 2단계 전환

**이론 수정 연결**: DM 전환 실패가 지속되면, VALUE GAP 이론의 "갭 공개 순간 = 판매 순간" 가정이 "갭 공개 + 해결 경로 가시화 = 판매 순간"으로 수정 필요. 갭만으로는 부족하고, 달성 가능한 경로(Attainability)가 함께 제시되어야 전환이 발생한다는 것.

### 실패 신호 3: Free → Core 전환율 < 3% (W4 이후)

**신호**: Career Mirror 가입(5필드 입력)은 발생하나, Core tier(₩24,900/월) 전환율이 3% 미만

**진단**: 갭 시각화는 작동하나, 유료 가치 인식이 부족. 가능한 원인:
- Free tier에서 이미 충분한 가치를 얻어 유료 필요성을 느끼지 못함 (Free tier가 너무 관대)
- 블러 처리된 인과 분석/닫기 기간에 대한 호기심이 충분하지 않음
- ₩24,900이 갭 진단 가치 대비 높게 느껴짐

**피벗 옵션**:
- A) Free tier 축소: 발산점 라벨 3개 → 1개만 공개, 나머지 2개를 Core gate 뒤로 이동
- B) 가격 실험: ₩24,900 → ₩14,900 (₩10,000 인하) 또는 "첫 달 ₩9,900" 트라이얼
- C) Core tier에 "피어 1명 매칭 체험"을 추가하여 Social_Amplifier 가치를 즉각 체감하게 함

**이론 수정 연결 (iter 11 falsification)**: Free → Core 전환율 < 3%가 2주 이상 지속되면, iter 15의 L3 D(WTP)_sustainable = 0.653 추정이 과대일 가능성. 이 경우:
- Functional_Gap 추정(0.5)이 실제로는 0.3 이하 → 한국 L3 사용자의 갭 인식 강도가 이론 예측보다 약함
- 또는 Attainability 추정(0.8)이 실제로는 0.5 이하 → 갭을 보여줘도 "닫을 수 있다"고 느끼지 않음
- iter 11 falsification 기준 F1("지불 의향 0원 → 이론의 WTP 예측력 부정")의 부분 충족. WTP가 0은 아니지만 이론 예측의 50% 미만이면 변수 재보정 필요
