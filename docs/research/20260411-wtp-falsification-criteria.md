## 도입: 왜 반증 기준이 필요한가

Imre Lakatos의 과학적 연구 프로그램 방법론(MSRP)에 의하면, 어떤 이론이든 **핵심(hard core)**과 **보호대(protective belt)**를 구분해야 한다. 핵심은 이론의 정체성 — 포기하면 이론 자체가 소멸한다. 보호대는 핵심을 둘러싼 보조 가설들 — 반증 증거가 나타나면 핵심 대신 보호대를 수정하여 대응한다.

Karl Popper의 반증주의(falsificationism)는 더 근본적인 요구를 한다: 어떤 경험적 관찰이 나타나면 이론이 틀렸다고 인정할 것인지 **사전에** 명시해야 한다. 이것이 없으면 이론은 과학이 아니라 신조(creed)다.

VALUE GAP theory v2는 iter 1-9까지 설명력을 확장해왔으나, iter 8 메타-리뷰가 정확히 이 문제를 식별했다: "iter 7이 곱셈 구조 테스트를 실패해도 덧셈으로 다운그레이드할 뿐 — 언제 'VALUE GAP이 틀렸다'고 말할 것인지 명시 없음." 이것은 이론의 과학적 지위를 훼손하는 구조적 결함이다.

본 문서는 이 결함을 해소한다. VALUE GAP의 핵심 명제를 분리하고, 각 명제에 대한 구체적 반증 조건을 명시하며, 이론의 적용 범위(scope boundary)를 명문화하고, 경쟁 이론들과 차별적 예측이 갈라지는 지점을 식별한다.

## 1. 이론의 핵심 명제 (Hard Core)

Lakatos의 hard core는 "이론의 부정적 발견법(negative heuristic)에 의해 보호되는 명제들 — 연구 프로그램 참여자가 반증 증거에 직면해도 수정하지 않기로 합의한 것들"이다. VALUE GAP theory에서 hard core에 해당하는 명제들을 식별한다.

### HC-1: 정체성 갭 = WTP의 근원 명제

> **고관여 정체성 인접 구매에서, 지불의사(WTP)는 인지된 현재 자아(perceived current self)와 바람직한 자아(desired self) 사이의 갭 강도(Gap Intensity)에 비례한다.**

이것이 VALUE GAP의 존재론적 핵심이다. WTP가 기능적 효용, 습관, 사회적 압력, 가격 앵커링 등 다른 요인과 무관하게 "정체성 갭"에 의해 **지배적으로** 설명된다는 주장. 이 명제가 부정되면 이론은 고유한 설명력을 상실한다.

**정밀화**: "비례"는 단조 증가 관계(monotonically increasing relationship)를 의미한다 — 갭 강도가 증가하면 WTP가 감소하는 경우가 체계적으로 관찰되면 HC-1이 반증된다. 비선형 관계(볼록, 오목, S자)는 허용하되, 비단조(non-monotonic) 관계는 불허한다.

### HC-2: 갭 공개 = 구매 전환 촉발 명제

> **잠재 구매자가 자신의 정체성 갭을 인식(공개)하는 순간이 구매 전환의 핵심 촉발점이다. 갭이 인식되지 않은 상태에서는 고관여 구매가 발생하지 않는다.**

Eugene Schwartz(1966)의 문제 인식 세그멘테이션을 정체성 프레임으로 재진술한 것이지만, VALUE GAP의 고유한 메커니즘적 주장이다. "갭 공개 = 판매"라는 등식은 마케팅 전략의 핵심 함의를 결정한다. 이 명제가 부정되면 VALUE GAP의 실천적 처방 전체가 무효화된다.

**정밀화**: "인식"은 자기보고(self-report), 행동 지표(갭 관련 콘텐츠 소비 후 전환), 또는 제3자 관찰(갭 경험을 묘사하는 인터뷰 데이터)로 측정 가능해야 한다.

### HC-3: 계층적 갭 구조 명제

> **정체성 갭은 질적으로 구분되는 레벨(L1-L5)로 계층화되며, 상위 레벨의 갭이 하위 레벨보다 체계적으로 더 높은 WTP를 생성한다.**

L1(Social Presence) → L2(Commodity Delegation) → L3(Identity Delegation) → L4(Meta-insight known) → L5(Meta-insight unknown)의 순서적 위계가 VALUE GAP의 진단 프레임워크를 구성한다. 이 위계가 존재하지 않거나, 레벨 간 WTP 차이가 무작위적이라면 L1-L5 분류는 임의적 태그에 불과하다.

**정밀화**: 체계적으로 = 모든 개인에게 항상이 아니라, 모집단 수준에서 평균 WTP가 L1 < L2 < L3 < L4 < L5 순서를 보인다. 개인 차이는 허용하되 집단 수준의 역전은 불허한다.

### HC-4: 지속가능성 분리 명제

> **순간적 WTP(D(WTP)_instantaneous)와 지속가능 WTP(D(WTP)_sustainable)는 분리 가능한 구성개념이며, 비윤리적 갭 착취는 전자는 극대화하되 후자를 체계적으로 훼손한다.**

이것은 Ethical_Coefficient의 이론적 기초다. 도박, 중독성 소셜미디어, 착취적 마이크로트랜잭션이 막대한 순간 WTP를 추출하면서 장기적으로 이탈·규제·평판 붕괴를 초래한다는 관찰을 구조화한 것이다. 이 분리가 경험적으로 성립하지 않으면 — 즉, 착취적 제품이 장기적으로도 높은 WTP를 유지한다면 — D(WTP)_sustainable 개념이 불필요해진다.

## 2. 반증 기준 — 언제 VALUE GAP이 틀렸는가

Popper의 반증주의에서 가장 중요한 것은 "잠재적 반증자(potential falsifier)"의 사전 명시다. 이론이 금지하는 관찰을 명확히 해야 한다. VALUE GAP의 각 핵심 명제에 대해 구체적 반증 조건을 5개 이상 명시한다.

### F-1: 정체성 갭 비관련 고WTP 관찰 (HC-1 반증)

**반증 조건**: 고관여 정체성 인접 구매 상황에서, 정체성 갭 강도와 WTP 사이에 **통계적으로 유의한 상관이 없거나 음의 상관**이 관찰된다.

**구체적 테스트 설계**:
- 피험자 N >= 200명 (통계적 검정력 확보)
- 정체성 갭 측정: 자기불일치 척도(Self-Discrepancy Scale, Higgins 1987) 한국어 번안 + VALUE GAP 자체 척도(L1-L5 자기분류)
- WTP 측정: BDM(Becker-DeGroot-Marschak) 경매 메커니즘 또는 PSM(Price Sensitivity Meter, Van Westendorp)
- 제품 범주: VALUE GAP이 주장하는 고관여 영역 (커리어 개발, 전문성 도구, 정체성 표현 제품)
- **반증 임계값**: Pearson r < 0.15 (약한 효과 이하) 또는 r < 0 (음의 상관), p < 0.05

**왜 이것이 반증인가**: VALUE GAP의 존재 이유는 "WTP = 정체성 갭 해소 비용"이라는 등식이다. 이 등식이 실증적으로 지지되지 않으면 이론의 핵심이 공허해진다. 단순히 "갭이 있으면 WTP가 발생한다"가 아니라, "갭 강도가 WTP 크기를 결정한다"는 더 강한 주장을 하고 있으므로, 상관 부재는 결정적 반증이다.

**보호대 수정으로 흡수 불가능한 이유**: "측정 도구가 잘못되었다"는 방어는 허용하되, 3가지 이상의 독립적 갭 측정 도구(자기불일치 척도, VALUE GAP L-분류, 갭 시각화 목업 반응)가 모두 WTP와 무상관이면 측정 문제가 아닌 이론 문제다.

### F-2: 갭 비인식 구매의 체계적 관찰 (HC-2 반증)

**반증 조건**: 고관여 정체성 인접 구매자의 상당 비율(>40%)이 구매 시점에 정체성 갭을 인식하지 못했다고 보고하며, 사후적으로도 갭 경험을 재구성하지 못한다.

**구체적 테스트 설계**:
- 최근 고관여 구매(₩50,000+)를 한 한국 소비자 N >= 100명
- 구매 직후(24시간 이내) 인터뷰
- 질문 구조: (1) 구매 동기 자유 서술, (2) 정체성 갭 프로빙(구조화된 질문 — "구매 전에 자신에게 부족하다고 느낀 것?"), (3) VALUE GAP L1-L5 설명 후 자기 분류
- **반증 임계값**: 40% 이상이 (1)에서 갭 관련 언급 없음 + (2)에서도 갭 경험 부정 + (3)에서 "해당 없음" 선택

**왜 이것이 반증인가**: "갭 공개 = 판매"는 갭 인식이 구매의 필요조건이라는 주장이다. 다수의 구매자가 갭 인식 없이 구매한다면 이 필요조건이 붕괴한다. 사후합리화 편향을 제거하기 위해 "사후적으로도 갭을 재구성하지 못한다"는 조건을 추가했다.

**허용되는 예외**: 습관적 재구매(구독 자동 갱신)는 초기 갭 인식 후의 관성이므로 제외. 반증 대상은 **신규 구매 또는 최초 구매**로 한정한다.

### F-3: L-레벨 위계 역전의 체계적 관찰 (HC-3 반증)

**반증 조건**: 동일 제품 범주 내에서, L-레벨이 높은 제품이 L-레벨이 낮은 제품보다 WTP가 **체계적으로 낮은** 패턴이 관찰된다.

**구체적 테스트 설계**:
- 동일 범주(예: 커리어 개발 도구)에서 L2(commodity delegation — 이력서 자동 작성), L3(identity delegation — 커리어 코칭), L4(meta-insight known — 강점/약점 진단), L5(meta-insight unknown — 미인식 정체성 갭 발견) 제품을 각각 제시
- 동일 피험자 내(within-subject) WTP 측정
- **반증 임계값**: 모집단 평균 WTP 순서가 L5 < L3 또는 L4 < L2인 패턴이 반복 관찰(2회 이상 독립 표본)

**왜 이것이 반증인가**: L1-L5 위계는 "deeper gap = higher WTP"라는 구조적 예측이다. 이 예측이 성립하지 않으면 L-레벨 분류는 서술적 태그일 뿐 예측력이 없다. 특히 L5(미인식 갭)가 L3(정체성 위임)보다 WTP가 낮다면, "모르는 갭이 아는 갭보다 값지다"는 VALUE GAP의 가장 반직관적이고 차별적인 예측이 무효화된다.

**보호대 수정으로 흡수 불가능한 이유**: "L5 갭은 인식되지 않았으므로 WTP로 표현되기 어렵다"는 방어가 가능하다. 이것을 방지하기 위해 테스트 설계에서 L5 제품은 갭 공개(gap revelation) 과정을 포함시킨 후 WTP를 측정한다. 갭이 공개된 후에도 L5 WTP가 L3보다 낮으면 위계 역전은 진짜다.

### F-4: Social_Amplifier 무효과 관찰 (HC-1+HC-3 부분 반증)

**반증 조건**: 사회적 가시성(social visibility)을 실험적으로 조작(공개 vs 비공개 사용)했을 때, WTP에 **통계적으로 유의한 차이가 없다.**

**구체적 테스트 설계**:
- 2x2 팩토리얼 설계: (공개 사용 / 비공개 사용) × (고 기능적 갭 / 저 기능적 갭)
- 예: 커리어 진단 도구를 (A) LinkedIn에 결과 공개 vs (B) 개인만 열람 조건에서 WTP 비교
- **반증 임계값**: 공개 조건과 비공개 조건의 WTP 차이가 Cohen's d < 0.2 (무시할 수준), p > 0.10

**왜 이것이 반증인가**: VALUE GAP v2 공식에서 Social_Amplifier는 "기능적 갭이 중요한 타인에게 보이는 정도"로 정의된다. 사회적 가시성이 WTP에 영향을 미치지 않으면 Social_Amplifier는 실재하지 않는 구성개념이다. v2의 핵심 수정(Gap_Intensity = Functional_Gap + Social_Position_Gap)의 Social_Position_Gap 성분도 무효화된다.

**부분 반증인 이유**: Social_Amplifier가 무효해도 HC-1(정체성 갭 = WTP의 근원)은 살아남을 수 있다 — Functional_Gap만으로 WTP를 설명할 수 있으므로. 하지만 L1(Social Presence alone)이 독립 레벨로 존재하는 것이 불가능해지므로 HC-3의 L1 부분이 반증된다.

### F-5: 윤리적 착취 제품의 장기 WTP 유지 관찰 (HC-4 반증)

**반증 조건**: 명백히 착취적인 제품(중독성 게임, 다크 패턴 구독)이 **5년 이상** 높은 WTP를 유지하며, 이탈률 증가·규제·평판 훼손이 WTP에 유의미한 부정적 영향을 미치지 않는다.

**구체적 테스트 설계**:
- 착취적 제품 10개, 비착취적 제품 10개를 윤리성 평가(독립 평가자 합의)로 분류
- 각 제품의 5년간 ARPU(Average Revenue Per User) 추이 비교
- **반증 임계값**: 착취적 제품 군의 5년 ARPU 감소율이 비착취적 제품군과 통계적으로 유의한 차이 없음 (p > 0.10)

**왜 이것이 반증인가**: D(WTP)_instantaneous와 D(WTP)_sustainable의 분리가 VALUE GAP v2의 핵심 수정이었다. 착취적 제품이 장기적으로도 건강한 WTP를 유지한다면 이 분리가 불필요하다 — 단일 WTP 모형으로 충분하다.

**허용되는 예외**: 규제가 개입하여 인위적으로 WTP가 유지되는 경우(예: 독점 지위)는 제외. 반증 대상은 경쟁 시장 내 착취적 제품으로 한정.

### F-6: 정체성 비인접 구매에서 VALUE GAP 우월성 관찰 (스코프 반증)

**반증 조건**: VALUE GAP이 스코프 밖이라고 명시한 저관여/비정체성 구매(생필품, 충동구매)에서 VALUE GAP 프레임워크가 기존 이론(가격 이론, 행동경제학)보다 **더 나은 설명력**을 보인다.

이것은 역설적 반증이다. VALUE GAP이 스코프 밖에서도 작동하면 이론이 틀린 것이 아니라 **스코프 주장이 틀린 것**이다. 하지만 보편적 적용은 iter 8 메타-리뷰가 식별한 과잉주장("모든 수요 발생 메커니즘은 이 명제의 특수 사례")으로의 회귀이며, 이는 반증 가능성 자체를 약화시킨다. 따라서 스코프 밖 작동도 일종의 반증으로 취급한다 — 이론의 정밀도(precision) 반증.

### F-7: 갭 강도-WTP 관계의 문화 간 비재현 (외적 타당도 반증)

**반증 조건**: VALUE GAP이 한국 표본에서 관찰된 패턴이 다른 문화권(개인주의 문화: 미국/네덜란드, 집단주의 문화: 일본/중국)에서 **재현되지 않는다.**

**구체적 테스트 설계**:
- 동일 제품 범주, 동일 측정 도구, 3개 이상 문화권에서 동시 측정
- **반증 임계값**: 한국에서 관찰된 갭 강도-WTP 상관(r)이 다른 문화권 2개 이상에서 r < 0.10 (무상관)

**왜 이것이 반증인가**: VALUE GAP이 한국 특수적 현상(한국의 높은 사회적 비교 문화, 체면 중시)이라면 보편적 이론이 아닌 문화 특수적 관찰이다. 이론적 지위가 "수요의 일반 이론"에서 "한국 고관여 구매의 문화적 패턴"으로 격하된다.

**보호대 수정 허용 범위**: 문화에 따라 L-레벨 비중이 달라지는 것(예: 집단주의 문화에서 L1의 비중이 큰 것)은 허용. 갭 강도-WTP 상관 자체가 사라지는 것은 불허.

## 3. 스코프 경계 명문화

### 3.1 VALUE GAP이 적용되는 영역 (In-Scope)

VALUE GAP은 다음 **세 가지 조건을 모두 충족하는** 구매 상황에 적용된다:

**(1) 고관여(High Involvement)**

구매 결정에 인지적 노력과 심리적 관여가 수반된다. Zaichkowsky(1985)의 Personal Involvement Inventory 기준으로 중앙값 이상. 실무적 기준: 구매 전 비교·탐색 행동이 있고, 구매 후 만족/불만족이 자아 평가에 영향을 미치는 구매.

구체적 예시:
- 커리어 개발 도구 (온라인 코스, 코칭, 자격증)
- 전문성 표현 도구 (포트폴리오 플랫폼, 개인 브랜딩 서비스)
- 건강/웰빙 서비스 (개인 트레이너, 정신건강 서비스)
- 교육 서비스 (대학, 부트캠프, 멘토링)
- 창작 도구 (전문 소프트웨어, 악기, 사진 장비)
- 사회적 정체성 표현 제품 (고관여 패션, 럭셔리)

**(2) 정체성 인접(Identity-Adjacent)**

구매 대상이 구매자의 자아 개념(self-concept)과 연결되어 있다. "이 제품을 사용하는 사람은 어떤 사람인가?"라는 질문에 대한 답이 구매자의 바람직한 자아상(ideal self)과 관련된다.

조작적 정의: 제품 사용이 구매자의 사회적 정체성, 전문적 정체성, 또는 개인적 정체성의 일부로 통합되는 정도. Belk(1988)의 Extended Self 프레임워크에서 "소유물이 자아의 확장인 정도"가 중앙값 이상인 제품.

**(3) 비독점 시장(Non-Monopolistic)**

구매자에게 대안이 존재한다. 독점적 필수재(전기, 수도)는 WTP가 가격 이론과 규제에 의해 결정되므로 정체성 갭 프레임이 추가 설명력을 제공하지 않는다.

### 3.2 VALUE GAP이 적용되지 않는 영역 (Out-of-Scope)

다음 구매 상황에서 VALUE GAP은 주도적 설명 프레임워크로서의 지위를 주장하지 않는다:

**(A) 저관여 보충 구매(Low-Involvement Replenishment)**

휴지, 세제, 주유 등 소모품 보충 구매. 이들은 정체성 갭이 아닌 재고 소진(inventory depletion)에 의해 촉발된다. VALUE GAP이 이 영역에서 기존 가격 이론보다 나은 설명력을 주장하는 것은 과잉주장이다.

iter 1에서 "모든 수요 발생 메커니즘은 이 명제의 특수 사례다"라고 주장한 것은 명시적으로 철회한다. 휴지 구매에 정체성 갭 프레임을 적용하는 것은 unfalsifiable overreach다.

**(B) 충동 구매(Impulse Purchase)**

계획되지 않은 즉각적 구매 — 편의점 간식, 계산대 옆 진열 상품. 이들은 정체성 갭 인식 과정(HC-2)을 거치지 않으며, 감각적 자극·상황적 단서·저가 접근성에 의해 촉발된다. Stern(1962)의 충동 구매 분류에서 "순수 충동 구매"와 "상기 충동 구매"가 해당.

예외: 고가 충동 구매(예: ₩500,000+ 온라인 쇼핑에서의 즉각 결제)는 외관상 충동적이지만 잠복적 정체성 갭이 사전에 형성되어 있을 수 있다. 이 경우 사후 인터뷰로 갭 존재를 확인한 후에만 VALUE GAP 스코프에 포함.

**(C) 순수 상품재(Pure Commodity)**

차별화되지 않은 대체 가능 상품 — 원자재, 범용 볼트/너트, 비브랜드 식재료. 이들의 WTP는 수요-공급 균형과 거래 비용에 의해 결정되며 정체성 갭은 무관하다.

경계 사례: "유기농" 식재료, "공정무역" 커피처럼 가치 기반 브랜딩이 있는 상품재는 정체성 인접성이 존재할 수 있으므로 사례별 판단. VALUE GAP 스코프 내로 포함하려면 조건 (2)의 정체성 인접성 테스트를 통과해야 한다.

**(D) 제도적 구매(Institutional Purchase)**

구매 결정자가 개인이 아닌 조직인 경우 — B2B 조달, 정부 조달. 의사결정 주체가 개인의 정체성이 아닌 조직의 KPI/예산/절차에 의해 제약받으므로 정체성 갭 프레임의 적용이 제한적이다.

예외: B2B에서도 최종 의사결정자가 개인이고 그 개인의 전문적 정체성이 구매 결정에 영향을 미치는 경우(예: CTO가 기술 스택 선택 시 자신의 기술적 정체성을 투사) VALUE GAP이 부분 적용될 수 있다. 하지만 이 경우에도 조직적 제약이 지배적이므로 VALUE GAP은 **보조적** 설명 프레임이다.

**(E) 중독/강박 구매(Addictive/Compulsive Purchase)**

도박, 약물, 강박적 쇼핑 등 자기 통제 실패에 의한 구매. 이들은 정체성 갭이 아닌 신경화학적 보상 회로(dopamine reward circuit)에 의해 구동된다. VALUE GAP v2의 D(WTP)_instantaneous는 이 영역의 순간적 WTP를 설명할 수 있으나, 이는 임상적 영역이므로 VALUE GAP의 규범적 처방(갭 공개 마케팅 등)이 적용 불가.

### 3.3 경계 결정 절차

새로운 구매 상황이 VALUE GAP 스코프 내인지 판단하는 3단계 절차:

1. **관여도 테스트**: 구매 전 탐색/비교 행동이 있는가? → 없으면 Out-of-Scope
2. **정체성 인접성 테스트**: "이 제품을 사용하는 나는 어떤 사람인가?"라는 질문이 구매자에게 의미 있는가? → 의미 없으면 Out-of-Scope
3. **대안 존재 테스트**: 대안 제품이 존재하는가? → 존재하지 않으면(독점) Out-of-Scope

세 테스트를 모두 통과해야 VALUE GAP 스코프 내.

### 4.2 상세 분석: 각 예측 분기점

#### 분기점 1 — 갭 공개 프레이밍 vs 기능 효율 프레이밍

이것은 VALUE GAP의 가장 직접적이고 테스트하기 쉬운 차별 예측이다.

**VALUE GAP 논리**: WTP는 정체성 갭 강도에 비례한다. "숨겨진 약점 발견" 프레이밍은 갭을 인식시키므로(HC-2: 갭 공개 = 판매) WTP를 직접 활성화한다. "업무 효율화" 프레이밍은 기능적 편익만 전달하므로 갭 활성화가 약하다. 따라서 동일 제품이라도 갭 공개 프레이밍이 현저히 높은 WTP를 생성한다.

**JTBD 반론**: JTBD 프레임워크에서 두 프레이밍은 동일한 job("커리어 발전")을 해결한다. 프레이밍은 감정적 포장일 뿐이며 WTP의 근원인 job-to-be-done을 변경하지 않는다. 따라서 WTP 차이는 미미하거나 없어야 한다. Christensen(2016)의 JTBD에서 "functional, emotional, social dimensions of a job"을 인정하지만, 이것은 동일 job의 차원이지 다른 WTP 수준을 만들지 않는다.

**SDT 반론**: 자기결정이론(Deci & Ryan, 2000)에 따르면 "숨겨진 약점 발견" 프레이밍은 역량 욕구(competence need)를 위협한다. 역량 위협은 방어적 반응을 유발하여 WTP를 **감소**시킬 수 있다. 반면 "업무 효율화"는 역량 지원 프레이밍이므로 WTP를 유지하거나 증가시킨다. SDT 예측은 VALUE GAP과 **정반대 방향**이다.

**결정적 실험**: 동일 제품(예: AI 커리어 진단 도구)을 갭 공개 카피와 기능 효율 카피로 A/B 테스트. WTP를 BDM 경매로 측정. VALUE GAP이 맞으면 갭 공개 > 기능 효율. SDT가 맞으면 기능 효율 > 갭 공개. JTBD가 맞으면 차이 없음. 이 실험은 ₩500,000 이하 예산으로 N=100 피험자 온라인 실험 가능.

#### 분기점 2 — 그룹 vs 개인 코칭 WTP

**VALUE GAP 논리**: Social_Amplifier는 "기능적 갭이 중요한 타인에게 보이는 정도"다. 동종 업계 그룹 코칭에서는 자신의 갭이 peer에게 가시화되므로 Social_Amplifier가 상승한다. 그룹 설정은 사회적 비교(social comparison, Festinger 1954)를 촉발하여 갭 인식을 강화한다. 따라서 그룹 코칭의 WTP가 개인 코칭보다 높다.

**JTBD 반론**: 개인 코칭이 동일 job을 더 맞춤화되게 해결하므로 WTP가 더 높아야 한다. 그룹 코칭은 개인화 정도가 낮으므로 job 해결 품질이 떨어진다.

**SDT 반론**: 그룹 설정은 관계성(relatedness) 욕구를 충족하므로 WTP가 높을 수 있다. 하지만 SDT의 메커니즘(관계성 충족)과 VALUE GAP의 메커니즘(사회적 갭 가시화)은 다르다. 이 두 메커니즘을 분리하려면 그룹 구성원이 (A) 동종 업계 peer vs (B) 이질적 집단일 때를 비교한다. VALUE GAP은 (A)에서만 WTP 상승을 예측한다 (동종 peer만이 "중요한 타인"이므로). SDT는 (A)와 (B) 모두에서 WTP 상승을 예측한다 (관계성 충족은 집단 유형과 무관).

**결정적 실험**: 커리어 코칭 WTP를 3개 조건에서 비교: (1) 개인, (2) 동종 업계 5인 그룹, (3) 이질적 5인 그룹. VALUE GAP: (2) > (1) > (3) 또는 (2) > (3) ≈ (1). SDT: (2) ≈ (3) > (1). JTBD: (1) > (2) ≈ (3).

#### 분기점 3 — "당신은 충분합니다" 피드백 후 WTP 변화

이것은 VALUE GAP의 가장 반직관적인 예측이다.

**VALUE GAP 논리**: WTP = f(Gap_Intensity). 전문가가 "당신은 이미 충분합니다"라고 갭을 닫아주면 Gap_Intensity가 감소한다. 따라서 갭 해소 제품(자기계발, 코칭, 교육)의 WTP가 감소한다. 이것은 역설적이다: 좋은 피드백이 WTP를 감소시킨다.

**JTBD 반론**: job-to-be-done은 외부 피드백과 독립적이다. "나는 더 나은 전문가가 되고 싶다"는 job은 "당신은 충분합니다" 피드백으로 사라지지 않는다. 따라서 WTP 불변.

**SDT 반론**: 역량 욕구가 충족되었으므로 해당 영역에서의 소비 동기가 감소할 수 있다 (SDT는 욕구 충족 → 동기 감소를 예측하지 않음 — 오히려 욕구 충족 → 내재적 동기 증가). 하지만 역량 확인은 자기효능감을 증가시켜 더 높은 목표를 추구하게 할 수 있으므로, WTP가 불변이거나 오히려 증가.

**결정적 실험**: 커리어 진단 후 (A) "3개 영역에서 개선이 필요합니다" vs (B) "이미 상위 10%입니다" 피드백을 제공한 후, 커리어 코칭 서비스 WTP를 측정. VALUE GAP: (A) > (B). JTBD: (A) ≈ (B). SDT: (B) >= (A). 효과 크기가 결정적 — VALUE GAP이 맞으면 (A)-(B) 차이의 Cohen's d > 0.5.

#### 분기점 4 — 정체성 이동성에 따른 WTP 분화

**VALUE GAP 논리**: v2의 ICP 수정에서 "제외 기준 = 정체성 이동성(identity portability)"으로 교체했다. 전문 정체성이 고용 기관과 독립적으로 이동하는 사람(프리랜서, 공개 아웃풋이 있는 직장인, 연구자)이 정체성 갭에 더 민감하다. 따라서 정체성 이동성이 높은 사람이 동일 제품에 대해 더 높은 WTP를 보인다.

**JTBD 반론**: 정체성 이동성은 job-to-be-done의 긴급성과 무관하다. 동일 업무 과제를 가진 사람은 정체성 이동성과 무관하게 동일한 WTP를 가져야 한다.

**멘탈 어카운팅 반론**: 프리랜서는 업무 비용을 개인 멘탈 계좌에서 지출하지만, 직장인은 기업 비용 또는 복지 계좌에서 지출한다. WTP 차이는 정체성 이동성이 아닌 지불 주체의 차이로 설명 가능하다.

**결정적 실험**: 통제 변수로 (i) 소득 수준, (ii) 업무 유사성, (iii) 지불 주체(본인 부담으로 통일)를 동일화한 후, 정체성 이동성 고/저 집단의 WTP를 비교. VALUE GAP이 맞으면 이동성 고 > 저 (소득·업무·지불 주체 통제 후에도). 멘탈 어카운팅이 맞으면 지불 주체 통제 후 차이 소멸.

#### 분기점 5 — 공개 표시 조건에서의 WTP 변화

**VALUE GAP 논리**: Social_Amplifier = 기능적 갭이 중요한 타인에게 보이는 정도. 구매 결과가 LinkedIn에 표시되면 Social_Amplifier가 증가한다. L3+ 제품(정체성 위임 이상)에서 WTP가 상승한다. L1-L2에서는 Social_Position_Gap만 관련되므로 효과가 다를 수 있다.

**SDT 반론**: 외적 동기(external regulation)가 내재적 동기를 구축(crowd out)한다는 것이 SDT의 핵심 예측(cognitive evaluation theory, Deci 1971). LinkedIn 공개 표시는 외적 보상/압력이므로 자율성을 훼손하여 WTP가 **감소**한다. 특히 "자기 성장을 위해" 구매하려던 사람이 "남들이 볼 것이므로" 구매하게 되면 동기의 질(quality of motivation)이 하락한다.

**결정적 실험**: 동일 온라인 코스를 (A) 수료증이 LinkedIn에 자동 게시 vs (B) 비공개 수료 조건에서 WTP 비교. VALUE GAP: (A) > (B). SDT: (A) < (B). JTBD: (A) ≈ (B). 이 실험은 VALUE GAP과 SDT를 직접 대립시키는 핵심 실험이다.

#### 분기점 6 — 프레이밍: 자기계발 vs 업무 비용

**VALUE GAP 논리**: "자기계발" 프레이밍은 정체성 갭을 직접 환기시킨다 ("더 나은 내가 되기 위해"). "업무 비용" 프레이밍은 기능적 필요를 환기시킨다 ("업무 효율을 위해"). VALUE GAP에서 WTP의 근원은 정체성 갭이므로 자기계발 프레이밍이 더 높은 WTP를 생성한다.

**멘탈 어카운팅 반론**: Thaler(1985, 1999)의 멘탈 어카운팅 이론에서, "업무 비용" 멘탈 계좌는 일반적으로 "자기계발" 멘탈 계좌보다 예산이 크다 (기업 비용으로 인식하거나, 필수적 지출로 분류). 따라서 "업무 비용" 프레이밍이 더 높은 WTP를 생성한다. 이 예측은 VALUE GAP과 **정반대**다.

**결정적 실험**: 동일 제품(예: 데이터 분석 코스)을 (A) "당신의 커리어 정체성을 강화하세요" vs (B) "팀 생산성을 20% 높이세요"로 제시. VALUE GAP: (A) > (B). 멘탈 어카운팅: (B) > (A). JTBD: 차이 없음. 본인 부담 조건에서만 테스트 (기업 비용 개입 제거).

#### 분기점 7 — L4 vs L5 사용자의 사후 WTP

**VALUE GAP 논리**: L5 사용자는 "몰랐던 갭"이 공개되는 경험을 한다. 이 경험은 L4("알고 있던 갭 확인")보다 더 강렬한 갭 인식을 생성하며, 따라서 후속 갭 해소 제품에 대한 WTP가 더 높다. "Unknown unknown의 해소"가 "known unknown의 해소"보다 가치 있다는 것이 VALUE GAP의 가장 차별적인 예측이다.

**JTBD 반론**: L4와 L5 모두 동일한 job("커리어 개선")을 완료했다. 갭이 이미 알려져 있었든 새로 발견되었든 job completion은 동일하므로 재구매 WTP에 차이가 없다.

**SDT 반론**: L4 사용자는 역량감 확인("내가 알던 것이 맞았다")을 받으므로 만족도가 높다. L5 사용자는 역량감 위협("내가 모르던 것이 있었다")을 받으므로 만족도가 상대적으로 낮다. 따라서 L4의 재구매 WTP가 L5보다 높을 수 있다.

**결정적 실험**: 커리어 진단 서비스 사용 후 사용자를 (i) "이미 알고 있던 약점이 확인된" 집단(L4 경험)과 (ii) "몰랐던 약점이 발견된" 집단(L5 경험)으로 분류. 후속 코칭 서비스 WTP 비교. VALUE GAP: (ii) > (i). SDT: (i) > (ii). JTBD: 차이 없음.

## 5. 보호대 (Protective Belt)

Lakatos의 보호대는 "핵심을 보호하기 위해 수정 가능한 보조 가설들"이다. 반증 증거가 나타났을 때 핵심(HC-1~4)을 포기하기 전에 보호대를 먼저 수정한다. 하지만 보호대 수정에도 한계가 있다 — 보호대 수정이 **퇴행적(degenerative)**이면(즉, 새로운 예측을 하지 못하고 기존 데이터만 사후적으로 맞추면) 연구 프로그램 전체가 퇴행적이 된다.

### PB-1: Social_Amplifier의 구체적 구조

**현재 정의**: "기능적 갭이 중요한 타인에게 보이는 정도" — 신호 전달 계수.

**수정 가능 범위**: Social_Amplifier가 곱셈 구조인지, 덧셈 구조인지, 비선형 함수인지는 핵심이 아니라 보호대에 속한다. iter 7이 테스트하려 했던 "곱셈 vs 덧셈" 문제가 바로 이것이다. 곱셈이 반증되면 덧셈으로, 덧셈이 반증되면 임계값(threshold) 모형으로 수정할 수 있다.

**퇴행 방지 조건**: Social_Amplifier 구조 수정 시 반드시 **이전 모형이 설명하지 못했던 새로운 현상을 예측**해야 한다. 예: 곱셈에서 덧셈으로 수정한다면, "기능적 갭 = 0이지만 WTP > 0인 순수 사회적 구매(L1)를 설명할 수 있다"는 새로운 예측이 필요하다 (v2에서 이미 수행). 단순히 "곱셈이 안 맞으니 덧셈으로"는 퇴행적 수정이다.

### PB-2: Attainability 메커니즘

**현재 정의**: D(WTP) = [Gap_Intensity × Attainability] × [Social_Amplifier]. Attainability는 갭 해소가 달성 가능하다고 인지되는 정도.

**수정 가능 범위**: Attainability가 선형 조절변수(moderator)인지, U자형인지(너무 쉽거나 너무 어려우면 WTP 감소), 임계값 함수인지는 보호대에 속한다. 현재 이론은 Attainability를 선형 조절변수로 처리하지만, 경험적 데이터에 따라 비선형으로 수정할 수 있다.

**퇴행 방지 조건**: Attainability 함수 형태 수정 시, 수정된 모형이 원래 모형의 예측을 포함(subsume)하면서 추가 예측을 해야 한다. 예: U자형 Attainability 모형은 "극단적으로 쉬운 갭 해소(예: 1-click 솔루션)가 WTP를 감소시킨다"는 추가 예측을 해야 한다.

### PB-3: L-레벨 경계값

**현재 정의**: L1-L5의 5단계 분류.

**수정 가능 범위**: 5단계가 아닌 3단계, 7단계, 또는 연속체(continuum)로 수정할 수 있다. L-레벨의 수와 구체적 경계는 보호대에 속한다. 핵심은 "질적으로 구분되는 레벨이 존재하고 위계가 있다"는 것(HC-3)이지 "정확히 5개다"는 것이 아니다.

**퇴행 방지 조건**: 레벨 수 변경 시, 변경 전에는 설명하지 못했던 현상을 설명해야 한다. 예: L3와 L4 사이에 L3.5를 추가한다면, L3.5 고유의 WTP 패턴을 예측해야 한다. 단순히 "데이터에 맞추기 위해 분할"은 퇴행적.

### PB-4: Ethical_Coefficient의 시간 함수

**현재 정의**: Ethical_Coefficient ∈ (0, 1] — 평생 추출 가능 잉여의 할인 인자.

**수정 가능 범위**: 이 계수가 시간에 따라 어떻게 변화하는지(선형 감소, 지수 감소, 단계 함수)는 보호대에 속한다. 또한 Ethical_Coefficient의 입력 변수(무엇이 "윤리적"을 결정하는가)도 수정 가능하다.

**퇴행 방지 조건**: 시간 함수 수정 시, 수정된 모형이 특정 산업의 ARPU 궤적을 사전적으로 예측해야 한다. 사후적으로 "이 산업은 이런 Ethical_Coefficient 궤적을 가졌다"고 맞추는 것은 퇴행적.

### PB-5: 정체성 이동성의 구성요소

**현재 정의**: "전문 평판이 고용 기관과 독립적으로 이동하는 정도".

**수정 가능 범위**: 정체성 이동성을 구성하는 하위 차원(공개 아웃풋 양, 산업 간 이직 빈도, 개인 브랜드 강도 등)은 보호대에 속한다. 어떤 하위 차원이 가장 예측력이 높은지는 경험적 질문이다.

**퇴행 방지 조건**: 하위 차원 추가/제거 시 모형의 예측력(R² 또는 AUC)이 통계적으로 유의하게 증가해야 한다. 파라미터만 늘려서 과적합(overfitting)하는 것은 퇴행적 — 교차검증(cross-validation)으로 확인.

### 보호대 수정의 누적 한계

Lakatos가 경고한 것: 보호대 수정이 누적되면 "괴물 조정(monster-barring)"이 된다. VALUE GAP에 다음 한계를 설정한다:

1. **보호대 수정 횟수 제한**: 동일 반증 증거에 대해 보호대 수정은 최대 2회. 2회 수정 후에도 반증이 해소되지 않으면 핵심 명제(HC) 재검토.
2. **파라미터 팽창 제한**: 이론의 자유 파라미터 수가 현재(Gap_Intensity 2성분, Social_Amplifier 1, Attainability 1, Ethical_Coefficient 1 = 총 5) 대비 2배(10)를 초과하면 과적합 경고.
3. **진행적 문제 이동 요구**: 모든 보호대 수정은 수정 전에 설명하지 못했던 새로운 사실(novel fact)을 최소 1개 예측해야 한다. 이 조건을 충족하지 못하는 수정은 퇴행적이며 이론의 과학적 지위를 약화시킨다.

## 6. 이론의 생산성 기준

Lakatos의 "진행적 연구 프로그램(progressive research programme)"은 새로운 사실을 예측하는 프로그램이다. VALUE GAP이 경쟁 이론들이 하지 않는 독자적 예측(novel prediction)을 식별한다.

### NP-1: 갭 공개 마케팅의 기능 마케팅 대비 WTP 우위

**예측**: 고관여 정체성 인접 제품에서, 정체성 갭을 공개하는 마케팅 카피가 기능적 편익을 강조하는 카피보다 2배 이상 높은 전환율을 보인다.

**기존 이론으로 예측 불가능한 이유**: JTBD는 프레이밍 효과를 설명하지 않는다 (job-to-be-done은 프레이밍에 불변). 멘탈 어카운팅은 가격 프레이밍만 다루고 정체성 프레이밍을 다루지 않는다. SDT는 갭 공개 프레이밍이 역량 위협으로 오히려 부정적 효과를 예측한다.

**테스트 가능성**: A/B 카피 테스트로 직접 측정 가능. ₩200,000 예산, 2주 내 결과 확인 가능.

**이론적 함의**: 이 예측이 확인되면 VALUE GAP은 마케팅 실무에서 직접적 처방력을 갖게 된다. 부정되면 HC-2(갭 공개 = 판매)가 약화된다.

### NP-2: 정체성 이동성이 소득보다 강한 WTP 예측자

**예측**: 고관여 정체성 인접 구매에서, 정체성 이동성(identity portability)이 가처분 소득(disposable income)보다 WTP의 더 강한 예측자(higher beta coefficient in regression)다.

**기존 이론으로 예측 불가능한 이유**: 가격 이론은 소득이 WTP의 지배적 결정자라고 본다. JTBD는 job의 긴급성과 빈도가 WTP를 결정한다고 본다. 멘탈 어카운팅은 멘탈 계좌의 크기(=소득 함수)가 WTP를 제약한다고 본다. VALUE GAP만이 정체성 구조 변수가 경제적 변수보다 우월하다고 예측한다.

**테스트 가능성**: 회귀 분석 — DV: WTP, IV: 정체성 이동성 점수 + 가처분 소득 + 통제 변수. β(정체성 이동성) > β(가처분 소득)이면 VALUE GAP 지지.

**이론적 함의**: 이 예측이 확인되면 ICP 선정에서 소득 기반 타겟팅보다 정체성 이동성 기반 타겟팅이 우월하다는 실무적 함의가 도출된다.

### NP-3: L5 갭 공개 경험의 "가격 무감각" 창

**예측**: L5 갭 공개(미인식 갭이 처음 발견되는 순간)를 경험한 사용자는 공개 후 24-72시간 동안 가격 민감도가 현저히 감소하는 "가격 무감각 창(price insensitivity window)"을 보인다. 이 창은 L4(이미 아는 갭 확인) 경험자에게는 관찰되지 않는다.

**기존 이론으로 예측 불가능한 이유**: 멘탈 어카운팅은 시간에 따른 가격 민감도 변동을 예측하지 않는다 (멘탈 계좌는 단기적으로 안정적). JTBD는 job 인식 시점과 무관하게 WTP가 안정적이라고 본다. 손실 회피(Kahneman & Tversky, 1979)는 참조점 이동으로 단기 가격 무감각을 예측할 수 있으나, "미인식 갭 공개"라는 특정 트리거와 연결하지 않으며 L4/L5 차이를 예측하지 않는다.

**테스트 가능성**: 커리어 진단 도구 사용 후 (t=0, t=24h, t=72h, t=168h) 시점에서 후속 서비스 WTP를 반복 측정. L5 경험자와 L4 경험자의 WTP 시간 곡선을 비교. L5의 초기 스파이크 + 감쇠 패턴이 L4에서 관찰되지 않으면 VALUE GAP 고유 예측 확인.

**이론적 함의**: 이 예측이 확인되면 (1) L5 제품 설계 시 갭 공개 직후 구매 제안의 타이밍이 결정적이라는 실무적 함의, (2) VALUE GAP이 동적(dynamic) 이론으로 진화할 수 있는 경험적 기초가 마련된다.

### NP-4: 갭 해소 후 WTP 소멸과 새로운 갭 형성의 주기성

**예측**: VALUE GAP 기반 제품 사용 후 해당 갭의 WTP는 감소하지만, 갭 해소 과정에서 새로운 상위 갭이 인식되어 후속 제품의 WTP가 생성된다. 이것은 L2→L3→L4→L5 순서의 "갭 상승 캐스케이드(gap elevation cascade)"를 형성한다.

**기존 이론으로 예측 불가능한 이유**: JTBD는 job completion 후 만족을 예측한다 (새로운 job이 자동 생성되는 메커니즘이 없다). 멘탈 어카운팅은 지출 후 멘탈 계좌 감소를 예측한다. SDT는 욕구 충족 후 안녕감 증가를 예측한다. VALUE GAP만이 "갭 해소가 새로운 갭을 노출시킨다"는 동적 메커니즘을 제안한다.

**테스트 가능성**: L2 제품 사용자 코호트를 6개월 추적. 후속 구매 패턴이 L3→L4 방향으로 상승하는지 관찰. VALUE GAP이 맞으면 L2→L3 전환율이 L2→L2(동일 레벨 반복 구매)보다 높다.

**이론적 함의**: 이 예측이 확인되면 VALUE GAP은 고객 생애 가치(CLV) 모형의 기초가 될 수 있다. L2에서 시작한 고객이 L5까지 상승하는 경로를 설계하는 것이 제품 전략의 핵심이 된다.
