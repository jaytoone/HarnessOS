## 1. 구조적 중첩 (동의 지점)

| VALUE GAP | JTBD / ODI | 공통 메커니즘 |
|---|---|---|
| Gap_Intensity | Push from current situation | 현재 상태에 대한 불만족 측정 |
| Gap_Intensity × Attainability | Importance × Satisfaction gap (ODI) | 충족되지 않은 중요도 = 수요 신호 |
| L1-L2 (기능적 갭) | Functional job | 기능적 상태 전환 |
| Social_Amplifier | Social job | 타인에게 보이는 것 관련 |

두 프레임워크는 공통 관찰에서 파생 — Kahneman 참조점 의존 효용이 암묵적 근거.

**공통 예측**: 현재 상태 불만족 높음 + 더 나은 상태 비전 명확 = 전환 확률 최고

## 2. 실질적 충돌 (진짜 긴장)

### 분석 단위 차이
- **JTBD**: 제품 중심 — "어떤 작업이 필요한가?" (제품 = 답)
- **VALUE GAP**: 구매자 중심 — "어떤 정체성 위협을 닫는가?" (제품 = 부수적)

**실무적 함의**: JTBD는 드릴 구매(작업: 그림 걸기)를 설명한다. 동일한 "작업"을 하는 ₩30,000 책 vs ₩300,000 코칭 세션의 10배 WTP 차이는 설명하지 못한다.

### L5 (unknown-unknown) 문제

JTBD는 L5 WTP에 메커니즘이 없다. JTBD의 스위치 트리거 모델(push + pull + anxiety + habit)은 고객이 문제를 알고 있다고 가정한다. VALUE GAP L5는 갭 공개 자체가 제품 — "당신이 모른다는 것을 몰랐다"가 최고 WTP를 생성하는 이유를 JTBD는 설명 못 한다.

### 10배 WTP 현상

성격 진단 테스트 (작업: 자기 이해) vs 치료 세션 (작업: 자기 이해) — JTBD 정의상 동일 작업, 실제 WTP 5-20배 차이. JTBD는 이를 전환 비용과 감정적 작업으로 설명하려 하지만 메커니즘을 특정하지 못한다. VALUE GAP은 특정한다: Social_Amplifier × Attainability.

## 3. VALUE GAP이 JTBD를 확장하는 지점

### Ethical_Coefficient (빠짐 경계)
JTBD 등가물 없음. JTBD의 anxiety 사분면은 전환 비용을 포착하지, 도덕적 자아 개념 위협을 포착하지 않는다.

VALUE GAP의 계수는 포착한다: "이 갭을 이런 방식으로 닫으면 내가 원하지 않는 사람이 된다." → 고가 제안을 거부하는 고 WTP 고객 설명 가능. JTBD는 이를 anxiety나 습관으로 오진한다.

### Social_Amplifier (곱셈 메커니즘)
- JTBD Social Job: 정적 — "X로 보이고 싶다" (작업 카테고리)
- VALUE GAP Social_Amplifier: 동적, 곱셈 — 갭의 사회적 가시성이 WTP를 비선형적으로 증폭

**실무적 차이**: 순수 사적 기능 갭과 동일하지만 공개적으로 가시화된 갭은 VALUE GAP에서 다른 WTP를 예측한다. JTBD Social Job 프레임에서는 동일한 WTP를 예측한다.

## 4. 통합 프레임워크

```
Step 1 — JTBD: 작업 식별
  → Functional / Emotional / Social
  → 스위치 트리거: push + pull + anxiety + habit

Step 2 — VALUE GAP: WTP 보정
  → 작업을 L1-L5 계층에 매핑 (어떤 정체성 레이어를 건드리는가?)
  → 점수: Gap_Intensity × Attainability
  → Social_Amplifier 적용 (갭이 공개적으로 가시적인가?)
  → Ethical_Coefficient 적용 (닫는 것이 자아 개념을 위협하는가?)

Step 3 — 가격 신호
  → L1-L2 + 낮은 Amplifier = 범용 가격대
  → L3-L4 + 높은 Amplifier = 프리미엄 구간
  → L5 + 갭 공개 = 제품 = 10배 구간
```

**언제 JTBD 먼저**: 초기 제품 정의, 시장 세그멘테이션, 경쟁 치환 분석 — JTBD가 고객이 고려할 솔루션 카테고리를 알려준다.

**언제 VALUE GAP 먼저**: 가격 결정, 포지셔닝, 세일즈 대화 설계, 기능적으로 동일한 두 제품의 비정상적 WTP 차이 설명.

## 5. 최종 판정

**VALUE GAP은 JTBD의 재진술이 아닌 진짜 확장이다** — 단, 부분적으로.

확장이 실질적인 3개 영역:
1. L5 수요 (인식론적 자기 무지가 수요 상태)
2. Ethical_Coefficient (정체성 일관성이 불안과 구분되는 구매 장벽)
3. Social_Amplifier (WTP 곱셈 메커니즘, 작업 카테고리가 아님)

### VALUE GAP이 JTBD보다 약한 지점 (솔직한 평가)

| 약점 | 설명 |
|---|---|
| 구매 타이밍 | JTBD 스위치 트리거 모델이 더 발달. VALUE GAP에 전환 트리거 이론 없음 |
| 실무 도구 | JTBD: 20년+ 인터뷰 프로토콜, 실패 모드 문서. VALUE GAP: 측정 도구 미검증 |
| 저관여 구매 | JTBD는 범용. VALUE GAP 정체성 갭 프레임은 고관여/정체성 인접 구매에 암묵적으로 스코핑됨 |

### 미검증 항목
- [UNCERTAIN] Ethical_Coefficient의 JTBD anxiety와의 경험적 분리 가능성 — 설문 도구 + 판별 타당도 검증 필요
- [UNCERTAIN] Social_Amplifier 효과의 곱셈 vs 덧셈 여부 — 가시성 변동 통제 현장 실험 필요
- [UNCERTAIN] L5 WTP 프리미엄 크기 — "10배"는 예시, 실제 도메인별 차이 존재

---

**요약 한 줄**: JTBD가 더 완전한 수요 진단 시스템. VALUE GAP이 정체성 인접 제품에서 더 정밀한 WTP 예측 도구 — 정확히 실무자가 정밀도를 가장 필요로 하는 고마진 시장에서.
