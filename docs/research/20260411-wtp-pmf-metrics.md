## 1. VALUE GAP이 예측하는 PMF 서명

표준 PMF 정의("사용자가 제품 없이는 못 살겠다고 느끼는 상태")는 Career Mirror에 적용하면 위험하다. "못 살겠다"는 감정은 건강한 가치 인식과 의존성(빠짐)을 구분하지 못한다. VALUE GAP 이론은 정체성 갭 제품의 PMF를 **4가지 행동 서명**으로 예측한다.

### P1: 갭 축소 메트릭 (Gap-Closure Metric)

**이론적 근거**: D(WTP)_sustainable = D(WTP)_instantaneous x Ethical_Coefficient에서, Ethical_Coefficient가 높은 제품은 사용자의 실질 갭을 닫는다. PMF는 갭이 실제로 닫히고 있다는 증거가 있을 때만 존재한다.

**예측되는 행동**: 3개월 사용 후 사용자의 자가 보고 갭 점수가 온보딩 시점 대비 **최소 20% 감소**한다. 단, 감소가 멈추지 않아야 한다 -- 감소가 정체되면 제품이 갭을 닫는 것이 아니라 갭 인식만 무디게 한 것이다.

**측정 방법**: 온보딩 시 5필드 폼에서 측정한 발산점 3개 각각에 대해 "이 갭이 얼마나 크다고 느끼는가?" (1-10 리커트). 이를 M1, M3, M6에 재측정. 코호트 중앙값이 20% 이상 감소하면 P1 충족.

**PMF가 아닌 것**: 갭 점수가 감소하지만 사용자가 제품 밖에서 갭을 닫는 행동을 하지 않는 경우. 이는 "인식 변화"일 뿐 "역량 변화"가 아니다.

### P2: 정체성 이동성 증가 (Identity Portability Increase)

**이론적 근거**: v2 이론의 핵심 수정 -- ICP 기준이 고용 형태가 아닌 **정체성 이동성**이다. Career Mirror가 PMF를 달성했다면, 사용자의 정체성 이동성이 제품 사용 전보다 증가해야 한다. 즉, 외부에서 인식되는 전문 정체성이 강화되어야 한다.

**예측되는 행동**: 사용자가 Career Mirror 사용 후 **공개 아웃풋을 더 많이 생산**한다. 블로그 게시물, 발표, 프로젝트 공개, 포트폴리오 업데이트 등. 발산점을 인식한 사용자가 그 갭을 닫기 위해 외부 행동을 시작하는 것이 정상이다.

**측정 방법**: M3 서베이에서 "지난 3개월간 외부에 공개한 전문 아웃풋이 있나요?" 질문. 사용 전 3개월 vs 사용 후 3개월 비교. **공개 아웃풋 빈도가 1.5배 이상 증가**하면 P2 충족.

**PMF가 아닌 것**: 아웃풋이 증가하지만 모두 Career Mirror 내부에서만 발생하는 경우 (예: 제품 내 코멘트, 분석 요청만 증가). 이는 제품 의존이지 정체성 이동성 증가가 아니다.

### P3: Social Amplifier 자발적 활성화

**이론적 근거**: v2 이론에서 Social_Amplifier는 "기능적 갭이 중요한 타인에게 보이는 정도"를 조절하는 신호 전달 계수다. PMF 상태에서는 사용자가 **자발적으로** 갭 경험을 전문 네트워크에 공유한다. 강제된 공유(공유해야 기능 잠금 해제)가 아니라, 경험 자체가 공유할 만하다고 느끼는 자발적 공유다.

**예측되는 행동**: Free tier의 익명 공유 기능 외에, 유료 사용자가 **비익명적으로** 갭 인사이트를 동료에게 추천한다. "나 이거 해봤는데 네가 해보면 좋을 것 같아"라는 개인화된 추천이 발생한다.

**측정 방법**: 
- 공유 링크 생성 후 실제 클릭까지 전환하는 비율 (CLG 퍼널)
- 유료 사용자 중 "추천 코드"를 자발적으로 공유한 비율
- **유료 사용자의 15% 이상이 M3까지 최소 1회 자발적 공유**하면 P3 충족

**PMF가 아닌 것**: 인센티브(할인, 무료 월) 기반 공유만 발생하는 경우. 인센티브 공유는 Social_Amplifier 활성화가 아니라 가격 민감성의 표현이다.

### P4: "제품 없는 제품" 테스트 (Product-Without-Product Test)

**이론적 근거**: iter 13의 빠짐 감사 프레임워크에서 가장 중요한 지표 -- AU-1 독립 실행 테스트. 건강한 PMF는 사용자가 **제품 없이도 갭 닫기를 계속할 수 있는 역량**을 갖추게 된 상태다. 역설적이지만, iter 13 원칙 4(역설적 역량 이전)에 의해 이 상태가 오히려 재구매를 높인다.

**예측되는 행동**: 6개월 사용 후, 제품을 1개월 중단해도 사용자가 갭 닫기 행동을 지속한다. 제품이 프레임워크를 이전했기 때문이다. 그리고 중단 후 복귀하는 사용자는 "새로운 프론티어"를 보기 위해 돌아온다 (기존 갭 미해결 불안이 아니라).

**측정 방법**: M6 코호트에서 자발적 이탈자(해지 후 자연 이탈) 중 3개월 후 서베이. "제품 없이 갭 관련 활동을 계속하고 있나요?" 응답의 **60% 이상이 YES**이면 P4 충족.

**PMF가 아닌 것**: 해지자 전원이 "제품이 그리워요"라고 답하는 경우. 이는 의존성이지 역량 이전이 아니다.

### P1-P4 복합 판정

```
PMF 충족 조건:
  P1 (갭 축소) AND P2 (정체성 이동성) = 최소 PMF
  P1 AND P2 AND P3 (Social Amplifier) = Strong PMF
  P1 AND P2 AND P3 AND P4 (제품 없는 제품) = Full PMF (Healthy)

PMF 미충족:
  P1 미충족 = 제품이 갭을 닫지 못함 → 핵심 가치 부재 → 피벗
  P1 충족 + P2 미충족 = 갭 인식은 변했으나 행동 변화 없음 → 제품 설계 수정
  P1 + P2 충족 + P3 미충족 = 개인 가치는 있으나 확산 불가 → CLG 재설계
  P1 + P2 + P3 충족 + P4 미충족 = 빠짐 위험 → iter 13 감사 즉시 실행
```

## 2. 표준 PMF 지표 vs VALUE GAP PMF 지표

| 지표 | 표준 SaaS | VALUE GAP 예측 | Career Mirror 구현 방법 |
|---|---|---|---|
| **핵심 질문** | "매우 실망" 40%+ (Sean Ellis test) | "이 제품이 보여준 갭을 다른 방법으로 볼 수 있었나요?" NO 70%+ | M3 서베이에 "갭 비대체성" 질문 추가. "매우 실망"보다 "대체 불가"가 정체성 갭 제품의 정확한 측정. 이유: 사용자가 "실망"이라 답하면 의존인지 가치인지 구분 불가. "다른 방법으로 볼 수 없다"는 기능적 독자성을 측정 |
| **재구매/갱신** | M3 retention 40%+ | M3 retention 35%+ AND 갱신 동기가 "새 프론티어" > "기존 갭 불안" | 갱신 시 1-질문 서베이 (iter 13 GA-3): "왜 갱신하셨나요?" 오픈 응답 → 코딩. VALUE GAP은 retention 수치보다 **동기 구성**이 중요. 40% retention이어도 동기가 불안이면 빠짐이지 PMF가 아님 |
| **NPS** | 50+ | NPS 40+ AND 추천 이유에 "갭/인사이트/발견" 키워드 포함 60%+ | NPS 서베이에 "추천 이유" 오픈 질문 필수 추가. VALUE GAP은 NPS 절대값보다 **추천 서사의 질**을 본다. "편리하다"(L2)와 "내가 몰랐던 걸 보여줬다"(L4-L5)는 같은 NPS 10이어도 PMF 서명이 다름 |
| **바이럴 계수** | k > 0.3 | k > 0.2 AND 공유 경로가 "전문 네트워크"(카카오 직장인 그룹, 링크드인, 동료 DM) > "일반 소셜"(인스타, 트위터) | 공유 링크에 UTM 파라미터로 채널 추적. VALUE GAP은 바이럴 계수 절대값보다 **공유 채널의 전문성 밀도**를 본다. 일반 소셜에서 k=0.5여도 전문 네트워크에서 k=0.1이면 L4-L5 PMF 미달 |
| **활성화율** | D7 30%+ | D7 활성화 = "갭 시각화 확인 + 블러 호버" 50%+ (5필드 입력 완료자 기준) | PQL 트리플 시그널의 처음 2개 (gap_visualization_rendered + divergence_point_hover)가 D7 내 발생. VALUE GAP은 "앱 열기"가 아니라 **"갭을 눈으로 본 순간"**이 활성화. 단순 로그인 활성화율은 무의미 |
| **시간 대비 가치** | DAU/MAU > 0.3 | 월 세션 수 < 4 AND 세션당 핵심 행동 완료율 > 80% | 세션 로그에서 "핵심 행동"(갭 확인, 진행 업데이트, 피어 비교) 완료율 추적. VALUE GAP은 **저빈도 고강도** 사용이 PMF 서명. 매일 접속하는 건 빠짐 신호일 수 있음. Career Mirror는 월 2-3회, 각 세션에서 깊은 인사이트를 얻는 패턴이 건강 |

### 왜 표준 지표를 그대로 쓰면 안 되는가

표준 SaaS PMF 지표는 **사용 빈도와 감정적 집착**을 PMF의 대리 변수로 사용한다. 이것이 작동하는 이유는 대부분의 SaaS가 L2(Commodity Delegation) 제품이기 때문이다 -- 기능적 작업 아웃소싱이므로 빈도가 가치와 비례한다.

Career Mirror는 L4-L5 정체성 갭 제품이다. 이 제품의 가치는 **인식의 전환 순간**(갭 공개)에 집중되며, 이 순간은 빈도가 아니라 강도로 측정된다. 매일 갭을 확인하는 사용자는 불안에 빠진 것이고, 월 1회 갭을 확인하고 나머지 시간에 갭을 닫는 행동을 하는 사용자가 PMF 상태다.

따라서 Career Mirror의 PMF 측정은 모든 표준 지표에 **동기/행동 질적 필터**를 추가해야 한다. 양적 임계값만으로는 PMF와 빠짐을 구분할 수 없다.

## 3. Leading Indicators (선행 지표) -- 빌드 전 측정 가능

### L0 지표 (인터뷰 단계)

시드 코호트 60명 인터뷰에서 PMF를 예측하는 구체적 응답 패턴.

**L0-1: 갭 자각 반응 강도**

인터뷰에서 "당신의 커리어에서 지금 가장 큰 갭은 무엇이라고 생각하나요?"에 대한 응답 분류:

| 응답 패턴 | L-Level | PMF 예측력 |
|---|---|---|
| "글쎄요, 잘 모르겠는데..." (5초 이상 침묵 후 답변) | L5 후보 | **높음** -- unknown-unknown 상태 확인 |
| "네, 저는 X가 부족한 건 아는데 어떻게 해야 할지..." | L4 후보 | **높음** -- known-unknown, 제품 핵심 타겟 |
| "아, 네 저 그거요. 이미 강의도 듣고 있어요" | L3 이하 | **낮음** -- 기존 대안으로 충분히 대응 중 |
| "저는 갭이 없다고 생각해요" | 비타겟 | **매우 낮음** -- 갭 부정은 PMF 저항 |

**PMF 선행 신호**: 인터뷰 대상자의 **40% 이상이 L4-L5 응답 패턴**을 보이면, 시드 코호트의 ICP 정합도가 높다 → PMF 가능성 상승.

**L0-2: 지불 반응의 질적 구조**

가격 질문("이 서비스에 월 ₩49,000을 내실 의향이 있나요?")에 대한 응답에서 PMF를 예측하는 것은 **금액이 아니라 반응 구조**다:

| 반응 구조 | PMF 예측 |
|---|---|
| "그 돈이면... (계산 시작) ... 강의 두 개 값인데..." → 비교 쇼핑 | **낮음** -- L2 사고, 기능 대체재와 비교 |
| "내 갭을 정확히 보여준다면 그 정도는..." → 조건부 수용 | **중간** -- L3-L4, 가치 조건 확인 |
| "그거보다 중요한 건, 이게 정말 되는 거냐?" → 효능 질문 | **높음** -- L4-L5, 가격이 아닌 작동 여부가 관건 |
| "비싸네요" (즉각 가격 저항) | **낮음** -- Gap_Intensity 부족 |

**PMF 선행 신호**: "효능 질문" 반응이 **30% 이상**이면, ICP의 Gap_Intensity가 가격을 압도 → PMF 가능성 높음.

**L0-3: 갭 공개 프로토타입 반응**

종이 프로토타입 또는 피그마 목업으로 "당신의 궤적 vs 목표 코호트 궤적" 시각화를 보여준 후:

| 반응 | PMF 예측 |
|---|---|
| 화면을 오래 응시하며 발산점을 손가락으로 짚음 | **매우 높음** -- 갭 공개 순간이 실제로 발생 |
| "아... 여기서 갈라지는군요" (자기 해석 시작) | **높음** -- 메타-인사이트 활성화 |
| "이 데이터가 정확한 건가요?" (방법론 질문) | **중간** -- 관심은 있으나 신뢰 형성 필요 |
| "그래서요? 이걸로 뭘 하라는 건가요?" (무관심) | **낮음** -- 갭이 정체성과 무관 |

**PMF 선행 신호**: "응시 + 자기 해석" 반응이 **50% 이상**이면, 제품의 핵심 경험(갭 시각화)이 작동 → PMF 기반 확보.

### L1 지표 (MVP 출시 1주차)

론칭 첫 주에 측정해야 하는 행동 지표. 허영 지표(가입 수, 페이지뷰)를 배제하고 갭 활성화 행동만 추적한다.

**L1-1: 갭 시각화 완주율**

- **정의**: 5필드 입력 시작 → 갭 시각화 화면 도달까지 완료한 비율
- **임계값**: **65% 이상** (5필드가 3분이므로 이탈률 35% 이하가 정상)
- **PMF 신호 이유**: 5필드 입력은 마찰이 있다. 이 마찰을 넘는 사용자는 Gap_Intensity가 충분히 높다는 증거
- **경고 수준**: 50% 미만이면 → 5필드 폼 자체가 문제이거나 유입 채널의 ICP 정합도가 낮음

**L1-2: 발산점 호버 깊이**

- **정의**: 갭 시각화 도달 후, 블러된 발산점 상세를 호버/탭한 횟수 (사용자당)
- **임계값**: **평균 2.0회 이상** (발산점 3개 중 2개 이상 탐색)
- **PMF 신호 이유**: 단순 호기심이 아니라 "내 갭이 어디인지 알고 싶다"는 Gap_Intensity 표현. 1개만 보고 떠나면 갭 관여도 부족
- **경고 수준**: 평균 1.0 미만이면 → 갭 시각화의 시각적 설득력이 부족하거나 발산점 라벨이 모호

**L1-3: D1 재방문율 (갭 재확인)**

- **정의**: 갭 시각화를 본 사용자 중 24시간 이내 재방문한 비율
- **임계값**: **20% 이상**
- **PMF 신호 이유**: D1 재방문은 "갭이 머릿속에 남아 있다"는 증거. 정체성 갭이 활성화되면 "정말 내가 저기서 갈라졌나?" 하고 다시 확인하고 싶은 충동이 발생한다. 이것은 일반 SaaS의 D1 retention과 질적으로 다르다 -- 기능 재사용이 아니라 인식 재확인
- **경고 수준**: 10% 미만이면 → 갭 공개 순간의 정서적 강도가 부족

**L1-4: 익명 공유 전환율**

- **정의**: Free tier의 "익명으로 공유하면 발산점 상세 1개 잠금 해제" 기능 사용 비율
- **임계값**: **12% 이상** (갭 시각화 도달자 기준)
- **PMF 신호 이유**: 공유는 두 가지를 동시에 증명한다. (1) 사용자가 발산점 상세를 볼 가치가 있다고 판단 (Gap_Intensity), (2) 공유해도 괜찮다고 판단 (Social_Amplifier 활성화 잠재력)
- **경고 수준**: 5% 미만이면 → 잠금 해제 인센티브가 공유 심리적 비용을 못 넘기거나, 갭 자체에 충분한 관심이 없음

### L2 지표 (시드 코호트 4주차)

1개월 사용 후, PMF 방향을 판단하는 결정적 지표. 여기서 가속/피벗을 결정한다.

**L2-1: PQL 트리플 시그널 전환율**

- **정의**: (갭 시각화 확인 + 블러 호버 + 7일 내 재방문) → 유료 전환까지 도달한 비율
- **임계값**: **Free → Core 8% 이상** (iter 15 기본 시나리오 기준)
- **PMF 신호 이유**: 트리플 시그널은 Gap_Intensity, Attainability, 지속 관심을 모두 통과한 사용자. 이 사용자의 유료 전환율이 높으면 제품의 핵심 루프가 작동
- **가속 신호**: 12% 이상이면 → 기본 시나리오 초과, CLG 채널 확대 투자
- **피벗 신호**: 5% 미만이면 → 갭 공개가 유료 가치로 전환되지 않음. 가격 or 유료 gate 재설계

**L2-2: Core 사용자 갭 닫기 착수율**

- **정의**: Core 가입 후 30일 내, 발산점 1개 이상에 대해 "닫기 행동"을 시작한 비율 (자가 신고 진행 업데이트 or 피어 코호트 매칭 요청)
- **임계값**: **45% 이상**
- **PMF 신호 이유**: 유료 전환만으로는 PMF가 아니다. 전환 후 실제로 갭을 닫기 위한 행동을 시작해야 제품이 가치를 전달하고 있는 것. 전환했지만 아무것도 안 하는 사용자는 "충동 구매 → 후회 해지" 경로
- **가속 신호**: 60% 이상이면 → 제품의 Attainability 설계가 성공
- **피벗 신호**: 30% 미만이면 → 갭은 보여줬지만 닫는 경로가 불명확. 인과 분석 콘텐츠 또는 피어 매칭 품질 문제

**L2-3: Week 4 갱신 의향**

- **정의**: Core 가입 4주차에 "다음 달도 계속 사용하시겠습니까?" 질문의 긍정 응답 비율
- **임계값**: **70% 이상** (4주는 첫 갱신 시점이므로 이 시점의 의향이 M3 retention의 선행 지표)
- **PMF 신호 이유**: 갱신 의향 질문에 **이유**도 함께 수집. "새로운 갭을 보고 싶다" = 건강한 PMF. "아직 다 안 봤다" = 정보 소비 패턴 (보통). "끊으면 불안하다" = 빠짐 경고
- **피벗 신호**: 50% 미만이면 → 4주 내 핵심 가치 전달 실패. 온보딩 퍼널 or 핵심 경험 재설계

**L2-4: 자발적 피드백 발생율**

- **정의**: 4주 내 사용자가 자발적으로 피드백(이메일, 인앱 피드백, 카톡 메시지 등)을 보낸 비율
- **임계값**: **8% 이상** (시드 코호트 60명 중 5명 이상)
- **PMF 신호 이유**: 자발적 피드백은 "이 제품이 나에게 중요하다"는 최강의 신호. 피드백 내용이 "이 기능 추가해주세요"(기능 요청)보다 "이거 보고 깨달은 게 있는데요"(인사이트 공유)이면 L4-L5 PMF 서명
- **가속 신호**: 15% 이상 + 인사이트 공유 비율 과반 → Strong PMF 조기 신호

## 4. Lagging Indicators (후행 지표) -- PMF 확인

### Core PMF Gate: 건강한 M3 유지율

**정의**: 가입 3개월 후에도 활성 사용 중인 비율 AND 갱신 동기가 "새 프론티어 > 불안/습관"인 비율의 복합 지표.

**공식**:
```
Core_PMF = M3_Retention × Frontier_Motivation_Ratio

M3_Retention = (M3 활성 유저) / (M0 가입 유저)
Frontier_Motivation_Ratio = ("새로운 갭/프론티어를 보고 싶다" 응답) / (전체 갱신자 응답)
```

**임계값**:
```
Core_PMF >= 0.25 → PMF 달성
  예: M3 Retention 40% × Frontier Ratio 65% = 0.26 ✓
  예: M3 Retention 50% × Frontier Ratio 40% = 0.20 ✗ (높은 리텐션이지만 동기가 불건강)

Core_PMF < 0.15 → PMF 미달, 재설계 필요
Core_PMF 0.15-0.25 → 부분 PMF, 특정 세그먼트에서만 작동 (세그먼트 분석 필요)
```

**왜 이 지표가 가장 중요한가**: M3 Retention만으로는 빠짐과 PMF를 구분할 수 없다. 이 복합 지표는 "남아 있는 사람이 건강한 이유로 남아 있는지"를 검증한다. VALUE GAP 이론의 핵심 예측 -- D(WTP)_sustainable = D(WTP)_instantaneous x Ethical_Coefficient -- 을 직접 측정하는 것이다.

### Extended PMF Confirmation (3개 후행 지표)

**Lag-1: 코호트 갭 축소 실증 (M6)**

- **정의**: 6개월 사용 코호트의 온보딩 시점 갭 점수 vs M6 갭 점수 비교
- **임계값**: 코호트 중앙값 **30% 이상 감소**
- **확인하는 것**: 제품이 실제로 갭을 닫고 있는지. P1의 장기 버전
- **M3의 20% 감소가 M6에 30%로 확대**되면 갭 닫기 가속 = 프론티어 확장 원칙이 작동하는 증거

**Lag-2: 이탈자 성공률 (M6 이탈 후 M9 서베이)**

- **정의**: iter 13 GA-2 "이탈자 성공률". 제품을 떠난 사용자 중 원래 목표를 달성한 비율
- **임계값**: **35% 이상** (자연 이탈자, 해지 사유 "목표 달성/졸업" 기준)
- **확인하는 것**: 역량 이전의 실증. 제품이 P4(제품 없는 제품)를 실제로 달성했는지
- **이탈자 성공률이 높다** = Ethical_Coefficient가 높다 = D(WTP)_sustainable이 건강하다 = 재가입/추천 엔진이 작동

**Lag-3: CLG 자연 성장률 (M6)**

- **정의**: 유료 마케팅 없이 CLG(Community-Led Growth) 채널만으로 유입되는 Free 사용자의 월간 성장률
- **임계값**: **월 15% 이상 자연 성장**
- **확인하는 것**: Social_Amplifier가 지속적으로 작동하는지. P3의 장기 버전
- **자연 성장률 > 유료 유입 성장률**이면 → PMF의 가장 강한 확인. 제품 자체가 마케팅이 되는 상태

## 5. Anti-PMF 신호 (피벗 트리거)

PMF를 추구하는 과정에서 "이건 PMF가 아니다"를 빠르게 인식하는 것이 PMF를 달성하는 것만큼 중요하다. 다음 3가지 시나리오는 각각 다른 대응을 요구한다.

### Anti-PMF 시나리오 1: 갭 무관심 (Gap Indifference)

**신호**:
- L0-3 갭 프로토타입 반응에서 "무관심" 50% 이상
- L1-1 갭 시각화 완주율 50% 미만
- L1-2 발산점 호버 평균 1.0 미만

**진단**: 타겟 사용자가 갭을 정체성 위협으로 인식하지 않는다. Gap_Intensity가 이론적 예측보다 낮다.

**이론적 의미**: VALUE GAP v2의 ICP 기준(정체성 이동성)이 잘못되었거나, Career Mirror의 갭 시각화가 갭을 충분히 드라마틱하게 보여주지 못한다. 이론 자체가 아닌 **제품-이론 매핑**이 실패했을 가능성.

**대응**:
1. ICP 재검증: 시드 코호트의 정체성 이동성을 재측정. 실제로 외부 가시성이 있는 전문직인지 확인
2. 갭 시각화 재설계: 발산점을 더 개인화된 방식으로 표현 (추상적 그래프 → 구체적 시나리오)
3. **4주 내 개선 없으면**: ICP를 L4-L5에서 L3으로 하향 조정. 가격 체계 전면 재설계

### Anti-PMF 시나리오 2: 전환 단절 (Conversion Disconnect)

**신호**:
- L1 지표는 모두 건강 (갭 시각화 완주 65%+, 호버 2.0+, D1 재방문 20%+)
- 그러나 L2-1 PQL → 유료 전환율 5% 미만
- Free에서 머물며 유료로 넘어가지 않음

**진단**: 갭 공개 순간은 작동하지만, 유료 gate 뒤의 가치(인과 분석, 닫기 벤치마크, 피어 매칭)가 갭 닫기에 필수적이라는 확신을 주지 못한다. Attainability 인식 실패.

**이론적 의미**: D(WTP) = [Gap_Intensity x Attainability] x Social_Amplifier에서, Gap_Intensity는 확인되었지만 **Attainability가 0에 가까운 상태**. 사용자가 "갭은 보이지만 이 제품으로 닫을 수 있을지 모르겠다"고 느끼는 것.

**대응**:
1. 유료 gate 콘텐츠 미리보기 강화: 블러를 부분 해제하여 인과 분석의 맛보기 제공
2. 시드 코호트 성공 사례 1개를 Free tier에 노출 ("이 사람은 이 발산점을 3개월 만에 닫았습니다")
3. **4주 내 전환율 8% 미달 시**: 가격 인하 실험 (₩24,900 → ₩14,900) + Free tier 가치 확대 동시 테스트

### Anti-PMF 시나리오 3: 의존성 리텐션 (Addiction Retention)

**신호**:
- M3 Retention 50%+ (표면적으로 건강)
- 그러나 갱신 동기에서 "불안/습관" > "새 프론티어" (Frontier_Motivation_Ratio < 0.4)
- iter 13 AU-1 독립 실행 테스트에서 평균 3.5 미만
- 일일 접속 빈도가 월 10회 이상 (과도한 빈도)

**진단**: 리텐션이 높지만 건강하지 않다. 사용자가 갭을 닫는 것이 아니라 갭을 반복 확인하며 불안을 관리하고 있다. iter 13의 빠짐 조건 1(갭 재생산) + 조건 4(자율성 인식 왜곡) 충족 가능성.

**이론적 의미**: D(WTP)_instantaneous는 높지만 Ethical_Coefficient가 예상보다 낮다. 제품이 의도치 않게 갭 불안을 유지하는 메커니즘을 작동시키고 있다. 이것은 **이론 자체의 falsification 후보** -- VALUE GAP이 예측하지 못한 "건강한 설계가 의도치 않게 의존을 유발하는 경로"가 존재할 수 있다.

**대응**:
1. 즉시 iter 13 빠짐 감사 체크리스트 13개 항목 전체 실행
2. 과빈도 사용자에게 "이번 주는 제품을 쉬고, 지난주 인사이트를 직접 적용해보세요" 넛지 발송
3. 갭 시각화의 "비교" 프레이밍을 "진행" 프레이밍으로 교체 (타인과의 비교 → 과거 나와의 비교)
4. **6주 내 Frontier_Motivation_Ratio가 0.5를 넘지 못하면**: 핵심 루프 재설계 -- 월간 갭 재분석 빈도를 줄이고, 갭 닫기 행동 지원 기능을 강화

### Anti-PMF → 이론 수정 연결

iter 11의 falsification 기준과의 연결:

| Anti-PMF 시나리오 | 이론 수정 필요 여부 |
|---|---|
| 갭 무관심 | ICP 정체성 이동성 기준 수정 필요 가능 (v2 수정 3 재검토) |
| 전환 단절 | 이론 수정 불필요 (Attainability 변수가 이미 설명). 제품 설계 문제 |
| 의존성 리텐션 | **이론 수정 후보**: Ethical_Coefficient가 설계 의도와 무관하게 하락하는 메커니즘 존재 가능 → v3 검토 |

## 6. 빠짐 x PMF 교차 지표

### 문제 정의

높은 engagement + 높은 retention은 PMF의 통상적 증거다. 그러나 정체성 갭 제품에서는 높은 engagement가 **빠짐(의존성)**일 수 있다. iter 13에서 정의한 빠짐의 4가지 조건(갭 재생산, 대안 차단, 인출 비용 증가, 자율성 인식 왜곡)은 모두 높은 engagement와 양립한다.

따라서 Career Mirror에는 "높은 engagement AND 높아지는 사용자 역량"을 동시에 확인하는 복합 지표가 필요하다.

### Healthy PMF Index (HPMFI) 공식

```
HPMFI = Engagement_Score × Capability_Transfer_Score × (1 - Dependency_Score)

각 점수의 범위: 0.0 - 1.0
HPMFI 범위: 0.0 - 1.0
```

**Engagement_Score (ES) 산출**:
```
ES = min(1.0, (M3_Retention / 0.40))

M3_Retention >= 40% → ES = 1.0
M3_Retention = 20% → ES = 0.5
M3_Retention = 0%  → ES = 0.0
```

**Capability_Transfer_Score (CTS) 산출**:
```
CTS = (Gap_Reduction_Pct / 30%) × 0.5 + (Public_Output_Increase / 1.5x) × 0.3 + (Independent_Execution_Score / 3.5) × 0.2

Gap_Reduction_Pct = 온보딩 대비 갭 점수 감소 비율 (P1)
Public_Output_Increase = 공개 아웃풋 빈도 증가 배율 (P2)
Independent_Execution_Score = 독립 실행 자신감 리커트 평균 (P4, iter 13 AU-1)
각 항은 1.0에서 cap
```

**Dependency_Score (DS) 산출**:
```
DS = (Anxiety_Motivation_Ratio × 0.4) + (Excess_Frequency_Flag × 0.3) + (Gap_Stagnation_Flag × 0.3)

Anxiety_Motivation_Ratio = 갱신 동기 중 "불안/습관" 비율
Excess_Frequency_Flag = 월 세션 10회 초과 시 1.0, 4-10회 시 0.0, 4회 미만 시 0.0
Gap_Stagnation_Flag = M3 갭 점수가 M1 대비 10% 미만 감소 시 1.0, 그 외 0.0
```

### HPMFI 판정 기준

| HPMFI | 판정 | 의미 |
|---|---|---|
| **0.50 이상** | Healthy PMF | 높은 engagement + 높은 역량 이전 + 낮은 의존 |
| **0.30 - 0.49** | Partial PMF | engagement는 있으나 역량 이전 또는 의존 중 하나에 문제 |
| **0.15 - 0.29** | At Risk | engagement가 의존에 의해 유지될 가능성 |
| **0.15 미만** | No PMF | engagement 부족 또는 완전한 의존 |

### HPMFI 해석 예시

**예시 1: 건강한 PMF**
```
ES = 1.0 (M3 Retention 45%)
CTS = 0.7 (갭 25% 감소, 아웃풋 1.3x 증가, 독립 실행 3.2)
DS = 0.15 (불안 동기 10%, 과빈도 없음, 갭 감소 중)
HPMFI = 1.0 × 0.7 × (1 - 0.15) = 0.595 → Healthy PMF
```

**예시 2: 의존성 리텐션 (높은 retention, 낮은 HPMFI)**
```
ES = 1.0 (M3 Retention 55%)
CTS = 0.3 (갭 8% 감소, 아웃풋 변화 없음, 독립 실행 2.5)
DS = 0.65 (불안 동기 50%, 과빈도, 갭 정체)
HPMFI = 1.0 × 0.3 × (1 - 0.65) = 0.105 → No PMF (높은 retention에도 불구하고!)
```

**예시 3: 저빈도 건강 사용**
```
ES = 0.75 (M3 Retention 30%)
CTS = 0.85 (갭 35% 감소, 아웃풋 2x 증가, 독립 실행 4.0)
DS = 0.05 (불안 동기 5%, 저빈도, 갭 감소 중)
HPMFI = 0.75 × 0.85 × (1 - 0.05) = 0.606 → Healthy PMF (낮은 retention에도 불구하고!)
```

예시 3이 VALUE GAP PMF의 핵심 통찰이다: **낮은 retention + 높은 역량 이전 = 건강한 PMF**. 표준 SaaS 지표로는 이것을 PMF로 인식하지 못한다.

## 7. PMF 측정 대시보드 설계

### Daily (매일 확인)

| 지표 | 소스 | 임계값 | 조치 |
|---|---|---|---|
| 갭 시각화 완주율 | 이벤트 로그 | >= 65% | < 55% 시 5필드 폼 UX 점검 |
| 발산점 호버 깊이 | 이벤트 로그 | 평균 >= 2.0 | < 1.5 시 시각화 설득력 점검 |
| 익명 공유 전환율 | 이벤트 로그 | >= 12% | < 8% 시 공유 인센티브 구조 점검 |
| 신규 Free 유입 | 가입 로그 | 일 15+ (M1 기준) | < 10 시 CLG 채널 점검 |

### Weekly (주간 리뷰)

| 지표 | 소스 | 임계값 | 조치 |
|---|---|---|---|
| PQL 트리플 시그널 전환율 | 퍼널 분석 | >= 8% | < 5% 시 Anti-PMF 시나리오 2 체크 |
| 유료 전환 후 갭 닫기 착수율 | 자가 신고 로그 | >= 45% | < 30% 시 온보딩 이후 경험 재설계 |
| 자발적 피드백 건수 | 이메일/인앱 | 주 3건+ (시드 기준) | 0건 시 NPS 마이크로 서베이 발송 |
| 일일 과빈도 사용자 비율 | 세션 로그 | < 10% | > 20% 시 빠짐 경고 발동 |

### Monthly (월간 전략 리뷰)

| 지표 | 소스 | 임계값 | 조치 |
|---|---|---|---|
| Core_PMF (복합) | M3 서베이 | >= 0.25 | < 0.15 시 핵심 루프 재설계 |
| HPMFI | 복합 산출 | >= 0.50 | < 0.30 시 빠짐 감사 실행 |
| 코호트 갭 축소율 | 갭 점수 비교 | >= 20% (M3) | < 10% 시 Anti-PMF 시나리오 3 체크 |
| CLG 자연 성장률 | UTM 분석 | >= 15%/월 | < 10% 시 공유 메커니즘 재설계 |
| LTV/CAC | 재무 데이터 | >= 3.0x | < 2.0x 시 가격 or CAC 재검토 |

### Leading → Lagging 전환점 의사결정 트리

```
[Week 1-2] L1 지표 확인
  ├─ L1 통과 (완주 65%+, 호버 2.0+, D1 20%+)
  │   → Week 3-4: L2 지표 추적으로 전환
  │   ├─ L2 통과 (전환 8%+, 착수 45%+, 갱신 의향 70%+)
  │   │   → Month 2-3: Lagging 지표 대기
  │   │   ├─ Core_PMF >= 0.25 + HPMFI >= 0.50
  │   │   │   → PMF 확인. CLG 투자 가속
  │   │   ├─ Core_PMF 0.15-0.25 + HPMFI 0.30-0.49
  │   │   │   → 부분 PMF. 세그먼트 분석 후 타겟 재조정
  │   │   └─ Core_PMF < 0.15 or HPMFI < 0.30
  │   │       → PMF 미달. Anti-PMF 시나리오 진단 실행
  │   └─ L2 미통과
  │       → Anti-PMF 시나리오 2 (전환 단절) 대응
  └─ L1 미통과
      → Anti-PMF 시나리오 1 (갭 무관심) 대응
```

## 8. PMF 도달 타임라인 예측

iter 15 unit economics + iter 12 코호트 전략을 기반으로, PMF 도달까지의 마일스톤을 3가지 시나리오로 예측한다.

### Month 1 마일스톤 (MVP 출시 직후)

| 항목 | Pessimistic | Base | Optimistic |
|---|---|---|---|
| Free 유입 | 250명 | 500명 | 800명 |
| 갭 시각화 완주율 | 45% | 65% | 78% |
| D1 재방문율 | 10% | 20% | 30% |
| 익명 공유 전환율 | 4% | 12% | 18% |
| L1 지표 판정 | **미통과** (2/4) | **통과** (4/4) | **초과 달성** |
| 의사결정 | 갭 시각화 재설계 4주 | L2 추적 진입 | L2 추적 + CLG 확대 |

### Month 3 마일스톤 (시드 코호트 성숙)

| 항목 | Pessimistic | Base | Optimistic |
|---|---|---|---|
| Core 활성 유저 | 40명 | 159명 | 280명 |
| Free → Core 전환율 | 4% | 10% | 14% |
| Core 갭 닫기 착수율 | 25% | 45% | 60% |
| M3 Retention | 25% | 40% | 52% |
| Frontier_Motivation_Ratio | 0.35 | 0.60 | 0.75 |
| Core_PMF | 0.09 | 0.24 | 0.39 |
| HPMFI | 0.18 | 0.42 | 0.58 |
| PMF 판정 | **No PMF** | **Partial PMF** (0.24, 문턱) | **Healthy PMF** |
| 의사결정 | Anti-PMF 진단. 4주 내 개선 없으면 피벗 검토 | 세그먼트별 분석. L4-L5에서 PMF 집중 | 가속. Pro tier 론칭 + CLG 채널 확대 |

### Month 6 마일스톤 (PMF 확인/부정)

| 항목 | Pessimistic | Base | Optimistic |
|---|---|---|---|
| Core 활성 유저 | 80명 | 417명 | 650명 |
| MRR | ₩3,500,000 | ₩13,820,300 | ₩22,000,000 |
| 코호트 갭 축소율 (M6) | 12% | 30% | 42% |
| 이탈자 성공률 | 15% | 35% | 50% |
| CLG 자연 성장률 | 5%/월 | 15%/월 | 25%/월 |
| Core_PMF | 0.12 | 0.30 | 0.45 |
| HPMFI | 0.22 | 0.55 | 0.72 |
| PMF 판정 | **No PMF** | **Healthy PMF** 확인 | **Strong PMF** |

### Pessimistic 시나리오: Month 6에 PMF 미달 시 대응

Month 6에 Core_PMF < 0.15이면, 3가지 경로 중 하나를 선택해야 한다:

**경로 A: ICP 피벗 (이론은 유지, 타겟 변경)**
- 현재 ICP(L4-L5 정체성 이동성 높은 전문직)가 충분한 시장 규모가 아닐 수 있다
- L3으로 확장: 가격 하향 (₩24,900 → ₩14,900), 갭 시각화를 "학습 경로 추천"으로 리프레이밍
- 예상 소요: 추가 3개월
- 리스크: L3에서는 퍼블리/폴인과 직접 경쟁, 차별화 약화

**경로 B: 제품 피벗 (타겟 유지, 솔루션 변경)**
- ICP는 맞지만 "갭 시각화"가 올바른 솔루션이 아닐 수 있다
- 대안: 1:1 코칭 모델, 코호트 기반 프로그램, 피어 매칭 중심 서비스
- 예상 소요: 추가 4-6개월 (새 MVP 필요)
- 리스크: 기존 시드 코호트 이탈, 신규 투자 필요

**경로 C: 이론 수정 + 정지 (Theory revision)**
- VALUE GAP 이론의 L4-L5 예측 자체가 실제와 불일치
- 정지하고 iter 11 falsification 기준에 따라 이론 수정
- 수정된 이론으로 새로운 제품 가설 도출
- 예상 소요: 2개월 (이론 수정) + 3-4개월 (새 제품 검증)
- 가치: 이론 기반 접근의 핵심 -- 실패가 데이터가 됨

**선택 기준**:
```
if L0 인터뷰가 건강했고 L1이 건강했지만 L2에서 무너짐:
  → 경로 B (솔루션 문제)
  
if L0 인터뷰부터 기대 이하:
  → 경로 A (ICP 문제) or 경로 C (이론 문제)
  
if L1, L2 건강했지만 Lagging에서 무너짐 (높은 retention + 낮은 HPMFI):
  → 빠짐 재설계 우선 (경로 B의 변형)

if 모든 단계에서 일관되게 기대 이하:
  → 경로 C (이론 수정)
```

### PMF 도달 확률 추정

| 시나리오 | 확률 | 근거 |
|---|---|---|
| M3에 Partial PMF (Core_PMF >= 0.15) | 65% | 갭 공개 순간의 강도가 인터뷰에서 이미 확인된 경우 |
| M6에 Healthy PMF (HPMFI >= 0.50) | 40% | Healthy PMF는 역량 이전까지 요구하므로 추가 허들 존재 |
| M6에 Strong PMF (P1-P4 모두 충족) | 20% | 모든 예측이 동시 충족은 높은 기준. 첫 제품에서 달성은 드묾 |
| M6에 No PMF → 피벗 | 25% | Anti-PMF 시나리오 중 하나 이상 발생 확률 |

**핵심 인식**: 첫 제품에서 Full PMF를 M6에 달성할 확률은 20%다. 이것은 실패가 아니라 정상이다. VALUE GAP 이론의 가치는 PMF를 보장하는 것이 아니라, **PMF가 아닌 상태를 정확히 진단하고 최소 비용으로 다음 시도를 설계**하는 것이다. M6 Partial PMF(Core_PMF 0.15-0.25)에 도달하고 M9까지 Healthy PMF로 전환하는 경로가 가장 현실적인 성공 시나리오다.
