## v1 실험의 한계

### 1. v1은 이론 v1의 가설을 테스트한다 — v2와 정렬되지 않음

iter 7(v1 실험)은 Social_Amplifier의 **수학적 구조**(곱셈 vs 덧셈)를 테스트하도록 설계되었다. 핵심 가설은:

- H0: WTP_social = WTP_private + k (Gap_Intensity와 무관한 상수 프리미엄)
- H1: WTP_social = WTP_private × m (일정 비율 증폭)

이것은 이론 v1에서 Social_Amplifier가 "순수 곱셈 인자"였을 때 의미 있는 테스트였다. 그러나 iter 9(이론 v2)에서 Social_Amplifier는 **신호 전달 계수**로 재정의되었다: "기능적 갭이 중요한 타인에게 보이는 정도." 이 재정의의 핵심은 "사회적 조건의 존재 여부"가 아니라 **"관찰자와 사용자의 관계"**가 Social_Amplifier의 크기를 결정한다는 것이다.

v1 실험의 2x2 설계(Gap_Intensity x Social 조건)는 관찰자의 존재/부재만 조작한다. 관찰자가 **누구인지** — 사용자의 전문적 정체성에 대해 판단 권한이 있는 사람인지, 무관한 타인인지 — 를 구분하지 않는다.

### 2. v1 실험은 결과를 산출하지만 v2에 대해 비결정적(inconclusive)이다

v1 실험을 실행하면 두 가지 결과가 나올 수 있다:

**(a) 상호작용 유의**: Gap x Social 상호작용이 유의하면 "사회적 조건이 WTP를 증폭한다"는 결론을 내릴 수 있다. 그러나 이것은 v2 이론의 핵심 예측 — "증폭의 크기가 관찰자-사용자 관계의 판단 관련성(evaluative relevance)에 의해 조절된다" — 을 검증하지 못한다. 증폭이 관찰자의 존재 자체에 의한 것인지(SDT의 외적 동기 효과로도 설명 가능), 관찰자의 판단이 사용자의 전문적 정체성에 위협이 되기 때문인지 구분할 수 없다.

**(b) 상호작용 비유의**: 곱셈 구조가 기각되지만, 이것은 v2 이론의 Social_Amplifier가 무효라는 의미가 아니다. v2에서 Social_Amplifier는 단순한 사회적 존재(social presence)가 아니라 **판단적 관계(evaluative relationship)**에 의해 활성화된다. v1의 "Social 조건"이 무관한 타인을 포함했다면 Social_Amplifier가 충분히 활성화되지 않았을 가능성이 있다.

### 3. JTBD와의 차별화 실패 (iter 8 메타-리뷰 경고)

iter 8 메타-리뷰는 v1 실험이 VALUE GAP과 JTBD를 깔끔하게 구분하지 못한다고 지적했다. JTBD에서도 "사회적 job"이 존재하며, 사회적 조건에서 WTP가 상승하는 것은 "social job-to-be-done이 활성화되었다"로 설명할 수 있다. v1의 2-요인 설계로는 "갭의 사회적 증폭(VALUE GAP)" vs "사회적 job의 추가 활성화(JTBD)"를 구분할 수 없다.

v2 설계는 **관찰자 유형**을 조작함으로써 이 문제를 해결한다: JTBD에서 "social job"은 관찰자가 누구이든 동일하게 활성화되지만, VALUE GAP v2에서는 관찰자의 판단 관련성이 높을 때만 Social_Amplifier가 강하게 작동한다.

## v2 이론의 구체 예측

이론 v2에서 Social_Amplifier는 "기능적 갭이 중요한 타인에게 보이는 정도 — 신호 전달 계수"로 재정의되었다. 이 재정의가 v1의 "순수 곱셈 인자"와 다른 점은 **관찰자의 속성**이 Social_Amplifier의 크기를 결정한다는 것이다. 구체적으로 세 가지 반증 가능한 예측을 도출한다.

### 예측 P1: 관찰자-판단 관련성 조절 효과 (Observer Evaluative Relevance Moderation)

> **동일한 사회적 가시성 조건에서, 관찰자가 사용자의 전문적 정체성에 대해 판단 권한이 있는 사람(중요 타인)일 때 WTP가 유의하게 높고, 판단 권한이 없는 사람(무관 타인)일 때 WTP 상승이 미미하다.**

구체적 수치 기준:
- 중요 타인 조건 vs 비공개 조건: Cohen's d >= 0.4 (중간 효과)
- 무관 타인 조건 vs 비공개 조건: Cohen's d < 0.2 (무시할 수준)
- 중요 타인 조건 vs 무관 타인 조건: 유의한 차이 (p < 0.05)

**v1 실험이 이것을 테스트할 수 없는 이유**: v1의 "Social 조건"은 "비즈니스 파트너/핵심 클라이언트와 공유"로만 설정되어 관찰자 유형이 단일하다. 무관 타인 조건이 없으므로 관찰자 유형의 조절 효과를 검증할 수 없다.

**반증 조건**: 중요 타인 조건과 무관 타인 조건의 WTP 차이가 비유의하면(p > 0.10), 관찰자의 판단 관련성은 Social_Amplifier의 결정 요인이 아니다. 이 경우 v2의 "신호 전달 계수" 재정의가 기각되고, v1의 "사회적 존재 자체가 증폭 인자"라는 더 단순한 모형이 유지된다.

### 예측 P2: 3-way 상호작용 — Gap_Intensity x Observer_Type x Evaluative_Relevance

> **Gap_Intensity가 높고, 관찰자가 중요 타인이며, 그 관찰자가 사용자를 전문적으로 평가하는 관계일 때 WTP가 비선형적으로 증폭된다. 이 3-way 상호작용이 VALUE GAP v2의 고유 예측이다.**

이것은 단순한 "사회적 조건에서 WTP 증가"를 넘어서는 예측이다. 갭이 크고(High Gap) + 그 갭이 나를 전문적으로 평가하는 중요 타인에게 보일 때(High Evaluative Relevance) + 그 관찰자가 실제로 중요한 사람일 때(중요 타인) — 이 세 조건이 동시에 충족될 때 WTP가 가장 극적으로 상승한다.

구체적 수치 기준:
- 3-way 상호작용 효과: partial eta-squared >= 0.02 (소-중간 효과)
- High Gap / 중요 타인 / 높은 판단 관련성 셀의 WTP가 다른 모든 셀의 평균보다 >= 40% 높음

**v1 실험이 이것을 테스트할 수 없는 이유**: v1은 2-요인 설계(Gap x Social)이므로 3-way 상호작용 검정이 불가능하다.

**반증 조건**: 3-way 상호작용이 비유의하면(p > 0.10), v2의 "관계적 판단 관련성이 Social_Amplifier를 추가 조절한다"는 주장이 기각된다. 2-way 상호작용만 유의하면 v1 수준의 이론으로 복귀한다.

### 예측 P3: 갭 비공개 비용의 관계적 비대칭 (Relational Asymmetry of Non-Closure Cost)

> **v2 이론에서 Social_Amplifier는 "갭을 닫지 않는 비용의 사회적 가시성"이다. 이 비용은 관찰자가 사용자를 전문적으로 평가할 수 있는 관계에서만 실질적이다. 따라서: 갭을 닫지 않았을 때의 인지된 사회적 비용(perceived social cost of NOT closing the gap)이 중요 타인-판단 관련 조건에서만 유의하게 높고, 이 인지된 비용이 WTP 상승을 매개한다.**

이것은 v2의 메커니즘적 예측이다: WTP 상승의 원인이 "사회적 존재에 의한 일반적 각성(general arousal)"이 아니라, "이 사람이 나를 평가하는데 갭이 보이면 안 되기 때문에 닫아야 한다"는 구체적 비용 인식이라는 것이다.

구체적 수치 기준:
- "갭을 닫지 않으면 이 관찰자에게 어떤 비용이 있는가?" 측정 (1-7 Likert)
- 중요 타인 / 높은 판단 관련성 조건: M >= 5.0
- 무관 타인 조건: M <= 3.0
- 매개 분석: 인지된 사회적 비용 → WTP 경로의 간접효과가 전체 효과의 >= 40%

**v1 실험이 이것을 테스트할 수 없는 이유**: v1은 매개 변인(인지된 사회적 비용)을 측정하지 않으며, 관찰자 유형이 단일하므로 관계적 비대칭을 관찰할 수 없다.

**반증 조건**: (a) 인지된 사회적 비용이 관찰자 유형에 따라 차이가 없거나, (b) 인지된 사회적 비용이 WTP를 매개하지 않으면(간접효과 CI가 0 포함), v2의 메커니즘적 설명이 기각된다. 이 경우 Social_Amplifier는 "신호 전달 계수"가 아니라 단순한 사회적 촉진(social facilitation) 효과일 수 있다.

## 실험 설계 v2: 3-Factor Between-Subjects

### 요인 구조

v2 설계는 3-요인 피험자 간(between-subjects) 설계다.

**Factor 1: Gap Intensity (2 수준)**
- Low Gap: 주 3시간 손실 (v1과 동일)
- High Gap: 주 10시간 손실 (v1과 동일)

**Factor 2: Observer Type (3 수준)**
- 비공개(Private): 아무도 결과를 보지 않음 (v1의 Private과 동일)
- 무관 타인(Irrelevant Observer): 결과를 보지만 사용자의 전문적 맥락과 무관한 사람
- 중요 타인(Significant Observer): 사용자의 전문적 정체성에 직접적으로 관련된 사람

**Factor 3: 관계의 판단 관련성 (2 수준)**
- 낮음(Low Evaluative Relevance): 관찰자가 사용자의 전문적 역량을 평가하지 않는 관계
- 높음(High Evaluative Relevance): 관찰자가 사용자의 전문적 역량을 직접 평가하는 관계

**주의**: Factor 3은 Factor 2의 "관찰자 있음" 조건에서만 의미가 있다. 비공개 조건에서는 관찰자가 없으므로 Factor 3이 적용되지 않는다. 이것은 불완전 팩토리얼(incomplete factorial) 설계가 된다:

```
비공개 조건 (2 셀):           Low Gap / Private, High Gap / Private
무관 타인 조건 (4 셀):        Low Gap / 무관 / Low ER, Low Gap / 무관 / High ER
                              High Gap / 무관 / Low ER, High Gap / 무관 / High ER
중요 타인 조건 (4 셀):        Low Gap / 중요 / Low ER, Low Gap / 중요 / High ER
                              High Gap / 중요 / Low ER, High Gap / 중요 / High ER
```

총 10개 셀. 이것은 완전 3x2x2 = 12셀 설계가 아닌 10셀 불완전 팩토리얼이다.

### 3-요인이 필요한 이유: v1의 2-요인 설계로는 불충분

v1의 2x2 설계가 구분하지 못하는 것을 v2의 3-요인 설계가 구분하는 세 가지 경쟁 이론을 정리한다:

**(1) VALUE GAP v2 vs JTBD 구분**: JTBD에서 "social job"은 관찰자의 유형과 무관하게 활성화된다 — "타인이 있으면 사회적 job이 추가된다." VALUE GAP v2에서는 관찰자의 판단 관련성이 높을 때만 Social_Amplifier가 강하게 작동한다. 따라서 **무관 타인 조건과 중요 타인 조건의 WTP 차이**가 두 이론을 구분한다. v1에는 무관 타인 조건이 없었으므로 이 구분이 불가능했다.

**(2) VALUE GAP v2 vs SDT 구분**: SDT에서 외적 평가(external evaluation)는 자율성을 훼손하여 동기를 감소시킨다. 평가가 전문적으로 관련될수록(높은 판단 관련성) 자율성 훼손이 크다. VALUE GAP v2에서는 반대로 판단 관련성이 높을수록 Social_Amplifier가 강화된다. 따라서 **판단 관련성 고/저의 WTP 방향**이 두 이론을 구분한다. Factor 3 없이는 이 구분이 불가능하다.

**(3) v2의 고유 3-way 예측 검증**: "Gap_Intensity가 높고 + 중요 타인이고 + 판단 관련성이 높을 때" WTP가 비선형적으로 폭증한다는 것은 v2의 가장 차별적인 예측이다. 이것은 2-요인 설계에서 테스트할 수 없는 3-way 상호작용이다.

### 조건 설명: 참가자가 읽는 시나리오

**공통 설정**: v1과 동일한 "생산성 감사 리포트" 시나리오. 프리랜서/창업가가 자신의 시간 사용 방식, 손실, 비용을 분석한 리포트를 의뢰한 상황.

**Gap_Intensity 조작 (v1과 동일)**:
- Low Gap: "분석 결과, 주당 약 3시간이 비효율적으로 사용되고 있습니다. 연간 약 150시간입니다."
- High Gap: "분석 결과, 주당 약 10시간이 비효율적으로 사용되고 있습니다. 연간 약 500시간입니다."

**Observer Type 조작**:

- **비공개(Private)**: "이 리포트는 당신만 봅니다. 의뢰했다는 사실과 결과를 아무도 모릅니다."

- **무관 타인(Irrelevant Observer)**: "이 리포트의 요약본이 [조건에 따라 달라지는 관찰자]에게 공유됩니다. 그들은 당신의 갭과 대응 여부를 봅니다."
  - Low ER (낮은 판단 관련성): "요약본이 **동네 운동 모임 멤버들**에게 공유됩니다. 그들은 당신의 업무 분야와 무관한 사람들입니다."
  - High ER (높은 판단 관련성): "요약본이 **지역 창업자 독서 모임 멤버들**에게 공유됩니다. 그들은 당신과 같은 분야는 아니지만 창업/프리랜서 경험이 있는 사람들입니다."

- **중요 타인(Significant Observer)**: "이 리포트의 요약본이 [조건에 따라 달라지는 관찰자]에게 공유됩니다. 그들은 당신의 갭과 대응 여부를 봅니다."
  - Low ER (낮은 판단 관련성): "요약본이 **당신의 오래된 대학 동기 5인 그룹**에게 공유됩니다. 그들은 당신을 잘 알지만 현재 당신의 업무를 평가하는 위치에 있지 않습니다."
  - High ER (높은 판단 관련성): "요약본이 **분기 리뷰에서 핵심 클라이언트 3인 + 비즈니스 파트너 2인**에게 공유됩니다. 그들은 당신의 전문적 역량을 직접 평가하며, 이 평가가 향후 협업과 계약에 영향을 미칩니다."

**v2 핵심 조작의 차별점**: 중요 타인 / High ER 조건과 무관 타인 / Low ER 조건은 "사회적 가시성"의 수준은 유사하다(모두 5명에게 공개). 다른 것은 **관찰자와 사용자의 관계**, 그리고 **관찰자의 판단이 사용자의 전문적 정체성에 미치는 영향**이다. v2 이론이 맞다면 이 차이가 WTP를 결정적으로 분화시킨다.

### 핵심 차별 예측 (v2 vs JTBD vs SDT)

| 예측 상황 | VALUE GAP v2 | JTBD | SDT |
|---|---|---|---|
| 무관 타인 vs 비공개 | WTP 차이 미미 (d < 0.2) — 신호 전달 경로 약함 | WTP 상승 — social job 활성화 | WTP 감소 가능 — 외적 감시에 의한 자율성 훼손 |
| 중요 타인 vs 비공개 | WTP 현저 상승 (d >= 0.4) — 신호 전달 경로 강함 | WTP 상승 — social job 활성화 (무관 타인과 유사한 크기) | WTP 감소 — 중요 타인일수록 외적 평가 압력 강해 자율성 훼손 심화 |
| 중요 타인 vs 무관 타인 | WTP 유의 차이 — 핵심 구분 예측 | WTP 차이 없음 — social job은 관찰자 유형 무관 | WTP 차이 없거나 무관 타인이 더 높음 — 중요 타인 = 더 큰 자율성 훼손 |
| High ER vs Low ER (중요 타인 내) | WTP 유의 상승 — 판단 관련성이 Social_Amplifier 강화 | WTP 차이 없음 — job은 평가 관계와 무관 | WTP 감소 — 전문적 평가 = 최대 자율성 훼손 |
| Gap x Observer x ER 3-way 상호작용 | 유의 — High Gap / 중요 타인 / High ER에서 비선형 증폭 | 비유의 — social job은 일정 프리미엄 | 유의하되 반대 방향 — High ER에서 WTP 억제 |
| High Gap / 중요 타인 / High ER 셀의 WTP | 전체 평균 대비 >= 40% 초과 | 전체 평균 대비 ~15-20% 초과 (social job 프리미엄) | 전체 평균 이하 가능 — 삼중 자율성 위협 |
| 매개 경로: 인지된 사회적 비용 → WTP | 간접효과 >= 40% — "갭 미해소 시 관찰자에게의 비용" | 매개 없음 — WTP는 job 해결 가치로 결정 | 역방향 매개 — 사회적 비용 인식이 동기 감소로 |
| 갭 미해소 시 인지된 비용의 조건 간 차이 | 중요 타인 / High ER에서만 높음 (M >= 5.0/7) | 모든 사회적 조건에서 유사 | 높은 평가 조건에서 불안은 높지만 WTP로 이어지지 않음 |

**결정적 결과 패턴**: VALUE GAP v2가 맞다면 Observer Type x Evaluative Relevance 상호작용이 유의하고, 그 방향이 "중요 타인 + High ER > 나머지"다. JTBD가 맞다면 Observer Type 주효과만 유의하고 ER의 조절 효과는 없다. SDT가 맞다면 ER이 높을수록 WTP가 **감소**한다.

## 측정 방법

### WTP 유도: Van Westendorp PSM 유지

v1과 동일하게 Van Westendorp PSM(Price Sensitivity Meter)을 사용한다. 변경하지 않는 이유:

1. **설문 맥락 적합성**: 가상 시나리오 기반 실험에서 실제 결제를 요구하는 BDM 경매는 비현실적이다.
2. **한국 소비자 조사 표준**: PSM은 한국 시장 조사에서 널리 사용되므로 비교 가능성이 높다.
3. **v1과의 연속성**: 동일 측정 도구를 사용해야 v1 파일럿 데이터와 비교할 수 있다.

PSM 4개 가격점: 너무 저렴(too cheap) / 적정(reasonable) / 비쌈(expensive) / 너무 비쌈(too expensive).

주요 종속변수: **최적 가격점(Optimal Price Point, OPP)** — "너무 저렴"과 "너무 비쌈" 곡선의 교차점.

### v2 추가 측정 변인

**(1) 관찰자 관계 중요성 평가 (Relationship Importance Rating)**

시나리오 제시 후, 관찰자가 있는 조건에서:
- "이 관찰자(들)가 당신의 전문적 평판에 얼마나 영향을 미칩니까?" (1-7 Likert)
- "이 관찰자(들)의 당신에 대한 판단이 얼마나 중요합니까?" (1-7 Likert)
- "이 관찰자(들)가 당신의 업무 능력을 평가할 자격이 있습니까?" (1-7 Likert)

이 3개 문항의 평균 = **관계 중요성 점수(RIS)**. 조작 확인(manipulation check)으로 사용: 중요 타인 / High ER 조건에서 RIS가 가장 높아야 한다.

**(2) 전문적 정체성 위협 척도 (Professional Identity Stakes)**

- "이 갭이 공개되면 당신의 전문가로서의 이미지가 얼마나 손상됩니까?" (1-7 Likert)
- "이 갭을 닫지 않으면 이 관찰자(들)에게 어떤 직업적 비용이 있습니까?" (1-7 Likert)
- "이 관찰자(들)가 이 갭을 본다면, 당신과의 향후 협업/계약에 영향이 있습니까?" (1-7 Likert)

이 3개 문항의 평균 = **정체성 위협 점수(ITS)**. 매개 분석에서 사용: ITS가 Observer Type/ER → WTP 경로를 매개하는지 검증.

**(3) 갭 미해소 시 인지된 사회적 비용 (Perceived Social Cost of Non-Closure)**

- "이 갭을 닫지 않고 그대로 두면 이 관찰자(들)에게 어떤 결과가 있을까요?" (자유 서술)
- "갭을 닫지 않는 것의 사회적 비용은 얼마나 큽니까?" (1-7 Likert)

이것은 예측 P3(갭 비공개 비용의 관계적 비대칭)의 직접 측정이다.

### 조작 확인 (Manipulation Checks)

v1의 조작 확인 2문항을 유지하고 v2 전용 문항을 추가한다:

**v1 유지 문항**:
- "이 갭이 중요한 타인에게 얼마나 가시적인가?" (1-7)
- "이 갭을 닫는 것이 얼마나 긴급하게 느껴지는가?" (1-7)

**v2 추가 문항**:
- "이 관찰자(들)이 당신의 전문적 역량을 판단할 수 있는 위치에 있는가?" (1-7)
- "이 관찰자(들)의 판단이 당신의 커리어에 실질적 영향을 미치는가?" (1-7)

**조작 확인 성공 기준**:
- 가시성: 무관 타인 ≈ 중요 타인 > 비공개 (사회적 가시성은 유사하되 비공개보다 높음)
- 판단 관련성: 중요 타인 / High ER > 중요 타인 / Low ER > 무관 타인 / High ER > 무관 타인 / Low ER > 비공개
- 긴급성: High Gap > Low Gap (Gap 조작 확인)
- 긴급성이 Observer Type에 의해 오염되면(사회적 조건에서 긴급성도 상승) 해석에 주의 필요

### 통제 변수

v1과 동일:
- 단독 vs 팀 운영
- 월 수익 구간
- 생산성 툴 이전 사용 여부

v2 추가:
- 사회적 비교 성향 (Iowa-Netherlands Comparison Orientation Measure, INCOM 축약판 6문항)
- 자기감시 성향 (Self-Monitoring Scale, Snyder 축약판 6문항)
- 정체성 이동성 자기 평가 (v2 이론의 ICP 기준, 단일 문항: "당신의 전문적 평판은 현재 소속과 독립적으로 인정받습니까?" 1-7)

## 샘플 크기 재계산

### v1 대비 확대 필요

v1: 2x2 = 4셀, 셀당 n=52, 총 N=208 (탈락 감안 N=240).
v2: 10셀 불완전 팩토리얼.

### 검정력 분석 (Power Analysis)

**주요 검정**: 3-way ANOVA에서 Gap x Observer x ER 상호작용.

3-way 상호작용의 효과 크기는 일반적으로 주효과나 2-way 상호작용보다 작다. 보수적으로 소-중간 효과(f = 0.20, partial eta-squared ≈ 0.04)를 가정한다.

**G*Power 계산 조건**:
- 검정: F-test, Fixed effects ANOVA, special effects and interactions
- 효과 크기: f = 0.20
- alpha = 0.05
- 검정력(power) = 0.80
- 분자 자유도(numerator df): 3-way 상호작용의 df = (2-1) x (3-1) x (2-1) = 2. 단, 비공개 조건에서 ER이 없으므로 실질적으로 관찰자 있는 조건 내의 2x2x2 상호작용 df = 1, 비공개 조건은 별도 대비(contrast)로 처리. 주 분석의 분자 df = 2 (보수적 추정).
- 분모 자유도: N - 10 (10셀)

**결과**:
- f = 0.20, alpha = 0.05, power = 0.80, df_numerator = 2:
- 필요 총 N ≈ 400
- 셀당 n = 40 (10셀 x 40 = 400)

**중간 효과(f = 0.25) 가정 시**:
- 필요 총 N ≈ 270
- 셀당 n = 27

**보수적 권장**: 소-중간 효과를 기준으로 **셀당 n = 45, 총 N = 450**. 탈락률 15% 감안 시 **모집 목표 N = 520**.

### v1 대비 규모 비교

| 항목 | v1 | v2 |
|---|---|---|
| 셀 수 | 4 | 10 |
| 셀당 n | 52 | 45 |
| 총 N (최소) | 208 | 450 |
| 모집 목표 | 240 | 520 |
| 효과 크기 가정 | 중간 (f=0.25) | 소-중간 (f=0.20) |
| 주요 검정 | 2-way 상호작용 | 3-way 상호작용 |

### 예산 함의

v1: ₩95,000-120,000 (N=240).
v2: N=520은 v1의 약 2.17배. 비용도 비례적으로 증가한다.

## 분석 계획 v2

### 1차 분석: 10셀 ANOVA

**종속변수**: PSM 최적 가격점 (OPP).

**모형**: Gap_Intensity (2) x Observer_Type (3) x Evaluative_Relevance (2) 불완전 팩토리얼 ANOVA.

비공개 조건(2셀)은 ER이 없으므로 두 가지 분석 전략을 병행한다:

**(A) 관찰자 있는 조건만의 완전 팩토리얼 (8셀)**:
- 2(Gap) x 2(Observer: 무관 vs 중요) x 2(ER: Low vs High) ANOVA
- 주효과 3개, 2-way 상호작용 3개, 3-way 상호작용 1개
- **핵심 검정**: Observer x ER 상호작용 (예측 P1), Gap x Observer x ER 3-way 상호작용 (예측 P2)

**(B) 비공개 vs 관찰자 대비 (10셀)**:
- 계획 대비(planned contrast): 비공개 vs 중요타인/HighER (예측 P1의 극단 비교)
- Bonferroni 보정 적용

### 결과 해석 매트릭스

| 결과 패턴 | 해석 | 이론적 함의 |
|---|---|---|
| 3-way 상호작용 유의 (예측 방향) | **VALUE GAP v2 지지** | Social_Amplifier = 신호 전달 계수 확인. 관찰자의 판단 관련성이 핵심 조절 변인 |
| 2-way 상호작용만 유의 (Gap x Observer), 3-way 비유의 | **v2 정교화 기각, v1 수준 유지** | Social_Amplifier는 사회적 존재 자체에 의해 작동. "누가 보는가"는 중요하지 않음. v1의 곱셈/덧셈 구조 질문이 여전히 유효 |
| Observer 주효과만 유의, 상호작용 모두 비유의 | **JTBD 설명과 일치** | 사회적 조건 = 일정 프리미엄. Gap_Intensity와 무관한 social job 추가. VALUE GAP의 곱셈 구조 미지지 |
| High ER 조건에서 WTP 감소 | **SDT 설명과 일치** | 전문적 평가 = 자율성 훼손 → 동기 감소. VALUE GAP v2의 방향 예측이 틀림 |
| 모든 효과 비유의 | **Social_Amplifier 무효** | F-4 반증 조건(falsification criteria) 충족. Social_Amplifier는 실재하지 않는 구성개념 |

### 2차 분석: 매개 분석

**경로 모형**: Observer_Type/ER → 인지된 사회적 비용(ITS) → WTP (OPP)

- Hayes PROCESS Model 4 또는 Mplus를 사용한 간접효과 추정
- Bootstrap 95% CI (5,000 재추출)로 간접효과 유의성 검정
- **예측 P3 지지 기준**: 간접효과 CI가 0을 포함하지 않으며, 간접효과가 총효과의 >= 40%

### 3차 분석: 비율 구조 검증 (v1 질문의 하위 검정)

v1의 곱셈/덧셈 질문도 v2 설계 내에서 부분적으로 답할 수 있다:

- 중요 타인 / High ER 조건 내에서: ratio_low = (Low Gap, Social) / (Low Gap, Private), ratio_high = (High Gap, Social) / (High Gap, Private)
- Bootstrap 95% CI 비교: 두 비율의 CI가 중첩되면 곱셈 구조 부분 지지

이것은 v2의 핵심 분석이 아닌 탐색적(exploratory) 분석으로 위치시킨다.

### 반증 판정 기준 (Falsification Decision Rules)

| 반증 대상 | 판정 조건 | 결과 |
|---|---|---|
| v2의 "신호 전달 계수" 정의 | Observer x ER 상호작용 비유의 (p > 0.10) | v2 정교화 기각 → v1 수준의 Social_Amplifier로 회귀 |
| v2의 3-way 예측 | Gap x Observer x ER 3-way 비유의 (p > 0.10) | v2의 "관계적 판단 관련성" 조절 효과 기각 |
| Social_Amplifier 전체 | 모든 사회적 조건 vs 비공개 차이 비유의 (d < 0.15) | F-4 반증 — Social_Amplifier 구성개념 무효 |
| VALUE GAP vs JTBD | Observer 주효과 유의 + Observer x ER 비유의 | JTBD "social job" 모형이 더 간명 |
| VALUE GAP vs SDT | High ER 조건에서 WTP 감소 | SDT 외적 동기 crowding-out이 작동 |

### v1 설계와 동시 실행 가능성

v2를 독립 실험으로 실행하는 것이 권장된다. 이유:

1. **v1과 v2의 핵심 질문이 다르다**: v1은 수학적 구조(곱셈 vs 덧셈), v2는 메커니즘적 구조(관찰자 판단 관련성). 동일 설문에 통합하면 참가자 부담이 과도하다.
2. **v2 설계가 v1 질문을 부분적으로 포함한다**: v2의 중요 타인 / High ER 조건 내에서 v1의 곱셈/덧셈 검정이 가능하다(탐색적 분석으로).
3. **v1을 별도로 실행할 이유가 감소했다**: v2 이론이 v1 이론을 대체했으므로, v1 실험의 결과가 어느 방향으로 나오든 v2 이론에 대한 결정적 증거가 되지 않는다.

**권장**: v1 실험을 **폐기(deprecate)**하고 v2 실험만 실행한다. v1의 곱셈/덧셈 질문은 v2 설계 내의 탐색적 분석으로 흡수한다.
