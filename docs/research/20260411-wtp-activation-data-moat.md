## PART A: 활성화 플로우 (Aha Moment 설계)

### A1. VALUE GAP 이론이 예측하는 Aha Moment

VALUE GAP v2 이론의 핵심 명제는 "갭 공개 순간이 곧 판매다(Gap disclosure = sale moment)"이다. 이 명제를 UX 언어로 번역하면: **사용자가 자신이 인지하지 못했던 갭을 처음 시각적으로 확인하는 순간**이 Aha Moment이며, 그 순간이 전환 의도(conversion intent)의 정점이다.

그러나 이 Aha Moment는 모든 사용자에게 동일하지 않다. VALUE GAP L3/L4/L5 사용자는 갭의 성격이 다르므로, Aha Moment의 내용도 달라야 한다.

**L3 사용자 (Identity Delegation): "내 갭이 보였다"**

L3 사용자는 자신의 정체성에 위협적인 기능적 갭을 갖고 있지만, 그 갭이 무엇인지 막연하게만 느끼고 있다. Career Mirror의 Aha Moment은 이 막연한 불안을 **구체적 발산점 라벨**로 변환하는 순간이다.

- 감정 변화: 막연한 불안 → "아, 이게 내 약점이었구나" (명명의 안도감 + 약간의 충격)
- UX 목표: 발산점 라벨 3개를 보여주되, 사용자가 자기 궤적과 코호트 궤적의 차이를 시각적으로 즉시 인지할 수 있어야 한다
- Mirror Moment 완성 조건: 사용자가 발산점 중 1개 이상에 마우스를 올리거나 탭한다 (= "내 것"으로 인지했다는 행동 신호)

**L4 사용자 (Meta-insight known): "저 사람이 이걸 어떻게 했는지 보였다"**

L4 사용자는 자기 갭을 이미 어느 정도 알고 있다. "나는 외부 포트폴리오가 부족하다"는 것쯤은 안다. 이들에게 발산점 라벨만 보여주면 "알고 있었는데"가 된다. L4의 Aha Moment은 **코호트가 그 갭을 닫은 경로**가 보이는 순간이다.

- 감정 변화: "이미 알고 있었는데" → "아, 이 시점에 이렇게 한 거구나" (경로의 구체성에 의한 가속 감각)
- UX 목표: 발산점 라벨 + 코호트 중앙 행동 요약(블러 처리)까지 보여주되, 상세 경로는 유료 잠금
- Mirror Moment 완성 조건: 블러 처리된 "코호트 경로 상세" 영역을 클릭하거나 호버한다

**L5 사용자 (Meta-insight unknown): "내가 모르는 게 뭔지 보였다"**

L5 사용자는 자신이 무엇을 모르는지조차 모른다. 이것이 VALUE GAP에서 가장 높은 WTP를 생성하는 조건이다. L5의 Aha Moment은 **자신이 질문조차 하지 못했던 차원의 갭**이 드러나는 순간이다.

- 감정 변화: 자기 확신 또는 모호한 방향감 → "이런 차원이 있었어?" (인식론적 충격)
- UX 목표: 발산점 3개 중 최소 1개는 사용자가 예상하지 못한 차원이어야 한다. 예: 사용자가 "스킬 갭"을 예상했는데 "네트워크 구조 갭"이 나온다
- Mirror Moment 완성 조건: 사용자가 발산점을 보고 5초 이상 체류한다 (= 예상 외의 정보를 처리하는 인지 시간)

**통합 설계 원칙**: 온보딩 과정에서 사용자가 L3/L4/L5 중 어디에 해당하는지를 판별할 필요는 없다. 발산점 3개를 공개하되, 최소 1개는 사용자가 예상 가능한 갭(L3/L4 대응), 최소 1개는 예상 불가능한 갭(L5 대응)으로 구성하면 모든 레벨의 Aha Moment을 동시에 충족한다.

### A2. 첫 5분 UX 흐름 (스텝별 설계)

사용자가 외부 채널(CLG 커뮤니티 포스트, 공유 링크, 검색)에서 Career Mirror 랜딩 페이지에 도착한 순간부터 Mirror Moment까지의 흐름을 설계한다. 총 소요 시간 목표: 4분 30초 이내.

**Step 1: 랜딩 페이지 도착 (0:00 ~ 0:15)**

- **사용자가 보는 것**: 헤드라인 한 줄 + 서브헤드 한 줄 + CTA 버튼 1개. 그 외 아무것도 없다.
  - 헤드라인: "당신이 모르는 커리어 갭 3개"
  - 서브헤드: "3분 입력. 계정 없이 즉시 확인."
  - CTA: "내 궤적 분석하기"
- **사용자가 하는 것**: CTA를 클릭한다
- **시스템**: 클릭 이벤트 기록 (`landing_cta_click`)
- **감정 상태**: 호기심 + 약간의 회의 ("정말 3분이야?")
- **설계 근거**: Fogg의 B=MAP에서 Ability를 극대화한다. 계정 생성 없음, 이메일 없음, 소셜 로그인 없음. 마찰을 제로에 가깝게.

**Step 2: 목표 아웃컴 선택 (0:15 ~ 0:35)**

- **사용자가 보는 것**: "당신의 커리어 목표는?" + 6개 아웃컴 카드. 각 카드에 한 줄 설명 + 아이콘.
  - 예시 카드: "시리즈A+ 창업" / "월 500만+ 프리랜서" / "대기업 임원급 승진" / "해외 취업" / "업종 전환 성공" / "공개 전문가 지위 (강연·저서·미디어)"
- **사용자가 하는 것**: 카드 1개를 선택한다
- **시스템**: 선택된 아웃컴을 기반으로 비교 코호트를 미리 필터링 시작 (백그라운드)
- **감정 상태**: 자기 목표를 명시적으로 선택하는 행위 자체가 몰입을 유발한다. "나는 이것을 원한다"고 확인하는 순간 갭 공개에 대한 수용도가 올라간다.
- **설계 근거**: 목표 선택이 먼저인 이유 — 역할 히스토리부터 입력하면 "데이터 수집" 느낌이 난다. 목표부터 선택하면 "미래를 설계하는 중" 느낌이 된다. 프레이밍 효과.

**Step 3: 현재 역할 입력 (0:35 ~ 1:15)**

- **사용자가 보는 것**: "현재 역할은?" + 자유 텍스트 입력 1줄 + 회사 규모 선택 (스타트업 / 중소기업 / 대기업 / 프리랜서)
  - 플레이스홀더: "예: 프로덕트 매니저"
  - 회사 규모: 4개 버튼 중 1개 탭
- **사용자가 하는 것**: 역할명을 타이핑하고 회사 규모를 선택한다
- **시스템**: 입력값을 표준 역할 택소노미에 매핑 (예: "PM" → "Product Manager"), 실패 시 원문 저장
- **감정 상태**: 아직 "쉽다"의 영역. 마찰 최소.
- **설계 근거**: 현재 역할 1개만 먼저 받는다. 전체 역할 히스토리는 다음 스텝.

**Step 4: 역할 히스토리 입력 (1:15 ~ 2:30)**

- **사용자가 보는 것**: "이전 주요 역할 2-4개를 추가해주세요" + 타임라인 UI (역할명 + 회사규모 + 대략적 기간 선택)
  - 기간 선택: 드롭다운이 아닌 슬라이더 ("약 1년 / 2-3년 / 4년+")
  - "건너뛸 수 있어요. 많을수록 분석이 정확해집니다" 텍스트
  - 실시간으로 사용자의 궤적 라인이 좌측에 그려진다 (시각적 피드백)
- **사용자가 하는 것**: 이전 역할 2-4개를 입력한다. 최소 2개 필요, 4개까지 선택적.
- **시스템**: 입력 즉시 궤적 라인 렌더링. 입력이 추가될수록 라인이 구체화된다. 백그라운드에서 코호트 매칭 정밀도 계산.
- **감정 상태**: 자기 커리어를 시각화로 보는 것 자체가 흥미롭다. "아, 내 커리어가 이런 모양이었구나." 약간의 몰입.
- **설계 근거**: 시각적 피드백이 핵심이다. 데이터 입력은 지루하지만, 입력할 때마다 궤적 라인이 변하면 게임화 없이도 완성 동기가 생긴다. 빠짐 audit GA-4 통과: 시각화는 사용자가 자기 데이터를 보는 것이지, 인위적 갭 재생산이 아니다.

**Step 5: 외부 아웃풋 체크 (2:30 ~ 2:50)**

- **사용자가 보는 것**: "외부에 공개된 아웃풋이 있나요?" + 체크박스 4개
  - "블로그/뉴스레터" / "GitHub/오픈소스" / "강연/발표" / "포트폴리오/작품"
  - + "없음" 버튼
- **사용자가 하는 것**: 해당하는 항목을 체크하거나 "없음"을 누른다
- **시스템**: 외부 아웃풋 유무가 발산점 계산의 핵심 변수 중 하나다. "없음"을 선택한 사용자는 높은 확률로 이 차원에서 발산점이 나온다.
- **감정 상태**: 약간의 자기 평가 불안 시작. "없음"을 누르는 순간 "나 괜찮은 건가?"라는 생각이 스친다. 이것이 Mirror Moment 직전의 심리적 프라이밍이다.
- **설계 근거**: 이 스텝이 의도적으로 마지막 입력 스텝이다. 외부 아웃풋 유무는 사용자가 이미 어느 정도 자각하고 있는 갭(L3 수준)이므로, Mirror Moment에서 더 깊은 갭이 공개될 때의 대비(contrast)를 만든다.

**Step 6: 계산 대기 화면 (2:50 ~ 3:20)**

- **사용자가 보는 것**: 분할 화면 애니메이션 준비
  - 좌측: 사용자 궤적 라인 (Step 4에서 이미 구축된 것)이 완성형으로 표시
  - 우측: "목표 코호트 궤적 로딩 중..." + 코호트 크기 표시 ("시리즈A 창업가 47명의 궤적과 비교 중")
  - 하단: 진행률 바 (실제 계산 시간과 무관하게 30초 고정 — 심리적 가치 부여)
- **사용자가 하는 것**: 기다린다. 그러나 기다림이 수동적이지 않다 — 좌측에 자기 궤적이 보이고, 우측이 로딩되는 과정에서 "내 궤적은 저들과 얼마나 다를까?" 질문이 자연스럽게 형성된다.
- **시스템**: 실제 갭 계산은 2-3초면 완료된다. 그러나 30초 대기를 의도적으로 설계한다.
- **감정 상태**: 기대 + 긴장. "진짜 내 갭이 나온다고?" 30초가 핵심이다 — 즉시 결과를 보여주면 가볍게 느껴진다. 기다림이 결과의 무게를 만든다.
- **설계 근거**: 대기 시간 의도적 설계는 빠짐 audit AU-2(숙고 시간 보존)와 양립한다. 여기서의 대기는 충동 구매 유도가 아니라 결과 수용을 위한 인지적 준비 시간이다. 단, 과도하게 길면 이탈하므로 30초가 상한.

**Step 7: Mirror Moment — 갭 공개 (3:20 ~ 4:30)**

- **사용자가 보는 것**: [A3 섹션에서 상세 설계]
  - 좌우 분할 화면이 완성된다
  - 좌: 사용자 궤적 라인 (실선, 사용자 브랜드 컬러)
  - 우: 코호트 중앙값 궤적 라인 (점선, 뉴트럴 컬러)
  - 발산점 3개: 펄스 마커 (빨간 원이 천천히 확장-수축하는 애니메이션)
  - 발산점 라벨: 마커 옆에 한 줄 텍스트 (예: "외부 아웃풋 부재", "네트워크 전환 시점", "역할 심화 기간")
  - 코호트 비교 수치: "성공 코호트의 73%는 이 시점에 [X]를 갖고 있었습니다"
- **사용자가 하는 것**: 발산점 마커를 호버/탭하여 라벨을 확인한다. 이것이 Mirror Moment이다.
- **시스템**: `gap_visualization_rendered` + `divergence_point_hover` 이벤트 기록. 이 두 이벤트가 모두 발생하면 Aha Moment 활성화 완료.
- **감정 상태**: 인식론적 충격 + 행동 의도의 동시 발생. "이게 내 갭이었구나" + "이걸 닫아야 하는데..."
- **설계 근거**: 이것이 VALUE GAP 이론이 예측하는 판매 순간이다. 갭이 시각적으로 공개되는 이 정확한 순간에 전환 의도가 정점에 달한다.

**Step 8: 전환 유도 (4:30 ~)**

- **사용자가 보는 것**: 발산점 라벨 아래에 블러 처리된 "상세 분석" 영역
  - 블러 영역 위에 한 줄: "이 갭이 왜 생겼는지, 닫는 데 평균 몇 개월이 걸리는지 확인하시겠습니까?"
  - CTA 버튼: "상세 분석 보기" (유료 전환)
  - 대안 CTA: "결과를 공유하고 발산점 1개 무료 잠금해제" (CLG 배포 유발)
  - 하단 소형 텍스트: "계정을 만들면 이 분석이 저장됩니다" (계정 생성은 전환 직전에만 요청)
- **사용자가 하는 것**: (a) 유료 전환, (b) 공유 잠금해제, (c) 이탈 중 하나를 선택한다
- **시스템**: PQL 신호 기록. 이탈한 사용자에게 7일 후 리마인더 (옵트인한 경우에만)
- **감정 상태**: "더 알고 싶다" vs "돈을 쓸 만한가?" 의 갈등. 블러 처리가 이 갈등을 만든다.
- **설계 근거**: 빠짐 audit AU-2 준수 — 즉시 결제를 강제하지 않는다. "공유 잠금해제"는 무료 대안을 제공하면서 CLG 배포를 유발하는 양면 설계. AU-3(정보 투명성) 준수 — "이 분석이 작동하는 원리" 링크가 하단에 상시 존재.

## PART B: 데이터 콜드스타트 해결

### B1. 문제 정의

Career Mirror의 핵심 가치 제안은 "사용자의 커리어 궤적을 성공 코호트와 비교하여 발산점을 공개한다"이다. 이 비교가 의미 있으려면 비교 대상 코호트의 크기와 품질이 임계값을 넘어야 한다.

**n=10이 호로스코프 영역인 수학적 이유**:

통계적 발산점 감지의 최소 조건을 생각하자. Career Mirror가 "성공 코호트의 73%는 이 시점에 외부 포트폴리오를 보유"라고 말하려면, 그 73%가 통계적으로 유의미해야 한다.

- 코호트 n=10일 때: 73% = 7.3명 ≈ 7명. 이항 분포 95% 신뢰구간: [39%, 94%]. 구간이 너무 넓어서 "39%일 수도, 94%일 수도 있다"는 의미. 사용자에게 "73%"라고 말하는 것은 허구에 가깝다.
- 코호트 n=30일 때: 73% = 21.9명 ≈ 22명. 95% 신뢰구간: [54%, 87%]. 여전히 넓지만 "과반수 이상"이라는 방향은 유의미.
- 코호트 n=50일 때: 73% = 36.5명 ≈ 37명. 95% 신뢰구간: [59%, 84%]. "대다수"라는 주장이 통계적으로 정당화되기 시작.
- 코호트 n=100일 때: 73% = 73명. 95% 신뢰구간: [63%, 81%]. 비로소 "약 2/3~4/5"라는 좁은 추정이 가능.

**핵심 임계값**: 아웃컴 카테고리별 최소 n=30이 되어야 "방향적으로 유의미한 비교"가 가능하다. n=50이면 "신뢰할 만한 비교", n=100이면 "강건한 비교"다.

**User 1 문제의 구체적 양상**:

6개 아웃컴 카테고리 x 코호트 n=30 = 최소 180명의 아웃컴 확인 유저가 필요하다. 그런데 이 180명은 "Career Mirror가 존재하기 전에" 확보해야 한다. 전형적인 데이터 닭-달걀 문제.

iter 5에서는 시드 코호트 60명을 설정했다. 60명을 6개 카테고리에 분배하면 카테고리당 평균 10명. 이것은 호로스코프 영역이다. iter 5의 시드 코호트 크기는 불충분했다.

**비교 품질 함수**:

```
Comparison_Quality = f(cohort_size, cohort_relevance, data_completeness)

cohort_size:        카테고리별 비교 대상 수 (n)
cohort_relevance:   아웃컴 확인 정확도 (실제로 성공한 사람인가?)
data_completeness:  5필드 전부 채운 비율 (부분 입력은 비교 정밀도 저하)
```

세 변수 모두 런칭 시점에 0에 가깝다. 이것이 콜드스타트 문제의 정확한 크기다.

### B2. 합성 데이터 전략 (0→1 단계)

런칭 시점에 실제 비교 코호트가 충분하지 않다면, 두 가지 선택이 있다: (a) 코호트가 충분해질 때까지 제품을 출시하지 않는다, (b) 공개 데이터 기반 합성 코호트를 구성하여 초기 비교를 제공한다. (a)는 닭-달걀 교착이므로 (b)가 현실적이다.

**한국 공개 커리어 데이터 소스 현실 평가**:

**1. LinkedIn Korea 프로필 (접근성: 중, 품질: 중상)**

- 무엇이 가용한가: 공개 프로필의 역할 시퀀스, 회사명, 재직 기간. LinkedIn은 public profile을 크롤링 금지하지만, LinkedIn API(Marketing API 또는 People Data Partners)를 통해 구조화된 데이터 접근이 가능하다.
- 현실적 한계: LinkedIn API는 개인 프로필 대량 조회에 제한적이다. People Data Partner 프로그램 가입이 필요하며 승인까지 3-6개월. MVP 타임라인에 맞지 않는다.
- 대안: LinkedIn 데이터를 직접 수집하는 대신, LinkedIn 기반 데이터 벤더(People Data Labs, Proxycurl)를 사용한다. 한국 커리어 프로필 커버리지는 약 30-40%. 비용: API 호출당 $0.01-0.10, 1000명 샘플 = $10-100. 합리적.
- 가용 필드: 역할 시퀀스(O), 회사 규모 추정(O), 재직 기간(O), 외부 아웃풋(X — LinkedIn에는 블로그/GitHub 데이터가 부족). 5필드 중 3필드만 가능.

**2. Wanted (원티드) 공개 프로필 (접근성: 하, 품질: 중)**

- 무엇이 가용한가: 원티드는 공개 프로필이 제한적이며 API를 외부에 제공하지 않는다. 크롤링은 이용약관 위반.
- 현실적 한계: 사용 불가. 직접적 데이터 소스로 부적합.
- 간접 활용: 원티드 커리어 콘텐츠(블로그, 인터뷰)에서 성공 사례의 커리어 패턴을 구조화할 수 있다. 그러나 이것은 일화적 데이터이지 통계적 코호트가 아니다.

**3. Rocketpunch (로켓펀치) 프로필 (접근성: 중하, 품질: 중)**

- 무엇이 가용한가: 로켓펀치는 한국 스타트업 생태계 중심 프로필 DB. 공개 프로필이 존재하나 API는 제한적.
- 현실적 한계: 기업 프로필은 공개이나 개인 프로필 대량 접근은 어렵다. 스타트업 관련 아웃컴("시리즈A+ 창업")에 한해 간접 데이터 추출 가능.
- 간접 활용: 로켓펀치의 기업 데이터(투자 라운드, 팀 규모)를 통해 "시리즈A+ 창업자"의 회사 정보는 확인 가능. 그러나 개인 커리어 궤적 데이터는 불가.

**4. 사람인/잡코리아 API (접근성: 중, 품질: 중하)**

- iter 5에서 "MVP 이후"로 분류. 채용공고 데이터는 풍부하나 이것은 "수요 측 데이터"이지 "성공자 궤적 데이터"가 아니다.
- 활용 가능성: 채용공고의 우대사항/자격요건에서 "이 역할에 도달하려면 무엇이 필요한가"의 프록시를 추출할 수 있다. 그러나 이것은 궤적 비교가 아니라 요건 비교이므로 Career Mirror의 핵심 메커니즘과 맞지 않는다.

**5. 공개 커리어 콘텐츠 (접근성: 상, 품질: 하-중)**

- 브런치/티스토리 커리어 회고글, 유튜브 "내가 PM이 된 과정" 류 콘텐츠, 출판된 인터뷰(EO, PUBLY 콘텐츠 일부).
- 비구조화 데이터이므로 LLM 기반 추출 필요. 추출 정확도 예상: 역할 시퀀스 80%, 회사 규모 60%, 기간 50%, 외부 아웃풋 70%.
- 현실적 규모: 카테고리별 20-50개 콘텐츠를 수집하면 100-300개의 부분 궤적 추출 가능.

**합성 코호트 구성 전략**:

위 소스들의 현실적 한계를 종합하면, 단일 소스로는 충분한 비교 코호트를 구성할 수 없다. 멀티소스 합성이 필요하다.

```
합성 코호트 = LinkedIn 벤더 데이터 (구조화, 3/5 필드)
            + 공개 콘텐츠 LLM 추출 (비구조화, 4/5 필드, 낮은 정확도)
            + 시드 코호트 자가 신고 (구조화, 5/5 필드, 높은 정확도)
```

**데이터 품질 등급제**:

합성 코호트의 각 프로필에 품질 등급을 부여한다:

| 등급 | 소스 | 필드 완성도 | 아웃컴 확인 | 비교 시 가중치 |
|---|---|---|---|---|
| A | 시드 코호트 자가 신고 | 5/5 | 확인 완료 | 1.0 |
| B | LinkedIn 벤더 + 공개 아웃컴 확인 | 3-4/5 | 간접 확인 | 0.7 |
| C | 공개 콘텐츠 LLM 추출 | 2-4/5 | 자가 선언 | 0.4 |

비교 시 가중 평균을 사용한다. "성공 코호트의 73%는..."이라는 수치는 가중 평균으로 계산되며, 등급별 신뢰도가 반영된다.

**빠짐 audit 함의 — 합성 데이터의 윤리적 경계**:

합성 데이터는 사용자를 오도할 위험이 있다. "47명의 시리즈A 창업자와 비교했습니다"라고 표시했는데 실제로는 10명이 실제 시드 + 37명이 LinkedIn 벤더 + LLM 추출이라면, 이것은 기만인가?

**원칙**: 정확한 출처를 숨기지 않되, 사용자에게 과도한 인지 부담을 주지도 않는다.

- 비교 화면에 "코호트 구성: 검증된 데이터 N명 + 공개 데이터 기반 추정 M명"을 소형 텍스트로 표시
- "이 분석이 작동하는 원리" 페이지에 데이터 소스와 한계를 완전 공개
- 합성 데이터 비율이 70%를 초과하는 카테고리는 "베타 분석 (데이터 수집 중)"으로 명시
- AU-3(정보 투명성) 체크리스트 준수: "제품 밖에서 동일 결과를 얻는 방법" 안내에 데이터 한계를 포함

### B3. 시드 코호트 데이터 수집 설계 (1→10 단계)

iter 12에서 설계한 90명 시드 코호트(기존 iter 5의 60명에서 상향)를 기반으로, 시드 코호트의 커리어 데이터를 **비교 가능 품질**로 수집하는 방법을 설계한다.

**시드 코호트에서 구조화된 커리어 데이터를 수집하는 문제**:

시드 코호트는 CLG(Community-Led Growth) DM 모집으로 확보한 사람들이다. 이들은 "커리어 분석 도구를 시험해보겠다"는 동기로 참여한다. 그러나 "5필드 커리어 데이터를 정확하게 입력해달라"는 요청은 별도의 동기가 필요하다. 문제: 시드 코호트가 대충 입력하면 비교 데이터 품질이 무너진다.

**인센티브 설계**:

| 레벨 | 입력 품질 조건 | 인센티브 |
|---|---|---|
| 기본 | 5필드 모두 입력 (최소 역할 3개) | 제품 런칭 시 유료 기능 1개월 무료 |
| 심화 | 5필드 + 각 역할 전환 이유 1줄 서술 | 유료 기능 3개월 무료 + 아웃컴 배지 |
| 멘토 | 심화 + "당신의 궤적이 다른 사용자에게 비교됩니다" 동의 + 후배 1명 매칭 의향 | 영구 무료 + 멘토 코호트 배지 |

**데이터 품질 게이트: "비교 가능(Comparison-Ready)" 프로필의 조건**:

프로필이 비교 코호트에 포함되려면 다음 5개 조건을 모두 충족해야 한다:

1. **역할 수**: 최소 3개 역할 입력 (현재 + 이전 2개)
2. **회사 규모**: 모든 역할에 회사 규모 태그 존재
3. **기간**: 모든 역할에 대략적 재직 기간 존재 (1년 미만 / 1-2년 / 3-4년 / 5년+)
4. **아웃컴 확인**: 아웃컴이 독립적으로 확인 가능 (시리즈A = 투자 뉴스, 프리랜서 수익 = 자가 선언 + 1개 증빙)
5. **외부 아웃풋**: 체크박스 4개 + "없음" 중 하나 이상 선택

5개 조건 중 4개 이상 충족 = Comparison-Ready (등급 A). 3개 충족 = Partial (등급 B, 보조 데이터로만 사용). 2개 이하 = Exclude.

**시드 코호트 90명의 현실적 데이터 수확 예상**:

- 90명 모집 → 70명 온보딩 폼 시작 (22% 이탈 예상)
- 70명 → 55명 5필드 완성 (21% 부분 입력 이탈)
- 55명 → 45명 Comparison-Ready (등급 A) 달성
- 45명 / 6개 카테고리 = 카테고리당 평균 7.5명

카테고리당 7.5명은 여전히 호로스코프 영역이다. 따라서 시드 코호트만으로는 콜드스타트를 해결할 수 없다. **합성 데이터(B2)와 시드 코호트(B3)의 결합이 필수적이다.**

결합 후 예상:

| 카테고리 | 시드 (등급 A) | LinkedIn 벤더 (등급 B) | 공개 콘텐츠 (등급 C) | 가중 합산 n |
|---|---|---|---|---|
| 시리즈A+ 창업 | 12 | 25 | 15 | 12 + 25x0.7 + 15x0.4 = 35.5 |
| 월 500만+ 프리랜서 | 8 | 10 | 20 | 8 + 10x0.7 + 20x0.4 = 23 |
| 대기업 임원급 | 5 | 30 | 10 | 5 + 30x0.7 + 10x0.4 = 30 |
| 해외 취업 | 8 | 20 | 15 | 8 + 20x0.7 + 15x0.4 = 28 |
| 업종 전환 | 7 | 15 | 25 | 7 + 15x0.7 + 25x0.4 = 27.5 |
| 공개 전문가 | 5 | 10 | 30 | 5 + 10x0.7 + 30x0.4 = 24 |

대부분의 카테고리에서 가중 합산 n=24-35. 이것은 "방향적으로 유의미한 비교"(n=30) 임계값에 근접하거나 달성한다. "월 500만+ 프리랜서"와 "공개 전문가"는 아직 부족하므로, 이 두 카테고리는 "베타 분석" 라벨로 런칭한다.

### B4. 데이터 모트 전략 (10→100+ 단계)

**네트워크 효과: 비교가 더 나아지는 구조**

Career Mirror의 데이터 네트워크 효과는 **단면(single-sided)**이다. 같은 종류의 사용자가 많아질수록 비교가 정밀해진다.

메커니즘:

1. 새 사용자가 온보딩 데이터를 입력한다
2. 사용자가 이후 갭 닫기 진도를 업데이트한다 (자가 신고)
3. 일부 사용자가 아웃컴에 도달한다 (졸업)
4. 졸업자의 궤적이 비교 코호트에 추가된다
5. 비교 코호트가 커지면 발산점 계산이 더 정밀해진다
6. 더 정밀한 발산점 = 더 높은 Aha Moment 품질 = 더 높은 전환율
7. 더 높은 전환율 = 더 많은 사용자 = 1로 복귀

```
더 많은 사용자 → 더 많은 졸업자 → 더 큰 코호트 → 더 정밀한 비교
      ↑                                                    |
      +────────────────── 더 높은 전환율 ←─────────────────+
```

**데이터 모트의 3개 층위**:

**층위 1: 코호트 크기 (양적 모트)**

비교 코호트가 크면 발산점 신뢰구간이 좁아진다. 후발 주자가 같은 수준의 비교를 제공하려면 동일한 크기의 코호트가 필요하다.

- 방어력: 중간. 충분한 자금이 있는 경쟁자는 LinkedIn 벤더 데이터로 빠르게 코호트를 구성할 수 있다.

**층위 2: 종단 데이터 (시간적 모트)**

Career Mirror가 쌓는 가장 가치 있는 데이터는 **동일 사용자의 시간별 궤적 변화**다. "이 사용자는 6개월 전에 이 갭이 있었고, 지금은 닫혔다"라는 종단(longitudinal) 데이터는 크로스섹셔널(한 시점) 데이터보다 발산점 인과 분석에 결정적이다.

- 방어력: 높음. 종단 데이터는 시간이 지나야만 축적되므로, 후발 주자가 자금으로 해결할 수 없다. Career Mirror가 6개월 먼저 시작하면 6개월치 종단 데이터가 영구적 우위.

**층위 3: 갭 닫기 인과 데이터 (행동적 모트)**

사용자가 발산점을 인지한 후 실제로 어떤 행동을 했고, 그 행동이 갭을 닫았는지 여부. 이것은 Career Mirror 안에서만 생성되는 독점 데이터이다.

- "외부 포트폴리오 갭"을 인지한 사용자 중, 실제로 블로그를 시작한 사용자는 48%
- 블로그를 시작한 사용자 중 6개월 후 이 발산점이 닫힌 사용자는 72%
- 이 데이터가 있으면 "이 갭을 닫으려면 X를 하세요, 성공 확률 Y%"라는 처방이 가능해진다

- 방어력: 매우 높음. 이 데이터는 Career Mirror 생태계 안에서만 생성된다. 외부에서 구매하거나 스크래핑할 수 없다.

**데이터 모트 방어 가능 임계값: 카테고리당 n=500, 총 n=3,000**

이 숫자의 근거:

1. **통계적 근거**: n=500이면 73%의 95% 신뢰구간이 [69%, 77%]. 4%p 오차. "약 73%"라고 말했을 때 실제로 69-77% 범위임을 보장. 경쟁자가 n=100으로 시작하면 [63%, 81%] 구간 — Career Mirror의 정밀도 우위가 명확.

2. **종단 데이터 근거**: 월 100명 신규 사용자, 6개월 리텐션 30% 가정. 12개월 후 약 200명의 6개월+ 종단 데이터 확보. n=500에 도달하려면 약 24-30개월이 필요하다. 후발 주자가 "오늘" 시작해도 이 데이터를 2년간 따라잡을 수 없다.

3. **행동 데이터 근거**: n=500에서 6개 카테고리 x 3개 발산점 유형 = 18개 갭 유형. 갭 유형당 평균 28명의 "갭 닫기 시도" 데이터. 이것이면 갭별 닫기 성공률의 방향성 추정이 가능하다.

4. **경쟁자 진입 비용**: n=3,000의 아웃컴 확인 코호트를 자금으로 구축하려면? LinkedIn 벤더 데이터로 커리어 궤적 3,000건을 구매하는 비용은 $300-3,000. 그러나 이것은 크로스섹셔널 데이터일 뿐, 종단 데이터와 행동 데이터는 포함되지 않는다. Career Mirror의 진짜 모트는 층위 2+3이며, 이것은 자금으로 복제 불가능하다.

**결론**: 카테고리당 n=500(총 3,000) 도달 시점(런칭 후 24-30개월)부터 데이터 모트가 방어 가능해진다. 그 전까지는 실행 속도와 커뮤니티 충성도(CLG)가 방어선이다.

### B5. 데이터 전략과 빠짐의 교차점

**데이터가 많아지면 제품이 더 중독적이 될 수 있는가?**

그렇다. 두 가지 경로가 존재한다.

**경로 1: 비교 정밀도 증가 → 갭 인지 강도 증가 → 불안 증폭**

코호트가 커지면 발산점이 더 정확해진다. 정확한 발산점은 "내 갭이 실제로 있다"는 확신을 높인다. 이 확신이 건강한 동기(갭을 닫겠다)로 이어지면 좋지만, 불안 루프(갭을 보고 → 불안 → 다시 확인 → 갭이 여전히 존재 → 더 불안)로 이어질 수 있다.

- 빠짐 조건 1(갭 재생산) 위험: 데이터가 정확해질수록 사용자가 "다 닫았다"고 느끼기 어려워진다. 항상 새 갭이 보인다. 이것이 프론티어 확장(건강)인지 인위적 갭 재생산(빠짐)인지 구분이 중요.

**경로 2: 행동 데이터 축적 → "처방" 기능 강화 → 제품 의존도 증가**

갭 닫기 인과 데이터(층위 3)가 축적되면, Career Mirror가 "이 갭을 닫으려면 X를 하세요"라는 처방을 제공할 수 있게 된다. 처방 기능은 사용자의 독립적 문제 해결 능력을 **대체**할 위험이 있다.

- 빠짐 조건 2(대안 차단) 위험: "Career Mirror가 말하는 대로만 하면 된다"는 인식이 형성되면, 사용자의 자율적 경력 설계 능력이 퇴화한다.

**데이터 큐레이션 원칙 (빠짐 방지)**:

**원칙 1: 갭 졸업 명시**

데이터가 정확해져도, 닫힌 갭은 "완료"로 확정하고 재표시하지 않는다. 새 갭은 반드시 "이전 갭을 닫았기 때문에 보이는 상위 수준의 갭"임을 명시한다.

구현: 갭 히스토리 뷰를 제공한다. "2026년 1월: 외부 아웃풋 갭 인지 → 2026년 4월: 블로그 시작 → 2026년 7월: 갭 해소. 그 결과 보이게 된 새 갭: 네트워크 구조 갭."

빠짐 audit GA-4(닫힌 갭 재활용 여부) 준수 장치.

**원칙 2: 처방이 아닌 옵션 제시**

행동 데이터 기반 추천을 제공하되, "해야 한다"가 아닌 "다른 사람들은 이렇게 했다"의 프레이밍. 동시에 "제품 없이 이 갭을 스스로 모니터링하는 법" 가이드를 함께 제공.

구현: "이 갭을 닫은 사람들의 73%는 블로그를 시작했습니다. 나머지 27%는 다른 방법을 사용했습니다. [모든 경로 보기] | [스스로 모니터링하는 법]"

빠짐 audit AU-1(독립 실행 테스트) + AU-3(정보 투명성) 준수 장치.

**원칙 3: 데이터 모트를 사용자의 자산으로**

Career Mirror의 데이터 모트가 커질수록, 그 데이터의 소유권이 사용자에게 있음을 명확히 한다. 사용자는 언제든 자기 데이터를 내보낼 수 있고, 비교 코호트 통계(개인 식별 불가능한 집계)도 내보낼 수 있다.

구현: "내 분석 결과 내보내기 (PDF)" + "코호트 비교 통계 내보내기 (CSV)"

빠짐 audit AU-4(데이터 이동성) 준수 장치.

## 통합: 활성화 x 데이터 x 빠짐 설계 원칙 요약

**원칙 1: Mirror Moment은 데이터 품질에 비례한다 — 그러므로 품질이 부족할 때 정직하라**

활성화 플로우의 Aha Moment 강도는 비교 데이터의 정밀도에 직접 비례한다. 합성 데이터로 런칭할 때 "47명과 비교했습니다"라고 말하되, 데이터 구성을 투명하게 공개한다. 정직함이 단기 전환율을 0.5-1%p 낮출 수 있지만, L5 사용자의 신뢰(Ethical_Coefficient)를 보존하여 D(WTP)_sustainable을 높인다. 거짓된 정밀도로 첫 인상을 좋게 만들면, 사용자가 나중에 "이 비교가 엉터리였다"는 것을 알게 되었을 때 신뢰가 영구히 파괴된다.

**원칙 2: 데이터 수집은 활성화의 부산물이어야 한다 — 별도의 데이터 수집 동기를 만들지 마라**

시드 코호트 모집과 사용자 온보딩이 동일한 5필드 폼을 사용한다. 사용자가 자기 갭을 보기 위해 입력하는 데이터가 곧 다른 사용자의 비교 코호트가 된다. 데이터 수집을 위한 별도의 인센티브(포인트, 뱃지, 게임화)를 최소화한다. 사용자가 "데이터를 제공하기 위해" 제품을 쓰는 것이 아니라 "자기 갭을 보기 위해" 제품을 쓰고, 그 과정에서 데이터가 축적되는 구조. 빠짐 audit 관점: 데이터 수집 인센티브가 과하면 AU-5(습관 vs 의도 비율)가 악화된다.

**원칙 3: 데이터 모트가 깊어질수록 졸업 경로를 넓혀라 — 모트와 자유는 반비례하지 않는다**

데이터가 축적될수록 제품의 비교 정밀도가 올라가고, 사용자가 제품 밖에서 같은 수준의 비교를 스스로 수행하기 어려워진다. 이것은 자연스러운 데이터 모트다. 그러나 이 모트가 사용자의 "졸업 불가능"으로 이어지면 안 된다. 해결: 데이터 모트가 깊어질수록, 사용자에게 "졸업 조건"을 더 명확하게 제시한다. "당신의 5개 발산점 중 4개가 닫혔습니다. 마지막 1개를 닫으면 이 목표를 졸업합니다." 졸업 후에는 무료 전환 + 멘토 역할 제안. 데이터 모트의 깊이와 사용자의 졸업 용이도가 함께 증가하는 구조가 VALUE GAP 이론의 Ethical_Coefficient = 1.0 이상 조건이다.
