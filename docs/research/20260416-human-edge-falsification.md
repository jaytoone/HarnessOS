# Human-Edge Falsification — 반증 기준 · 문화 경계 · 대체 설명

> **세줄결론**
> (판단) 9 primitives는 **보편적 인간 본성**이 아니라 **조건부 통계 경향**이다 — 각 primitive는 replication 실패·문화 반전·세그먼트 역작동 사례가 실증된다.
> (근거) 2015년 심리학 Reproducibility Project 이후 고전 실험 40%가 부분 실패; Hofstede/WEIRD 비판 이후 개인주의·서구 대학생 표본 편향 인정.
> (조건) primitive 적용 전 반드시 **replication 강도 + 문화 맥락 + 세그먼트 특성** 3축 검증 통과. 미통과 시 adversarial 재설계.

---

## 1. Replication Integrity — primitive별 실증 견고성

각 primitive에 replication 강도(●●● strong / ●● moderate / ● weak / ○ contested)와 실패 사례 첨부:

### 2.1 Scarcity — ●● moderate
- **견고 영역**: 물리적 제품 + 고관여 + 실재 제약 (e.g., 한정판 럭셔리, 이벤트 티켓)
- **약화 영역**: 디지털 상품, 저관여 (타이머 있어도 무한 대체재 인식)
- **Replication 실패**: 2019 Kupor et al. — 온라인 commodity 에서 "X개 남음" 배지가 전환률 무변동 (n=12,000)
- **대체 설명**: "한정"이 효과를 내는 것은 희소성보다 **품질 신호**(좋은 것이니 빨리 없어진다) 가설 — 제품이 신품질 시그널을 이미 가진 경우 중복 효과

### 2.2 Social Proof — ●●● strong (단, 경계 있음)
- **견고 영역**: 낯선 영역 + 불확실 + 타인 관찰 가능
- **약화 영역**: 전문가 자신감 높은 도메인 (역효과 — 대중과 차별화 욕구)
- **Replication 실패**: 2023 Milkman et al. mega-study — 백신 접종 독려 메시지 22종 중 peer social proof 효과 p=0.12, 일반 crowd 프레임은 거의 무효
- **대체 설명**: Goldstein 호텔 수건 효과 일부는 **descriptive norm** 때문 아니라 **메시지 현저성** 가설 — 어떤 메시지든 받으면 수건 재사용 ↑ 기저율 존재

### 2.3 Loss Aversion — ○ contested (2.25× 신화)
- **원래 수치**: 실험실 Kahneman-Tversky 1992, n=25 대학생, 2.25× 계수
- **최근 메타분석** (Brown et al. 2022, Nature HB): 실거래 상황 loss-gain ratio 중앙값 1.4~1.8×, 일부 도메인에서 무효
- **Replication 실패**: 주식 투자 의사결정 (n=8000 실거래): 기대 loss aversion 감지 불가. 보유 지속은 disposition effect(본전 회복 욕구)로 더 잘 설명
- **대체 설명**: 많은 loss aversion 관찰은 **reference point manipulation** 효과 — loss/gain 프레임이 아니라 기준점 설정이 결정 변수

### 2.4 Anchoring — ●●● strong
- **견고**: 가격 추정·수치 판단에서 거의 항상 관찰
- **약화**: 정보 전문가 (실거래 기반 대안 보유)
- **Replication 실패 드물음** (2016 다국적 replication 성공률 90%+)
- **대체 설명**: 앵커는 **scratchpad** 효과 — 생각의 출발점을 주는 것일 뿐, 방향성 편향은 맥락 의존

### 2.5 Reciprocity — ●● moderate
- **견고**: 개인적 관계, 저빈도 선물
- **약화**: 상업적 맥락에서 계산적으로 간파되면 역효과
- **Replication 실패**: Strohmetz 팁 실험(민트 동봉) 2022 대규모 replication에서 효과 크기 절반 (ES 0.2 → 0.09), 일부 국가(독일/스칸디) 무효
- **대체 설명**: 민트 효과 일부는 **서비스 품질 신호**(이 가게는 디테일 신경 쓴다) — 민트가 아닌 따뜻한 인사도 동일 효과

### 2.6 Commitment-Consistency — ●● moderate
- **견고**: 저커밋 → 중커밋 계단 (foot-in-the-door)
- **약화**: 고커밋 → 저커밋 하강 (자주 역효과)
- **Replication 성공률**: 약 50% (Freedman-Fraser 원실험, 2019 mega-analysis)
- **대체 설명**: 일관성 효과 일부는 **정체성 업데이트**(self-perception theory, Bem 1972) — "나는 X하는 사람이야" 자기정의 후 행동

### 2.7 Novelty-Seeking — ●●● strong (개인차 큼)
- **견고**: 도파민 prediction error 실증 (뇌과학, behavioural economics)
- **약화**: 변화 비용 높은 영역(전문 도구, B2B 엔터프라이즈) — status quo bias 우위
- **개인차**: novelty-seeking 성격 특성이 강한 개인과 약한 개인 간 반응 3-5× 차이
- **대체 설명**: "새로움 = dopamine"만으로 설명 불가. **사회적 대화 가치**(새 것 알면 대화 거리 생김) 가설이 더 많은 변동 설명

### 2.8 Meta-Insight Hunger — ●● moderate
- **견고**: 개인화된 진단 결과, 타인 대비 비교
- **약화**: Barnum effect — 일반화된 성격 묘사를 맞춤으로 오인. 이미 자기인식 높은 layer에서는 방어
- **Replication 실패**: MBTI 과학적 반증 (test-retest 50% 타입 변동), 하지만 **공유 바이럴성**은 유지 — 정확도와 심리 효과 분리
- **대체 설명**: 성격 테스트 효과는 인지적 정확성이 아닌 **정체성 스크립트 제공** 가치

### 2.9 Status Signaling — ●●● strong (단 세그먼트 의존)
- **견고**: 명품, 공개 소비
- **약화**: 상위 소득층 "조용한 럭셔리" (Han-Nunes-Drèze 2010 — 로고 크기 소득과 음의 상관)
- **Replication 성공률**: 85%+ (하지만 효과 방향은 세그먼트별 반전)
- **대체 설명**: 일부 status 관찰은 **품질 신호**(가격=품질) — Veblen이 아닌 정보 비대칭 보상

## 2. 문화 경계 (Cultural Boundaries)

Hofstede 6차원 중 3차원이 human-edge 효과 변동 주요 변수:

### 개인주의 vs 집단주의 (IDV)
- **높은 IDV (US, NL, DK)**: Commitment 계단, 개인 타겟 Meta-Insight 효과 강
- **낮은 IDV (KR, JP, MX)**: Social Proof "우리 집단" 프레임 강, 개인 선언형 Commitment 약화
- **예**: "혼자 해보세요" vs "친구들과 함께" 카피 효과 KR에서 3-4× 차이

### 권력 거리 (PDI)
- **높은 PDI (KR, CN, RU)**: Authority 기반 Social Proof(의사/전문가) 우위
- **낮은 PDI (NL, DK)**: Peer 기반 Social Proof만 작동, 권위 역효과 ("내가 왜 저 사람 따라")

### 불확실성 회피 (UAI)
- **높은 UAI (JP, FR, KR)**: Loss Aversion, Risk Reversal(환불 보장) 레버 강
- **낮은 UAI (US, UK, SG)**: Novelty, Scarcity 레버 강, Risk Reversal 상대 중요도 낮음

### WEIRD 편향 공식 경고
```
학술 실험 80%+ 표본 = WEIRD (Western, Educated, Industrialized, Rich, Democratic)
  → Henrich et al. 2010: "인류의 5%가 나머지 95%를 대표할 수 없다"
primitives 적용 전 확인: 참조 연구의 표본이 KR/타겟 시장과 일치하는가?
  불일치 = 효과 크기 할인 (x0.3-0.7) 또는 local 재현 실험 필수
```

## 3. 대체 설명 (Alternative Explanations)

관찰된 효과가 primitive가 아닌 다른 원인일 수 있는 상위 4가지 귀속 오류:

### 3.1 Confounding by Quality Signal
- **현상**: "한정판" 제품이 더 많이 팔림 → Scarcity 효과로 해석
- **대체**: 한정판은 보통 더 좋은 재료/디자인 = 품질 신호. Scarcity가 아닌 **품질 필터링** 설명
- **검증**: 동일 품질 무한 공급 vs 한정 A/B — 효과 격차 = 순수 Scarcity

### 3.2 Selection Effect
- **현상**: 리뷰 읽고 구매 전환 높음 → Social Proof 효과
- **대체**: 리뷰 읽는 유저 = 이미 high-intent. Proof가 원인이 아닌 **self-selection**
- **검증**: Random-assignment 리뷰 섹션 노출 vs 숨김 A/B

### 3.3 Expectation Effect (Placebo)
- **현상**: "프리미엄" 라벨 달면 만족도 ↑ → Status Signaling
- **대체**: 프리미엄 기대가 지각된 품질 ↑ — 실제 Status 효과 아닌 **expectation-based perception**
- **검증**: blind A/B (라벨만 다름, 품질 동일)

### 3.4 Novelty Artifact
- **현상**: 새 기능 출시 직후 engagement ↑ → Novelty 효과
- **대체**: **Hawthorne effect** — 관찰/변화 인식만으로 행동 변화, 지속성 없음
- **검증**: 30일 후 지표 복귀율 측정 — <80% 복귀면 artifact

## 4. Dead-Zone Conditions (primitive 무효 구간)

| Primitive | Dead-zone 조건 |
|---|---|
| Scarcity | 디지털 상품 + commodity + 무한 대체재 인식 가능 |
| Social Proof | 고전문성 도메인에 대중 증명 (역효과) / 리뷰 조작 감지된 플랫폼 |
| Loss Aversion | 이미 sunk cost 인식한 결정 / 현상유지 만족도 높은 고객 |
| Anchoring | 대체 가격 정보 다량 보유한 구매자 (B2B 시세 데이터 있음) |
| Reciprocity | 상업적 맥락에서 "비용 계산" 의심 받는 선물 |
| Commitment | 가치관 충돌하는 요청 (저커밋 → 이념 반대 고커밋) |
| Novelty | 변화 비용 높은 전문 도구 / 신뢰 누적 필요 영역 |
| Meta-Insight | 이미 성찰 성숙층 / Barnum 감지 층 |
| Status Signaling | 평등주의 강 clusters / 조용한 럭셔리 상위층 |

## 5. 최근 업데이트 (2020-2025 경계 갱신)

**감소한 효과**:
- Authority (Cialdini): 2010s 전문가 불신 시대, peer > authority 역전 [Pew 2021]
- Reciprocity 상업적: Z세대 광고 내성 증가, free 샘플 효과 2000년대 대비 약화
- Scarcity 가짜: 플랫폼 소비자보호 강화 (타이머 리셋 감지, "sold out 조작" 처벌)

**강해진 효과**:
- Meta-Insight: SNS·AI 개인화 시대 결과 공유 바이럴성 ↑
- Social Proof (peer 중심): UGC·TikTok 기반 peer 증명 효과 전례 없는 수준
- Status (커뮤니티 뱃지): 인사이더/레벨 시스템이 물리적 지위재를 대체 중

**새로 추가된 경계**:
- 2024 EU Digital Services Act + 2024 KR 소비자법 개정 → 다크패턴(강제 자동갱신, 취소 장벽) 규제
- AI 시대 "AI가 쓴 사회적 증명" 감지 기술 확산 → peer 증명의 진정성 검증 필수

## 7. Dead-Lever Signals (이 primitive를 빼야 할 때)

정량 지표 기반 kill:
- Replication 실패 보고 n≥2 축적 + 메타분석 ES<0.1 → 해당 primitive 인용 중단
- A/B 테스트 자사 데이터 효과 크기 < baseline 노이즈 3회 연속 → local replication 실패, 레버 비활성화
- 규제 리스크 신호 (법적 공방, 플랫폼 정책 변경) → Ethical_Coefficient 재평가

## 8. RWR (자연어 → T4 매핑)

- "이거 진짜 맞는 얘기야?" → replication 강도 확인 + 대체 설명 검토
- "미국 사례인데 한국에 되나?" → 문화 경계 (IDV/PDI/UAI) 체크
- "무조건 될 거야" → Dead-zone 조건 확인, 반증 가능성 서술 요구
- "심리학 연구가 이렇게 말함" → WEIRD 편향 + 2020s 업데이트 체크
- "카너먼 책에 나왔어" → 원 실험 n/샘플 확인 + 최근 메타분석 대조
- "효과 있을 거 같아" → ES 정량 제시 + A/B 실측 요구
