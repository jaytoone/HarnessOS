# WTP 전략 프레임워크 — 빠른 의사결정 가이드

## 핵심: WTP = 정체성 갭 해소 비용

고객이 지불할 의사는 기능적 갭이 아닌 **정체성 갭**을 얼마나 강렬하게 인식하는가에 따라 결정됩니다.

**WTP 발생 공식**
```
D(WTP) = [갭강도 × 달성가능성] × [사회적증폭] × [윤리계수]
```
→ **갭 공개 순간이 곧 판매**

---

## WTP 가치 계층 5단계 진단

| 계층 | 사용자 경험 | 판매 방식 | 가격대 | 신호 |
|------|----------|---------|------|------|
| **L1** | 사회적 존재감만 제공 | 무료 | - | 설득 필요, 전환율 낮음 |
| **L2** | 위임 (일반 상품화) | 프리미엄 캡 | - | "편하긴 한데..." |
| **L3** | 위임 (정체성 인접) | 핵심 유료 | ₩19-49k/mo | "이게 나같은데..." |
| **L4** | 메타인사이트 (알려진 미지) | 프리미엄 원타임 | 고가 | "아, 내가 몰랐네!" |
| **L5** | 메타인사이트 (미지의 미지) + 사회적 지분 | 선별적 접근 | 최고가 | "이거 없으면 경쟁 불가" |

**L5 = 최고 WTP** (체면 + 차별성 + 의존성)

---

## 진단: 당신 제품은 어느 계층?

**L1 체크박스**
- [ ] 사람들이 무료로도 쓰지만 끊임없이 설득이 필요한가?
- [ ] 세션 후 사용자가 제품 없이도 더 유능해 보이는가? ← **즉시 L2 이상으로 피벗**

**L2-L3 진단**
- [ ] 시간/피로 절약만 강조하는가? (L2)
- [ ] "이것 쓰는 사람 = 이런 종류" 정체성과 연결되는가? (L3 ✓)
- [ ] 체면/차별성이 명시적인가? (L3 ✓)

**L4-L5 신호**
- [ ] 사용 전후로 사용자의 자기 이해가 바뀌는가? (L4 ✓)
- [ ] "이거 없으면 다른 사람한테 지는 경쟁 상황"인가? (L5 ✓)

## 처방: 계층별 즉시 액션

| 계층 | 처방 | 핵심 메시지 |
|------|------|-----------|
| **L1 → L3** | "Silent Audit" 후크: 사용 데이터로 갭 시각화 (거울 순간) | "당신의 정체성, 공개되었습니다" |
| **L3 강화** | 수출 가능한 정체성 산출물 (배지/인증서), 카카오 오픈채팅 미러링 | 체면 증폭 × 동료 노출 |
| **L4 진입** | "Graduated Revelation": 점진적 깊이 → 메타인사이트 층 노출 | "당신이 몰랐던 당신" |
| **L5 목표** | 선별적 접근, 연간 청구 (프리미엄), 독점성 강조, 사회적 지분화 | "이것 없이는 불가능" |

## 피해야 할 함정 (빠짐 테스트)

**지금 각 세션 후 물어봐야 할 질문:**
```
"이 세션 후 사용자가 우리 제품 없이도 
더 유능하고 자신감 있어 보이는가?"
```

YES → 계층 상향 기회 (더 깊은 인사이트 / 정체성 강화 필요)
NO → 고착 위험 (위임만 되고 성장 없음 = 해지 신호)

**반-빠짐 방어**
- 진행률 원장 (진행 시각화)
- 단계적 공개 (다음 통찰이 어디 있는가)
- 수출 가능한 정체성 산출물
