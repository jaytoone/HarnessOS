## 프로토콜 개요

**목적**: 상대방이 어느 VALUE GAP 레벨(L1-L5)에 있는지, 정체성 이동성이 있는지, unknown-unknown 갭이 있는지 진단

**규칙**: 이론 언어("갭", "WTP", "레벨") 절대 사용 금지. 자연스러운 맥락 파악 대화처럼 진행.

## 1. 오프닝 (2분)

> "오늘은 제품 얘기보다 지금 하시는 일, 어떻게 하고 계신지를 먼저 듣고 싶어서요. 최근 3-6개월 기준으로 솔직하게 말씀해 주시면 됩니다. 틀린 답 없고, 제가 뭔가 팔려는 게 아니라 어떤 맥락에서 일하시는 분인지 이해하려는 거예요."

sales-guard 해제 + candid mode 활성화. 이 단계에서 제품 소개 금지.

---

## 2. 레벨 진단 질문 (5-6개)

**Q1. "지금 하시는 일, 1년 전이랑 비교하면 어떻게 달라졌나요?"**

| 신호 | 진단 |
|---|---|
| "많이 배웠어요" | L1-L2 |
| "내가 뭘 바꿨냐면..." | L3+ |
| "그냥 비슷해요" | 🔴 긴급성 낮음 |
| 변화 속도 불만 자발적 언급 | 🟢 L3+ |

---

**Q2. "요즘 일하면서 제일 에너지 쓰이는 게 뭐예요? 하기 싫어서가 아니라, 왜인지 모르게 잘 안 풀리는 것."**

| 신호 | 진단 |
|---|---|
| "그냥 바빠요" (모호) | L1-L2 |
| 명명된 반복 마찰 | L3 |
| 천장이 있는데 타인에게 보이지 않는다 | 🟢 L4-L5 |
| 제대로 이름 못 붙이고 멈춤 | 🟢 Unknown-unknown 전 신호 |

---

**Q3. "같은 일 하는 사람들 중에, 왜 저 사람은 더 잘 되지? 싶은 케이스가 있어요?"**

| 신호 | 진단 |
|---|---|
| "운이 좋은 것 같아요" | L1-L2, Social Amplifier 약함 |
| "그 사람은 뭔가 다른 걸 알고 있는 것 같아요" | 🟢 L4, Social Amplifier ON |
| 참조 집단 없음 | 🔴 WTP 낮음 |
| 구체적 인물 + 델타 관찰 + 좌절감 | 🟢 L4-L5 |

---

**Q4. "본인 기준에서, 지금 실력이랑 외부에서 인정받는 것 사이에 갭이 있다고 느껴요?"**

| 신호 | 진단 |
|---|---|
| "실력은 있는데 알려지지 않았어요" | L3 |
| "어떻게 알려야 하는지를 모르겠어요" | 🟢 L4-L5 (unknown-unknown 간접 표현) |
| "딱 맞는 것 같아요" | 🔴 갭 인식 없음 |
| 감정 고조 + 비유도 예시 제공 | 🟢 |

---

**Q5. "지금 하는 방식 그대로 2년 뒤에도 하고 있으면 어떨 것 같아요?"**

| 신호 | 진단 |
|---|---|
| "괜찮을 것 같아요" | 🔴 긴급성 없음 |
| 가벼운 불안 | L3 |
| 명명된 공포 | L4-L5 |
| "나 자신이 아닌 것 같을 것 같아요" 류 정체성 결과 | 🟢 L5 |

---

**Q6. "일 잘 된다는 게 본인한테 어떤 의미예요? 돈, 인정, 자유 중에 어떤 게 제일 먼저예요?"**

| 신호 | 진단 |
|---|---|
| 돈 우선 | Functional_Gap 지배 (L1-L3) |
| 인정 또는 자율 우선 | 🟢 Social_Position_Gap 또는 정체성 갭 (L4-L5) |
| 사회적으로 올바른 답만 | 🔴 ICP 불명확 |

---

## 3. 정체성 이동성 프로브 (2-3개)

**Q7. "지금 회사나 클라이언트 없이, 내일 바로 일을 구한다면 뭘 들고 나갈 수 있어요?"**

- 🟢 구체적 아웃풋, 결과, 평판 → 이동성 높음 (L5 ICP)
- 🔴 "경력서 내야죠" / 현 고용주 브랜드 참조 → 이동성 낮음

**Q8. "본인 이름으로 뭔가 쌓고 있다는 느낌이 있어요, 아니면 지금 있는 데서 쌓고 있는 느낌이에요?"**

- 🟢 "내 이름으로 쌓고 싶은데 잘 안 되고 있어요" → L5 포텐셜 높음, 갭 이미 체감

**Q9 (옵션). "지금 하는 일을 아는 사람이 업계 기준으로 몇 명이나 될 것 같아요?"**

- 낮은 수치 + 불만족 → Social Amplifier 갭 활성화

---

## 4. Unknown-Unknown 표면화 (2-3개)

"모르는 게 뭔지 아세요?"는 금지. 대비와 제3자 프레이밍으로 우회.

**Q10. "비슷한 배경인데 훨씬 빠르게 간 사람 보면, 그 사람이 뭘 알았다고 생각해요?"**

- 상대방의 답 = 자신의 unknown-unknown 투영
- 구체적 추론 → 갭 인식 가능성 높음

**Q11. "지금까지 혼자 해결해온 것 중에, 나중에 알고 보니 더 빠른 방법이 있었던 경험 있어요?"**

- 회고적 갭 인식 활성화 → 현재 unknown-unknown 저항 감소

---

## 5. 달성가능성 확인 (1-2개)

**Q12. "만약 그 갭이 실제로 좁혀질 수 있다면, 6개월 안에 가능할 것 같아요?"**

- 🟢 "가능할 것 같은데, 어떻게 하는지 모르겠어요" → Attainability 잠재, 활성화 가능
- 🔴 "저는 좀 특수한 케이스라서" → 구조적 귀인, Attainability 낮음

---

## 6. Social Amplifier 확인 (1-2개)

**Q13. "지금 이 문제가 해결되거나 안 되거나, 주변에서 알아채는 사람이 있어요?"**

- 🟢 구체적 인물 명명 (상사, 클라이언트, 커뮤니티 동료) → Social Amplifier ON
- 🔴 "딱히 없어요" → 갭이 사회적 참조 집단에 비가시, WTP 낮음

---

## 7. 클로징 (1분)

갭을 이름 붙이되, 솔루션은 제시하지 않는다.

> "말씀 들으니까, [Q5에서 나온 구체적 우려]랑 [Q10에서 나온 관찰] 사이에 뭔가 연결되는 게 있는 것 같아요. 혹시 그 부분 나중에 좀 더 얘기해 봐도 될까요?"

상대방 자신의 언어로 긴장을 반영하고 이름 붙임 — 솔루션 아님. **이 순간이 판매다.**
