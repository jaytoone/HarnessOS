## 1. VALUE GAP이 예측하는 Career Mirror WTP

### 공식 리마인더

```
D(WTP)_instantaneous = [Gap_Intensity × Attainability] × [Social_Amplifier]
D(WTP)_sustainable   = D(WTP)_instantaneous × Ethical_Coefficient

Gap_Intensity = Functional_Gap + Social_Position_Gap
```

Career Mirror는 unknown-unknown 갭을 공개하는 제품이다. 각 L-Level 사용자에 대해 공식의 각 변수를 추정하고, WTP 범위를 도출한다.

### L3 사용자: Identity-Adjacent Delegation

**ICP 프로필**: "내 이름으로 쌓고 싶은데 어떻게 하는지 모르겠다" — 외부 가시성이 있는 전문직, 갭의 존재는 인식하지만 구체적 경로를 모름.

**변수 추정**:
- `Functional_Gap`: 중간 (0.5/1.0) — 갭이 있다는 건 알지만 구체적 항목은 모호. "뭔가 부족하다"는 느낌은 있으나 "정확히 뭐가"는 불명확
- `Social_Position_Gap`: 낮음-중간 (0.3/1.0) — 동료 중 앞서가는 사람이 보이지만 아직 직접적 위협은 아님
- `Gap_Intensity`: 0.5 + 0.3 = 0.8
- `Attainability`: 높음 (0.8/1.0) — Career Mirror가 제시하는 갭은 "12개월 앞선 동료가 이미 닫은 것" → 불가능해 보이지 않음
- `Social_Amplifier`: 낮음-중간 (1.2) — L3는 갭을 타인에게 적극 공유하지 않음. 갭이 개인적 고민 단계

**D(WTP)_instantaneous 계산**:
```
D(WTP)_L3 = (0.8 × 0.8) × 1.2 = 0.768
```

**해석**: 기준 WTP 스케일에서 0.768은 "확실히 지불 의향 있으나 프리미엄 가격은 저항" 구간. 한국 B2C 지식 서비스 기준 월 ₩15,000-35,000 대역에 매핑.

**Ethical_Coefficient**: Career Mirror의 anti-빠짐 설계 (닫힌 갭 재활용 안 함, 새 프론티어만 제시) → Ethical_Coefficient ≈ 0.85

**D(WTP)_sustainable**:
```
D(WTP)_sustainable_L3 = 0.768 × 0.85 = 0.653
→ 지속 가능 WTP 범위: ₩15,000-29,000/월
```

### L4 사용자: Meta-Insight (Known Unknown)

**ICP 프로필**: 자신의 갭을 이름 붙일 수 있고, 메타-인사이트가 활성화된 상태. "내 네트워크가 편향돼 있다는 건 알지만, 어떤 방향으로 편향인지 모르겠다."

**변수 추정**:
- `Functional_Gap`: 높음 (0.7/1.0) — 갭을 명명할 수 있으므로 기능적 결핍이 구체적. 하지만 Career Mirror가 보여주는 "발산점 3개" 중 1-2개는 여전히 새로운 정보
- `Social_Position_Gap`: 중간 (0.5/1.0) — L4 사용자는 동료 비교에 민감. 자신의 갭을 아는 만큼 타인의 갭도 추정하며, 상대적 위치를 의식
- `Gap_Intensity`: 0.7 + 0.5 = 1.2
- `Attainability`: 높음 (0.85/1.0) — 메타-인사이트가 있으므로 "닫을 수 있다"는 자기 효능감이 L3보다 높음
- `Social_Amplifier`: 중간-높음 (1.5) — L4 사용자는 인사이트를 동료에게 공유하는 경향. "이런 갭이 있더라"가 대화 소재. Career Mirror의 피어 코호트 매칭이 이 계수를 증폭

**D(WTP)_instantaneous 계산**:
```
D(WTP)_L4 = (1.2 × 0.85) × 1.5 = 1.53
```

**해석**: 1.53은 L3의 약 2배. "기꺼이 지불하며, 가격보다 가치 판단이 우선" 구간. 한국 B2C 기준 월 ₩39,000-69,000 대역, 또는 단건 리포트 ₩100,000-200,000.

**Ethical_Coefficient**: L4 사용자는 갭 닫기 진행이 빠름 → 제품 의존도 감소 속도도 빠름. Ethical_Coefficient ≈ 0.90 (건강한 해지가 자연스러움)

**D(WTP)_sustainable**:
```
D(WTP)_sustainable_L4 = 1.53 × 0.90 = 1.377
→ 지속 가능 WTP 범위: ₩39,000-59,000/월
```

### L5 사용자: Meta-Insight (Unknown Unknown) + Identity Portability

**ICP 프로필**: 갭의 존재 자체를 모르는 상태에서 Career Mirror가 처음으로 공개. "이걸 몰랐다는 사실 자체를 몰랐다." 정체성 이동성이 높은 전문직 — 외부 평판이 고용 기관과 독립적.

**변수 추정**:
- `Functional_Gap`: 매우 높음 (0.9/1.0) — unknown-unknown이므로 갭이 공개되는 순간 충격이 큼. "성공 코호트의 73%는 이 시점에 외부 포트폴리오를 갖고 있었다. 당신은 없다" — 이 한 문장의 갭 강도가 L3-L4를 압도
- `Social_Position_Gap`: 높음 (0.7/1.0) — 정체성 이동성이 높다는 것은 외부 평판에 의존한다는 뜻. 갭이 외부에 보이면 커리어 전체가 흔들림
- `Gap_Intensity`: 0.9 + 0.7 = 1.6
- `Attainability`: 중간 (0.7/1.0) — unknown-unknown이었으므로 닫는 경로가 처음부터 학습 필요. L4보다 약간 낮음
- `Social_Amplifier`: 높음 (1.8) — L5 사용자의 갭 공개는 사회적 사건. "이걸 몰랐다"를 커뮤니티에서 공유하면 동시 갭 공개 효과 발생. Career Mirror의 CLG 메커니즘이 이 계수를 최대화

**D(WTP)_instantaneous 계산**:
```
D(WTP)_L5 = (1.6 × 0.7) × 1.8 = 2.016
```

**해석**: 2.016은 L3의 약 2.6배, L4의 약 1.3배. "가격이 문제가 아니라 접근이 문제" 구간. 한국 B2C 기준 월 ₩59,000-99,000 대역, 또는 코호트 기반 프리미엄 접근.

**Ethical_Coefficient**: L5 unknown-unknown 갭은 닫는 데 시간이 걸림 → 장기 구독 자연스러움. 단, Career Mirror의 anti-빠짐 설계가 유지되면 Ethical_Coefficient ≈ 0.88

**D(WTP)_sustainable**:
```
D(WTP)_sustainable_L5 = 2.016 × 0.88 = 1.774
→ 지속 가능 WTP 범위: ₩59,000-89,000/월
```

### L-Level별 WTP 요약

| Level | D(WTP)_inst | D(WTP)_sust | 월 WTP 범위 | 핵심 동인 |
|---|---|---|---|---|
| L3 | 0.768 | 0.653 | ₩15,000-29,000 | "어떻게 하는지 모르겠다" — 경로 갈증 |
| L4 | 1.530 | 1.377 | ₩39,000-59,000 | "어떤 방향인지 모르겠다" — 정밀 진단 갈증 |
| L5 | 2.016 | 1.774 | ₩59,000-89,000 | "이걸 몰랐다" — unknown-unknown 충격 |

## 2. Korean Benchmark Calibration

### 한국 제품 L-Level 매핑

Section 1의 WTP 범위를 iter 4 한국 시장 데이터로 보정한다.

**퍼블리 (₩15,000-20,000/월)**:
- iter 4 진단: L2-L3 경계
- Career Mirror 대비: 퍼블리는 갭 시각화 없이 콘텐츠만 제공. L3 WTP의 하한선 역할
- 시사점: Career Mirror L3 가격이 퍼블리보다 높으려면 갭 시각화가 "콘텐츠 읽기"보다 명확히 우월한 가치를 전달해야 함
- **L3 보정**: ₩19,900이 퍼블리 천장이면, Career Mirror L3는 이것을 넘되 L4와 구간이 겹치면 안 됨 → **₩24,900-29,000이 L3 적정 구간**

**폴인 (₩15,000-20,000/월)**:
- iter 4 진단: L3 (퍼블리보다 정체성 인접도 높음)
- Career Mirror 대비: 폴인은 트렌드 추적 정체성. Career Mirror는 개인화된 갭 공개 → 더 높은 정체성 관여도
- **L3 상한 확인**: 폴인도 ₩20,000 근처에서 실링 → Career Mirror가 ₩29,000을 받으려면 "내 커리어에 대한 개인화된 진단"이라는 프레이밍이 필수

**리멤버 프리미엄 (수익화 미약, 잠재력 L4-L5)**:
- iter 4 진단: 현재 L3이지만 네트워크 드리프트 리포트가 있으면 L5 가능
- Career Mirror 대비: 리멤버가 L5를 실행하지 않은 상태이므로 직접 가격 비교 불가
- **L5 바닥 추정**: 한국에서 코호트 기반 프리미엄 서비스 (예: 세이노의 가르침 유료 오프라인 모임, 비공개 마스터클래스) → ₩50,000-100,000/월 구간이 "진지한 자기 투자"로 인식되는 임계점

**클래스101 단건 (최대 ₩200,000)**:
- iter 4 진단: L2
- Career Mirror 대비: 단건 ₩200,000은 "진지한 투자 신호" (iter 2). L4 단건 가격의 참조점
- **L4 단건 보정**: Career Mirror의 심층 진단 리포트 단건 가격은 ₩150,000-250,000이 합리적

### Anchor Points 도출

| Anchor | 가격 | 근거 |
|---|---|---|
| L3 바닥 | ₩19,900 | 퍼블리 천장 = Career Mirror L3 진입점 |
| L3 천장 | ₩29,000 | 폴인 대비 개인화 프리미엄 한계 |
| L4 중간점 | ₩49,000 | L3 천장의 ~1.7배, 퍼블리-폴인 구간과 분리 |
| L4 단건 | ₩190,000 | 클래스101 단건 참조 (₩200,000) 미만 심리적 가격 |
| L5 바닥 | ₩59,000 | 코호트 프리미엄 서비스 임계점 |
| L5 천장 | ₩89,000 | 월 ₩100,000 심리적 저항선 미만 |

## 3. Freemium Gate 설계

### Free Tier: "갭 공개 순간" 생성기

Free tier의 목적은 단 하나다: **사용자가 자신의 갭을 눈으로 보는 순간을 만드는 것**. 이 순간이 판매의 전부다.

**Free로 제공하는 것** (iter 5 MVP spec 기준):
1. **온보딩 5필드 폼**: 역할 시퀀스, 회사 단계, 외부 아웃풋 유무, 자가 신고 목표 아웃컴 — 계정 생성 없이 즉시 입력
2. **궤적 시각화 전체**: 분할 화면 (좌: 내 궤적, 우: 목표 코호트 중앙값)
3. **발산점 라벨 3개**: 어디서 갈라졌는지 위치와 이름 공개
4. **익명화 공유 잠금 해제**: 결과를 익명으로 공유하면 발산점 상세 1개 무료 잠금 해제 (CLG 배포 유발)

**Free에서 블러 처리하는 것** (= Paid Gate):
- 발산점별 **인과 분석** ("왜 이 갭이 생겼는가")
- 현재 프로필 기반 **닫기 기간 벤치마크** ("이 갭을 닫는 데 평균 N개월")
- **피어 코호트 매칭** (같은 경로에서 12개월 앞선 사람 연결)
- **월간 재분석** (커리어 데이터 업데이트 시 갭 재계산)

### Upgrade Trigger 메커니즘

**"갭 공개 순간"에서 "결제 CTA"까지의 경로**:

```
[Step 1] 사용자 5필드 입력 (3분)
         ↓
[Step 2] 궤적 시각화 렌더링 — 발산점 3개 펄스 마커
         ↓ (여기까지 Free)
[Step 3] 발산점 호버 → 블러된 인과 텍스트 미리보기
         카피: "이 갭이 왜 생겼는지, 당신 위치에서 닫는 데 걸린 평균 기간은?"
         ↓
[Step 4] CTA 노출 — 질문 자체가 판매 도구
         "경로 보기" 버튼 = 전환 순간
```

**PQL 트리플 시그널** (iter 5 정의):
1. 갭 시각화 확인 (`gap_visualization_rendered`)
2. 블러 상세 호버 (`divergence_point_hover`)
3. 7일 이내 재방문

트리플 시그널 충족 시 → 인앱 넛지 + KakaoTalk 휴먼 메시지 자동 트리거.

### Activation Hook 선택

iter 2의 3가지 Hook 중 Career Mirror에 적합한 조합:

- **Hook A (Mirror Moment)**: 핵심 — 궤적 비교 시각화 자체가 Mirror Moment
- **Hook B (Silent Audit)**: 보조 — 발산점 라벨이 "당신이 인식하지 못한 패턴" 역할
- **Hook C (Social Exposure)**: L4 이상 전용 — 피어 코호트 매칭이 Social Exposure Event

## 4. 가격 티어 구조

| 티어 | 월 가격 | 연간 가격 | ICP L-Level | 핵심 가치 | Gate 메커니즘 |
|---|---|---|---|---|---|
| Free | ₩0 | ₩0 | L1-L2 | 갭 가시화 (궤적 비교 + 발산점 라벨) | 5필드 입력만으로 즉시 이용 |
| Core | ₩24,900 | ₩239,000 (20% 할인) | L3 | 발산점 인과 분석 + 닫기 기간 벤치마크 | 블러 해제 — 호버 → CTA |
| Pro | ₩49,000 | ₩470,000 (20% 할인) | L4 | 피어 코호트 매칭 + 월간 재분석 + 심층 리포트 | Core 사용 30일 후 업그레이드 제안 |
| Expert | ₩79,000 | ₩758,000 (20% 할인) | L5 | 코호트 전용 인사이트 + 1:1 갭 닫기 로드맵 + 분기 전략 리뷰 | 초대제 — Pro 사용자 중 활성도 상위 10% |

### 티어별 이론적 근거

**Free (₩0)**:
- 이론: L1-L2 사용자에게 paywall은 이탈을 낳는다 (iter 2). Free tier는 갭을 보여주되 해결책은 잠금 → 갭 공개 순간이 Free의 유일한 임무
- 가치: 사용자가 비용 0으로 자신의 unknown-unknown을 처음 보게 됨. 이 경험 자체가 CLG 배포의 연료

**Core (₩24,900/월)**:
- 이론: L3 D(WTP)_sustainable = 0.653 → WTP 범위 ₩15,000-29,000. ₩24,900은 이 범위의 상위 80% 지점
- 퍼블리(₩19,900) 대비 ₩5,000 프리미엄 = 개인화된 갭 진단의 가치. 폴인(₩20,000) 대비 ₩4,900 프리미엄 = 정체성 인접 우위
- 연간 ₩239,000 (월 ₩19,917) → 퍼블리 월정액과 동가 — "1년 투자" 프레이밍이 한국에서 강함 (iter 2)
- 전환율 가정: Free → Core **8-12%** (한국 지식 서비스 벤치마크 5-10%, Career Mirror의 갭 공개 순간이 상회)

**Pro (₩49,000/월)**:
- 이론: L4 D(WTP)_sustainable = 1.377 → WTP 범위 ₩39,000-59,000. ₩49,000은 중간점
- 피어 코호트 매칭이 Social_Amplifier를 직접 활성화. 같은 경로에서 12개월 앞선 사람과의 연결 = "달성 가능성" 극대화
- 월간 재분석 = 갭 닫기 진행 모니터링. L4 사용자의 메타-인사이트가 데이터로 검증되는 순간
- 전환율 가정: Core → Pro **15-20%** (L3→L4 진화는 갭 닫기 경험이 트리거)

**Expert (₩79,000/월)**:
- 이론: L5 D(WTP)_sustainable = 1.774 → WTP 범위 ₩59,000-89,000. ₩79,000은 상위 75% 지점
- 초대제: L5 희소성 원칙 (iter 2 — "동료 중 누가 이 티어를 보유하는지가 보이는 것 자체가 제품 피처")
- 코호트 전용 인사이트 = 일반 데이터가 아닌 Expert 코호트에서만 생성되는 패턴
- 1:1 갭 닫기 로드맵 = unknown-unknown이 식별된 후 구체적 실행 계획. 분기 전략 리뷰 = 장기 accountability
- 전환율 가정: Pro → Expert **5-8%** (초대제이므로 자연 제한)

### 단건 상품 (L4 보완)

iter 2의 발견: 한국 L4는 월정액보다 단건 고가가 "진지한 투자" 신호.

| 단건 상품 | 가격 | 내용 |
|---|---|---|
| 심층 갭 리포트 | ₩190,000 | 발산점 3개 × 인과 분석 + 벤치마크 + 구체적 닫기 로드맵 (PDF 20페이지) |
| 코호트 1:1 매칭 세션 | ₩290,000 | 12개월 앞선 피어 1명과 90분 구조화 대화 + 사전 갭 분석 제공 |

## 5. Social Amplifier를 활용한 가격 탄력성

### 이론: Social_Amplifier는 신호 전달 계수

v2 이론에서 Social_Amplifier는 "기능적 갭이 중요한 타인에게 보이는 정도"로 재정의되었다. 순수 곱셈 인자가 아니라, 갭의 사회적 가시성을 조절하는 계수다.

Career Mirror에서 이 계수가 가격 탄력성에 미치는 영향:

### Social Proof 메커니즘 → L4 프리미엄 정당화

**메커니즘 1: 갭 공유 피드백 루프**
```
사용자 A가 갭 결과 익명 공유 (Free tier 기능)
    ↓
동료 B가 링크 클릭 → "나도 해볼까" → 5필드 입력
    ↓
동료 B의 갭 공개 순간 → "A도 이걸 했구나" (사회적 검증)
    ↓
A와 B 모두 갭이 "실재한다"고 느낌 → 갭 닫기 WTP 상승
```

이 루프가 돌 때마다 Social_Amplifier가 1.2 → 1.5 → 1.8로 증가. A가 처음에 L3 Core 사용자였다면, 동료 3명이 공유 루프에 들어오면 L4 Pro로의 업그레이드 저항이 감소.

**메커니즘 2: 피어 코호트 밀도 효과**
- Pro 사용자는 같은 경로의 12개월 앞선 피어와 매칭
- 매칭된 피어가 많을수록 "이 경로가 실재한다"는 증거가 강해짐
- 피어 코호트 밀도가 높은 경로에서는 Pro → Expert 업그레이드가 자연스러움

**메커니즘 3: Expert 초대의 사회적 신호**
- Expert 티어가 초대제라는 사실 자체가 Social_Amplifier
- "나는 초대받았다" = 갭 닫기 상위 10%라는 사회적 증명
- 이 신호가 Expert 유지율을 높이고, Pro 사용자의 Expert 열망을 자극

### 가격 탄력성 모델

Social_Amplifier 수준에 따른 WTP 변동:

| Social_Amplifier | 조건 | L3 WTP | L4 WTP | L5 WTP |
|---|---|---|---|---|
| 1.0 (baseline) | 혼자 사용 | ₩15,000 | ₩30,000 | ₩45,000 |
| 1.2 (low) | 공유 1회 | ₩19,000 | ₩39,000 | ₩55,000 |
| 1.5 (medium) | 동료 3명 활성 | ₩24,900 | ₩49,000 | ₩69,000 |
| 1.8 (high) | 코호트 활성 | ₩29,000 | ₩59,000 | ₩79,000 |

Career Mirror의 가격은 Social_Amplifier = 1.5 (medium) 기준으로 설정했다. CLG 채널이 활성화되면 실제 Social_Amplifier가 1.8에 근접하며, 이때 할인 대신 추가 가치(피어 매칭, 코호트 인사이트)로 잉여를 흡수.

## 6. 빠짐 방지 x 수익 극대화 설계

### iter 13의 핵심 통찰: 건강한 제품 = 높은 지속 가능 WTP

Ethical_Coefficient가 높을수록 D(WTP)_sustainable이 D(WTP)_instantaneous에 가깝다. 중독성 제품은 instantaneous는 높지만 sustainable이 급락 → 가속 이탈 + 규제 리스크.

Career Mirror는 Ethical_Coefficient를 의도적으로 높게 유지하면서 수익을 극대화해야 한다.

### 가격 규칙: Ethical_Coefficient 보호

**규칙 1: 갭 닫기 → 가격 감소 허용**
- 사용자가 발산점 3개를 모두 닫으면 (자가 신고 기반) → 다음 아웃컴 티어로 재계산
- 만약 새 갭이 충분하지 않으면 → 다운그레이드 제안 (Pro → Core, 또는 Core → Free)
- "제품이 스스로 덜 필요해지면서 프론티어를 확장" — iter 5의 anti-빠짐 원칙
- **수익 영향**: 월 해지율 증가하지만 NPS + 재구매율(다음 커리어 전환기) 극대화

**규칙 2: 연간 플랜 = 책임 수평선**
- 연간 플랜은 20% 할인이지만 진짜 가치는 **accountability horizon**
- 12개월간 갭 닫기를 추적한다는 커밋먼트 = 빠짐 방지 + LTV 증가
- 연간 플랜 가입자는 월간 재분석을 자동 수신 → "아직 닫지 못한 갭"이 매월 리마인드
- **수익 영향**: 연간 플랜 비율 50% 이상 시 LTV 1.8배 (해지율 감소 효과)

**규칙 3: 해지 시 갭 아카이브 제공**
- 유료 해지 시 지금까지 생성된 모든 갭 분석 + 진행 기록을 PDF로 내보내기
- "당신이 쌓은 것은 당신의 것" — iter 2의 Exportable Identity Artifacts 원칙
- **수익 영향**: 해지 마찰 제거 → 재가입 장벽 낮춤. 해지 후 6개월 이내 재가입율 목표 15%

**규칙 4: 빈 갭 상태 과금 금지**
- 시스템이 새로운 갭을 공개하지 못하면 (시드 코호트 부족, 사용자 목표가 코호트 밖) → 해당 월 과금 유예
- "가치 없는 달에 돈을 받지 않는다" → 신뢰 = 장기 LTV의 연료
- **수익 영향**: 단기 매출 감소 (추정 5-8%) 대비 해지율 개선 (추정 20-30%)

### Ethical_Coefficient 모니터링 지표

| 지표 | 건강 신호 | 경고 신호 |
|---|---|---|
| 월간 갭 닫기 자가 신고율 | > 30% | < 10% (제품 미활용) |
| 갭 닫기 후 상위 티어 재계산 비율 | > 50% | < 20% (프론티어 정체) |
| 해지 후 6개월 재가입율 | > 15% | < 5% (가치 소멸) |
| 무료 공유 후 가입 전환 | > 5% | < 1% (CLG 루프 미작동) |

## 8. 가격 실험 설계

### 목표

이론에서 도출한 가격(₩24,900 / ₩49,000 / ₩79,000)이 실제 WTP와 얼마나 일치하는지 검증. 론칭 전 2주 내에 실행 가능한 최소 실험.

### 실험 1: Van Westendorp PSM (1주차)

iter 7에서 제안한 Van Westendorp Price Sensitivity Meter를 Career Mirror에 적용.

**대상**: 시드 코호트 60명 + CLG 채널 추가 모집 40명 = 100명  
**방법**: 5필드 입력 + 갭 시각화 경험 후 4개 질문

```
Q1: "이 서비스가 얼마면 '너무 싸서 품질이 의심된다'고 느끼시겠습니까?"
Q2: "이 서비스가 얼마면 '싸다, 좋은 거래다'라고 느끼시겠습니까?"
Q3: "이 서비스가 얼마면 '비싸지만 고려할 수 있다'고 느끼시겠습니까?"
Q4: "이 서비스가 얼마면 '너무 비싸서 절대 안 쓴다'고 느끼시겠습니까?"
```

**분석**: 4개 누적 분포 교차점에서 최적 가격대 도출. VALUE GAP 이론 예측(₩24,900 Core)과 실제 PSM 결과의 일치도 측정.

**실행 타임라인**:
- Day 1-2: Typeform/Tally 설문 구성 + 갭 시각화 목업 제작
- Day 3-5: 시드 코호트 + CLG 채널 배포
- Day 6-7: 데이터 수집 완료 + 분석

### 실험 2: A/B 가격 테스트 (2주차)

**대상**: 실험 1 이후 신규 유입자 (목표 200명)  
**방법**: 갭 시각화 경험 후 CTA에서 가격 A/B

```
Group A (n=100): Core ₩24,900 / Pro ₩49,000
Group B (n=100): Core ₩19,900 / Pro ₩39,000
```

**측정**: 
- CTA 클릭율 (결제 의향 proxy)
- 실제 결제 전환율 (KakaoPay/Toss 테스트 결제)
- Group A vs B의 ARPU 차이

**판단 기준**:
- Group A 전환율이 Group B의 70% 이상 → ₩24,900 유지 (높은 가격 × 적당한 전환 = ARPU 최적)
- Group A 전환율이 Group B의 50% 미만 → ₩19,900으로 하향 조정
- 중간 → 추가 실험 필요, ₩22,000 구간 테스트

### 실험 3: Social Amplifier WTP 증분 측정

iter 7의 Social_Amplifier 실험과 병행:

**대상**: 실험 2 Group A 중 전환자  
**방법**: 전환 후 30일간 "공유 잠금 해제" 사용 빈도 추적

```
Subgroup A1: 공유 0회 (Social_Amplifier ≈ 1.0)
Subgroup A2: 공유 1-2회 (Social_Amplifier ≈ 1.2)
Subgroup A3: 공유 3회+ (Social_Amplifier ≈ 1.5)
```

**측정**: 각 Subgroup의 Core → Pro 업그레이드율 차이. Social_Amplifier가 높은 그룹이 Pro 전환율도 높으면 → "공유가 WTP를 증가시킨다"는 이론 검증.

### 실험 타임라인 요약

```
Week 1:
  Day 1-2: 설문 + 목업 제작
  Day 3-5: Van Westendorp PSM 배포 (100명)
  Day 6-7: PSM 데이터 분석 → 가격 가설 검증/수정

Week 2:
  Day 8-10: A/B 가격 테스트 셋업 (KakaoPay 테스트 모드)
  Day 11-14: 200명 유입 → A/B 전환 데이터 수집
  Day 14: 가격 결정 → MVP Week 6-8 결제 통합에 반영

Social Amplifier 실험: Week 2 전환자 대상 30일 추적 (MVP 빌드와 병행)
```

### 의사결정 매트릭스

| PSM 결과 | A/B 결과 | 의사결정 |
|---|---|---|
| PSM 최적 = ₩22,000-27,000 | A>B (70%+) | ₩24,900 확정 |
| PSM 최적 = ₩22,000-27,000 | A<B (50%-) | ₩19,900으로 하향 |
| PSM 최적 = ₩15,000-20,000 | A/B 무관 | ₩19,900으로 하향 + Pro 가격도 재조정 |
| PSM 최적 = ₩28,000-35,000 | A>B (70%+) | ₩29,000으로 상향 |
| PSM 최적 = ₩28,000-35,000 | A<B (50%-) | ₩24,900 유지 (PSM 과대 가능성) |
