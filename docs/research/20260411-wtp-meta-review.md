# WTP 연구 시리즈 메타-리뷰 (iter 1-7)

**Date**: 2026-04-11  
**Method**: live-inf iter 8/∞ — review-harsh-critic 내부 감사  
**Verdict**: REVISE  
**Scope**: iter 1-7 전체 (이론 → 설계 → 실험까지) 내부 일관성 + 과잉주장 감사

---

## 총평

이론적으로 흥미롭고 설명력 있는 WTP 프레임워크를 7회에 걸쳐 구축했으나, **구조적 문제**: 외부 접촉 없이 자기 확인(circular self-confirmation)을 반복해 점진적 검증의 환상을 만들었다. 한국 제품 감사(iter 4)에서 실용적 예리함을 보였지만, 이론적 신규성 주장(iter 6)에서 가장 약하다.

---

## 1. 내부 모순

### Social_Amplifier: 곱셈 인자인가, 독립 드라이버인가?
iter 1: "사회적 존재감은 증폭제, 독립 드라이버가 아님 — 곱하기 연산자"
동시에 VALUE GAP 계층의 **L1 = Social Presence alone** — 가장 약한 독립 레벨로 분류

⚠️ **모순**: Social_Amplifier가 진짜 곱셈 구조라면 Gap_Intensity≈0일 때 WTP≈0. 그런데 L1이 독립 레벨로 존재한다. 공식이 L1 현실을 설명하지 못한다. iter 7 실험 설계도 이 역설을 해결하지 않는다.

### Ethical_Coefficient 방향성 불일치
iter 1: 의존성 설계 시 계수 → 0 → 전체 WTP 공식 → 0

⚠️ **경험적 부조리**: 중독성 제품이 막대한 WTP를 추출하는 현실과 충돌. 계수는 구매 시점 WTP가 아니라 장기 브랜드 신뢰 하락의 **지연 지표**인데, 공식은 동시 승수로 표현. iter 5 MVP 매핑에서 "Ethical_Coefficient = 1.0"이라고 주장하지만 사용자가 구매 시점에 이것을 어떻게 알 수 있는지 메커니즘 없음.

### ICP 제외 로직 vs iter 4 진단 충돌
iter 2: 직장인 ICP 제외 — "제도적 버퍼가 Unknown Unknown 비용 흡수"
iter 4: 리멤버(사용자 대부분 직장인)를 L5 잠재력 최고로 평가

⚠️ **모순**: 직장인의 L5 WTP가 낮다면 리멤버의 L5 포텐셜 진단이 훼손된다.

## 2. 과잉주장

### "모든 수요 발생 메커니즘은 이 명제의 특수 사례다" (iter 1)
- 데이터 없는 반증 불가능한 전칭 주장
- 휴지, 주유 등 보충 기반 구매는 정체성 갭과 무관
- 이론이 고관여 구매로 스코핑되어야 하지만 보편적으로 주장됨

### iter 4 "시장 확인" 체크마크 테이블
- 자신의 프레임워크를 공개 제품에 적용하고 부합함을 "검증"으로 표시
- 어떤 유연한 프레임워크도 사후적으로 맞출 수 있음
- 반증 케이스를 전혀 탐색하지 않음

### "10배 WTP" 주장 (iter 6)
- 성격 진단 vs 치료 세션 비교를 VALUE GAP 우월성 증거로 사용
- JTBD 반론: 이것들은 아예 다른 작업 (자기오락 vs 임상치료), 동일 작업의 다른 정체성 레이어가 아님
- 명백한 반론을 검토하지 않음

### iter 7 ₩120,000 예산
- 카카오/Disquiet 콜드 포스트 전환율 현실: 5-15%
- 240응답 = 1,600-4,800 노출 필요
- ₩50,000 기프티콘 × 10명 = 응답자 1인당 기대값 ₩208 → 한국 프리랜서 참여 유인 부족
- **실제 예산 3-5배 과소 추정**

## 3. 미해결 항목 (여전히 답 없음)

**핵심 이론의 반증 기준 없음**: iter 7이 곱셈 구조 테스트를 실패해도 덧셈으로 다운그레이드할 뿐 — 언제 "VALUE GAP이 틀렸다"고 말할 것인지 명시 없음.

**경쟁 대안 이론 미검토**: JTBD만 비교. 정신 회계(mental accounting), 손실 회피 + 정체성, SDT 역량/자율/관계 — 중첩 예측을 내리는 이론들 검토 없음.

**커리어 거울 MVP 콜드 스타트 과소평가**: 6개 아웃컴 카테고리 × 시드 10명 = n=10 기반 "중앙값 코호트" → 호로스코프, 신호 아님.

**사용자 리서치 0건**: 7회 반복, 인터뷰 0. ICP 정의, 활성화 훅, 가격 티어 전부 이론화. 한국 창업가 5명 인터뷰가 iter 7 실험 전체보다 더 많은 것을 밝혀줄 것.

## 4. 진짜로 확립된 것

**L1-L5 계층은 유용한 진단 렌즈**: 공식의 옳고 그름과 무관하게, 범용 위임에서 정체성 위협 unknown-unknown까지의 그라디언트는 제품 가치 제안을 분류하는 진짜 유용한 방법. iter 4 한국 제품 감사가 이를 증명 — 퍼블리/클래스101/리멤버 진단이 예리하고 비자명함.

**"갭 공개 = 판매" 통찰은 구조적으로 타당**: Eugene Schwartz(1966) 문제 인식 세그멘테이션의 재진술이지만 정체성 갭을 통한 재프레이밍이 실질적 뉘앙스를 추가. 실천적 함의(콘텐츠 마케팅이 피처 설명 대신 갭 공개)는 공식 옳고 그름과 무관하게 유지.

**Anti-빠짐 윤리 프레임워크가 잘 구축됨**: "각 세션 후 사용자가 제품 없이 더 유능해지는가?" + Fogg/Noggle 이중 테스트 — 명확하고 실행 가능하며 제품 디자인 문헌에서 진짜 부재했던 내용.

**iter 6의 솔직한 약점 인정이 신뢰성 있음**: 구매 타이밍, 실무 도구, 저관여 구매에서의 열세 인정 → 생존하는 주장들을 강화.

## 5. iter 9가 해야 할 단 하나

**한국 창업가/프리랜서 ICP 5-10명 정성 인터뷰 — VALUE GAP 진단을 프로브로, 피치로 사용하지 말 것**

방법:
1. 커리어 궤적 거울 컨셉 목업 보여주기
2. "얼마 내겠느냐?" 묻지 말 것
3. 갭 시각화 목업 보여주고 감정 반응 관찰
4. L5 이론 예측(정체성 위협, 사회적 이해관계 활성화, 즉각적 해결 욕구)과 일치하는가?
5. 반증 반응 기록: 무관심, 혼란, "이미 내 갭을 안다"

반증 증거를 가져오는 인터뷰 5개가 iter 7 실험 전체보다 값지다.
