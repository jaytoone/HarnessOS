## 제품 컨셉

**커리어 궤적 거울 (Career Trajectory Mirror)**

사용자의 커리어 히스토리를 입력하면, 사용자가 원하는 아웃컴에 도달한 사람들의 궤적과 비교해 **사용자가 스스로 진단할 수 없었던 갭 3개**를 자동 공개.

> 판매는 갭이 표시되는 순간에 발생한다.

---

## Core Loop (3단계)

```
Step 1 [Input]  → 커리어 타임라인 5필드 입력 (3분 이내, 로그인 불필요)
Step 2 [Reveal] → 목표 아웃컴 달성자 코호트와 궤적 비교 → 발산점 3개 공개
Step 3 [Action] → "이 갭을 닫는 경로를 보시겠습니까?" → 클릭 = 전환 순간
```

---

## 데이터 입력 (MVP 범위)

**최소 유효 데이터**: 궤적 형태, 세부 이력 아님
- 역할 시퀀스
- 각 역할의 회사 단계 (스타트업/SMB/대기업)
- 외부 아웃풋 유무 (블로그, 깃허브, 발표, 포트폴리오)
- 자가 신고 목표 아웃컴

**한국 데이터 소스 (MVP)**:
- Primary: 구조화된 온보딩 자가 신고 (스크래핑 불필요)
- 시드 코호트: 아웃컴 확인된 사용자 50-80명 CLG 직접 모집 (시리즈A 창업가, 월 500만+ 프리랜서) — 론칭 전 동일 5필드 입력 + 아웃컴 확인
- 사람인/잡코리아 API는 MVP 이후

**온보딩 플로우**: 목표 설정 → 역할 히스토리 3-5개 → 목표 아웃컴 6개 중 선택 → 즉시 갭 계산 시작 → **갭 표시 전까지 계정 생성 없음**

---

## 갭 공개 순간 (판매 순간)

**UI**: 분할 화면
- 좌: 사용자 궤적 라인
- 우: 목표 코호트 중앙값 궤적 라인
- 발산점 3개: 펄스 마커로 표시

**카피 예시**:
> "이 시점에 성공 코호트의 73%는 외부 포트폴리오를 갖고 있었습니다. 당신은 없습니다."

폴드 아래 텍스트 없음. 디자인의 침묵이 무게를 전달.

**Free→Paid 트리거**:
- 발산점 라벨은 공개, 상세 내용은 블러 처리
- "이 갭이 왜 생겼는지, 당신 위치에서 닫는 데 걸린 평균 기간은?" → 유료 잠금 해제
- 질문 자체가 판매 도구
- 가격: **₩29,000/월**

---

## PLG 메커니즘

### Aha Moment (측정 가능)
- 사용자가 착지 후 4분 이내 궤적 발산 시각화 확인
- 이벤트: `gap_visualization_rendered` AND `divergence_point_hover`
- 목표 활성화율: 60%+

### Free Tier
- 궤적 시각화 전체 + 발산점 라벨 3개
- 인과관계 + 닫기 기간은 블러
- **공유 잠금 해제**: 익명화 결과 공유 → 발산점 상세 1개 잠금 해제 (CLG 배포 유발)

### Paid Tier (₩29,000/월)
- 발산점별 인과 분석 전체
- 현재 프로필 기반 닫기 기간 벤치마크
- 월간 재분석 (커리어 데이터 업데이트 시)
- 피어 코호트 매칭 (같은 경로에서 12개월 앞선 사람 연결)

### PQL 신호
트리플 시그널 = 전환 의도 높음:
1. 갭 시각화 확인
2. 블러 상세 호버
3. 7일 이내 재방문

자동 트리거: 인앱 넛지 + 옵션 KakaoTalk/Slack 휴먼 메시지 (CLG→PLG 브릿지)

## Anti-빠짐 설계

각 유료 세션은 **다음 프론티어 갭**을 공개 — 동일한 것을 반복하지 않음.

- 사용자가 발산점 닫기 (자가 신고 진도 업데이트) → 시스템이 다음 코호트 티어로 재계산
- 닫힌 갭에 대해 제품 의존도 감소, 새 unknown-unknown에 즉각 필요
- 목표 티어의 모든 갭 닫기 → 한 단계 위 아웃컴 티어 노출

> 제품이 스스로 덜 필요해지면서 프론티어를 확장 — 제조된 의존성 없이 유지

## MVP 빌드 스코프 (8-10주)

```
Week 1-2:  온보딩 5필드 폼 + 목표 아웃컴 택소노미 (6개 고정)
           CLG DM으로 아웃컴 확인 시드 유저 60명 모집
           시드 데이터베이스 입력 UI (동일 폼 + 아웃컴 확인 플래그)

Week 3-5:  갭 계산 엔진
           궤적 비교 알고리즘 (중앙값 코호트 vs 사용자, 3구간 발산점 감지)
           정적 시각화 렌더러 — 분할화면 타임라인, 발산 펄스 마커
           (폼 제출 시 계산 실행, 결과 캐시)

Week 6-8:  페이월 통합
           Free 티어 블러 레이어
           KakaoPay / Toss 결제 (₩29,000/월)
           유료 상세 잠금 해제: 발산점별 인과 텍스트 + 닫기 기간 통계
           공유 잠금 해제 메커니즘

Week 9-10: PQL 감지 로직 + 창업자 알림 (MVP는 수동 팔로업)
           재방문 추적
           갭 닫기 자가 신고 시 재분석 트리거
           월간 이메일 "당신의 궤적이 업데이트되었습니다"
```

---

## 핵심 제약 (실패 방지)

> **시드 코호트 품질이 제품 존재 여부를 결정한다.**

아웃컴 확인 유저가 정확하게 세그먼트되지 않으면 발산점이 호로스코프처럼 느껴진다. 코드 한 줄 작성 전에 아웃컴 확인부터.

- 시드 코호트 최소: 60명 (아웃컴 확인 완료)
- 아웃컴 확인 기준: 시리즈A 이상 창업 OR 프리랜서 월 순수익 500만+
- Week 3 갭 엔진 시작 전 시드 50명 이상 확보 필수

## 이론 → MVP 매핑 검증

| WTP 이론 요소 | MVP 구현 |
|---|---|
| unknown-unknown 갭 | 아웃컴 코호트 데이터 없이는 사용자가 갭 진단 불가 |
| 갭 공개 = 판매 | 시각화 후 블러 + "경로 보기?" CTA = 전환 순간 |
| Social Amplifier | 공유 잠금 해제 + 피어 코호트 매칭 |
| Ethical_Coefficient = 1.0 | 갭 닫기 → 재계산 → 실제로 덜 필요해짐 |
| CLG First | 시드 코호트 60명 모집 = 첫 커뮤니티 |
| Anti-빠짐 | 닫힌 갭 재활용 없음, 항상 새 프론티어 |
